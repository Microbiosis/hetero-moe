## 2. 口径（全部跑前写死）

### 2.1 统计单位与块

**块** = (方向 A→B, 源层 l, 目标层 j, 槽 s)。种子是 **nuisance**（多种子观测并入同一块，取块内中位数）。

| 集合 | 构成 | 块数 |
|---|---|---:|
| 文本对（**主判据集**） | Qwen→BERT：L_Q × L_B = 8 × 4；BERT→Qwen：L_B × L_Q = 4 × 8 | **64** |
| ├ 同层子集（j = l，层号相等） | 每方向 4 块 | 8 |
| └ 跨层子集 | 其余 | 56 |
| ViT 平行臂 | ViT 自跨层 l ≠ j，L_V = {0, 3, 6, 9, 11} | 20 |

- **层阶梯**：`L_Q = {0, 1, 2, 3, 6, 12, 18, 23}`（Qwen 24 层）、`L_B = {0, 1, 2, 3}`（BERT 4 层）、`L_V = {0, 3, 6, 9, 11}`（ViT 12 层）。
- **功效门槛**：文本对块数 **≥ 32** 才允许开跑（当前 64 ✓）。不足则不开跑（与 v75 的 α 纪律同款）。

### 2.2 模型对与 ViT 的参与方式（**共享模态口径**）

- **跨模型方向**：Qwen→BERT、BERT→Qwen。两者同为文本、序列长同为 128 ⇒ tokenization 不同但**样本级**可比。
- **ViT 为何以「自跨层臂 + 槽特异性对照」参与**：
  - ViT 只吃图像、Qwen/BERT 只吃文本 ⇒ **不存在**「同一批样本上 ViT 的 Q 槽 ↔ 文本模型 Q 槽」的配对；强行按索引配对得到的是噪声。
  - 故 ViT 的参与方式是两条**不需要跨模态配对**的口径：
    1. **自跨层臂**：源与目标都是 ViT（图像配对成立），P1a/P1b 的注入-探针回路在 ViT 内部跑；
    2. **槽特异性对照 Δ_ViT**：同一模型内 Q 槽 vs O 槽的**标签可读性差**，与文本对同口径（4 类、留出集读数）⇒ 可与 Δ_Qwen / Δ_BERT 并列比较。
  - ⇒ **ViT 不进入跨模型配对统计**；它进入的是「第三架构的槽结构是否同源」这条平行证据。
  - **待办（不阻塞 S3）**：若拿到配对的图像-文本语料，ViT 可升级进跨模型配对统计。

### 2.3 注入算子与强度

按 [`docs/A1_DESIGN.md`](A1_DESIGN.md) §1.1 的形式 (a)（加性 + 残差缩放）：

```text
A 第 l 层槽 s 激活   a_s = 抓真模型模块激活（投影类取输出 / O·contract 类取输入）
共享空间槽 token     z  = P_A · a_s                     （P_A：v62 的正交投影，256 维）
注入量               Δ_B = P_Bᵀ · z                     （映回 B 的隐空间；**不做任何学出来的映射**）
目标模型第 j 层输入  h_B^j ← h_B^j + λ · Δ_B
```

- **注入点**：目标模型第 **j 层输入**处（`forward_pre_hook`，与 v77 的实现同款，不手工逐层调用）。
- **强度 λ（固定）**：逐样本归一化到 `‖Δ_B‖ = λ · ‖h_B^j‖`，**λ = 0.03**（**块 Frobenius 口径**；量纲无关、四臂同强度；λ 的标定与口径见 §2.3 修订记录第 6 条）。arm3 的随机方向按**同样的范数**构造。
- **机械前提（门）**：arm0（零注入）的「打断→续跑」必须与原前向**逐位等价**（rel_err = 0，沿用 v77 的 B2 口径）⇒ 不达标不开跑。
- ✅ **头号工程风险（S2-0）已结清，结论是负的（v79）**：v79 在真模型激活上核验了四个候选来源（v75 合成拟合 / ridge / procrustes / low-rank），**没有一个能在留出集上超过「不对齐」基线**（matched−noalign 中位差全 ≤ 0；池化映射在训练集上也不如基线 ⇒ 不是过拟合）⇒ **作为预登记对象的 `align[s|A→B]` 不存在可用的版本**。
- ⇒ **2026-11-17 拍板：注入算子保留「共享空间载体」，但不做任何学出来的映射**（上式即最终口径）⇒ 本条不再是风险，而是**已写死的口径**：S3 不依赖任何跨模型对齐映射，也因此**不再把「跨模型槽对应」当前提** —— 它是被检验对象，不是被使用的东西。

## 3. 判据（阈值跑前写死）

| 判据 | 统计量 | 阈值 | 含义 |
|---|---|---|---|
| **P1a 穿透** | 块级 Δ = R²(arm1) − R²(arm0)（目标槽可读性） | 块内分层置换 **p < α = 0.01** | 信息确实流过去了 |
| **P1b 槽特异** | R²(arm1) − R²(arm2)；R²(arm1) − R²(arm3) | 两个配对置换 **都 p < 0.01** | 不是随便什么都能流（**在目标模型内部判**：arm1 注入 Q 槽 vs arm2 注入 O 槽，在**同一读出**上比较；不再依赖跨模型 CKA 匹配） |
| **P2 深度语义** | 同层子集的中位增量 vs 跨层子集的中位增量 | 同层 ≥ 跨层，且分层置换 **p < 0.01** | 深度错配这条硬骨头存在 |
| **P3 守门** | ① 输出相对扰动 ∈ (1e-3, 0.5)；② 选择性：非目标槽可读性增量不普涨 | ① 必须成立；② 增量中位数 ≤ 0 或 p ≥ 0.05 | 注入没把 B 搞坏、也没把全盘抬起来 |
| **P4 否决** | 若 Δ_P1a 的块级中位数 ≤ 0 或不可判定 | —— | **离线前向下无可测效应 ⇒ A1 必须转训练版**，不得以「训练后就好了」搪塞 |
| **P1c 槽特异性存在性**（ViT 平行臂） | Δ_ViT = 标签可读性(Q 槽) − 标签可读性(O 槽) | 符号检验 **p < 0.05**（n = 20 ⇒ 需 ≥ 16 个正号） | 第三架构的槽结构也分得开 |

- **α = 0.01**（沿用 v75 的 `P_G2`）；落在 0.05 上下**照样不放行**。
- 置换 = **块内分层置换 + 臂间配对置换**（v75 口径），蒙特卡洛 10⁴ 次 ⇒ 最小可达 p ≈ 1e-4；报告须同时给 p 与置换次数。
- 种子：5 个 nuisance 种子，块内取中位数（v75 口径）。
- **报告要求**：每个判据给块数 / 正号数 / 中位增量 / p；只给「显著」不给块数的报告视为无效。

## 5. 已知近似与边界（引用本协议必须带上）

1. **层号 ≠ 相对深度**（Qwen 24 层 vs BERT 4 层）⇒ 「同层」指**层号相同**，属已知近似（同 A1_DESIGN §2 的「同层号 + 同槽名」近似）。
2. **Q/O 之外的槽不能作注入源**（GQA 非方阵 / 维度不匹配），不是「没测」而是「口径上不可比」。
3. **ViT 臂功效低**：20 块、单模态（图像）、类内样本少 ⇒ 结论只作**方向性对照**，不得单独支撑跨模型主张。
4. **跨模型可比单位是标量**，不是逐 token 配对；跨模型的槽配对诊断在 S3 里只作背景检查。
5. **不承诺能力提升**：P3 只证「B 没被搞坏」，不是「B 变强」。
6. ⚠️ **不再主张「跨模型槽对应」**：共享空间 + 槽激活作为跨模型载体是**被检验对象**，不是被使用的前提（v79 已证明没有可用的跨模型对齐映射）。
7. **注入量是 `a_s` 的 256 维投影**（P_A 的正交投影）⇒ 探针读回的信息上限受该投影限制 ⇒ 读数只作**相对增量**解读（arm1 vs arm0/arm2/arm3），**不作绝对水平解读**。
6. **不做共同成分残差化**（v78 已证明它不是解法：合并判据反而更差，10/16、p=0.4545）。若 S3 之后要采用，须在新语料/新块上**重新预登记**。
7. **本协议不产生任何 A1 的总判定**：A1 整体要等 S2–S4 全部完成。

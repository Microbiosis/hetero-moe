# v5.0-alpha 纸面验证报告（V-Model 右侧）

## 发现 4 处问题，2 处 alpha 阻断

| ID | 位置 | 严重度 | 阻断 | 问题 |
|---|---|:---:|:---:|---|
| V1 | 2.2 forward | Critical | 是 | return mask（二值）而非 alpha_seq*mask（软权重），破坏 f_m 语义 |
| V2 | 2.2 backward | Critical | 是 | mean(dim=1) 维度错配：expand 反向已 sum-pool 到 [B,M]，mean 误对专家维求平均 |
| V3 | 4 | Minor | 否 | D_m 不等于 D_shared 一般式缺输出投影 Q_m；alpha 强制方阵自洽 |
| V4 | 7.1 | Minor | 否 | "梯度不随 S 衰减"在 seq 级结构性平凡，应为 token vs seq 对照实验 |

## 修正版核心算子

- forward:  return alpha_seq * mask        # 软权重
- backward: return grad_output * mask      # grad_output 已 [B,M]，无 mean

## 关键推理链

unsqueeze+expand [B,M]->[B,S,M] -> autograd 反向规则为 sum -> 到达 backward 时
grad_output 已被 sum-pool 到 [B,M] -> 无需再 mean，仅乘 mask（STE）

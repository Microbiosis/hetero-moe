# 最终结论 + 诚信审计

## 起点问题

v4.0 异构融合能否用于 embedding / rerank / VLM / LM 四类模型？

## 回答

不能通用。v4.0 边界是同构族 LM-FFN。四类中仅 LM 完全适用；其余的深层问题
不是架构不匹配，而是路由粒度与损失粒度不匹配。

## 科学产出（两次证伪 -> 一次证实）

| 命题 | 结果 |
|---|---|
| errata-4: ||grad|| 正比于 1/sqrt(S) 能区分稀释 | 证伪（mean-pool 使 per-token 梯度完全相关，大数定律给 O(1)） |
| B': sequence 路由收敛更快 | 证伪（池化目标下欠定"免费"，两粒度收敛到相同 0.3543） |
| H': 粒度匹配——per-token 任务 token 更优 | 证实（MSE 0.055 vs 0.414，7.5x；正确率 82.8% vs 29.7%） |

## 一句话结论

本研究不是"实现了什么"，而是证伪了两个过强假设、提炼并证实了一个更精确的
原理——路由粒度应匹配损失粒度。v4.0 与 v5.0-alpha 的路由选择并非一错一对，
而是同一原理在两类任务上的正确实例。

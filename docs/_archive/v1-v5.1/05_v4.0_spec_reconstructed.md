# 异构微观融合系统 v4.0 规范

> **版本**: v4.0 规范（重构版）  
> **来源**: 跨 AI 对话重构  
> **日期**: 2026-08-21

---

## 1. 适用范围

同一 Transformer 架构族（相同注意力掩码、相同位置编码、相同归一化策略）内
的语言模型 FFN 层异构融合。

## 2. 核心架构

- 共享 Attention（冻结）+ 异构 FFN 专家（M 个，冻结）+ 轻量适配器（可训）
- Token 级稀疏路由：Top-K STE，K=2
- SwiGLU 结构：gate_proj / up_proj / down_proj，权重注入自预训练底座

## 3. 适配器参数（每专家每层）

- $\gamma_m$（逐通道缩放）、$\beta_m$（逐通道偏移）、$\alpha_m$（专家输出标量，初始化 0.01~0.1）
- $W_{router}$（路由器，Phase 1 学习率 100x 补偿）
- 适配器参数量 << 底座参数量，满足 $O(L \cdot D + \text{Adapter\_Params})$ 内存界

## 4. 训练分相

- **Phase 1**: 仅训适配器（$\gamma$/$\beta$/$\alpha$/$W_{router}$），底座全冻结，均匀路由 warmup
- **Phase 2**: 解锁 $W_{router}$ 稀疏路由，加 $L_{balance}$（负载均衡）+ $L_z$（z-loss）

## 5. 量化对齐

- Fake-INT4 STE 模拟量化噪声注入，Phase 2 起生效
- 验收：FP16 vs Fake-INT4 的 PPL 差异 < 阈值

## 6. 实施路径（严格顺序，禁止跳级）

- 8.1 PyTorch 原生验证（0.5B x 4 底座，A100-80G）
- 8.2 量化对齐验证
- 8.3 推理基准（容量因子 C=1.0/1.25/1.5 对照）
- 8.4 Triton Kernel（独立文档，独立工程师，前置依赖 8.1-8.3 全过）

## 7. 隐藏假设（v4.0 未显式声明，后被 v5.0 揭示）

- **A1**: Token 级均匀可分解性（每 token 是独立可路由计算单元）
- **A2**: 单一训练目标（next-token prediction 为主损失）
- **A3**: 同构架构族（M 个底座架构完全一致，仅权重异构）

# v5.1 规范：路由粒度匹配原理（Baselined）

## 核心原理（本研究最高产出）

> 路由粒度应匹配损失粒度（决策数 约等于 信号数）。

| 任务 | 损失粒度 | 匹配路由 | 结果 |
|---|---|---|---|
| InfoNCE（池化） | 1 信号 | sequence（1 决策） | 决策稳定（翻转 0% vs 2.46%） |
| Per-token 回归 | S 信号 | token（S 决策） | MSE 优 7.5x（0.055 vs 0.414） |
| 池化 + token 路由 | 1 信号 | 过参数化 | 收敛无损但决策游走 |
| Per-token + seq 路由 | S 信号 | 欠参数化 | loss 下界显著抬高 |

## 统一洞察

v4.0 token 路由（LM，per-token 损失）与 v5.0-alpha sequence 路由（embedding，
池化损失）都是粒度匹配的正确选择——同一原理的两个实例。

## 三粒度算子

- **token**: 逐 token TopK STE（v4.0 现状）
- **span**: 显式边界标记切分，边界内 Pool 后 TopK（v5.1 实现，严禁学习切分）
- **sequence**: mean-pool 后 TopK，broadcast 至全序列（v5.0-alpha 已验证）

## 验收协议

- Metric A: 输入扰动路由翻转率（seq < token，已验证 0% vs 2.46%）
- Metric B': 收敛速度对比（池化目标下无差异，已证伪；per-token 任务待规模化）
- H' 判定门: token MSE < sequence x 0.5 且正确率 > sequence+10%（已 PASS）

## 9. 验证边界（诚实标注）

CPU 小规模验证（D 小于等于 32, B 小于等于 4, S 小于等于 16）。0.5B 级 A100 验证待闭合（8.1 硬件依赖）。

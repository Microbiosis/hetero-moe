## 1. 架构前提与张量约束

1. **模型选择**：采用 $M$ 个具有相同 Transformer 架构规格的预训练模型作为异构底座（如 $M=4$ 个不同偏向的 1B/7B 模型）。
2. **维度与词表对齐**：所有底座隐藏层维度 $D$ 严格一致，共享同一 Tokenizer。若存在词表差异，需通过 Pad Token 对齐 ID 映射。
3. **结构约束（KV Cache 隔离）**：为避免 $M$ 倍 KV Cache 爆显存，**规定异构性仅存在于 FFN 层，Attention 层强制共享同一组冻结权重**（选取其中一个底座作为主干 Attention 提供者）。所有底座的 Attention 实现（包括 RoPE 基频、GQA/MHA 分组）必须逐字节一致。
4. **内存优化**：主干残差流 $X \in \mathbb{R}^{B \times S \times D}$ 的深层梯度传播退化为恒等映射 $I$，底座 FFN 的中间激活值无需保存，显存开销从 $O(M \times L \times D_{ff})$ 降至 $O(L \times D + \text{Adapter\_Params})$。

## 2. 前向传播与梯度流定义

针对残差流中任意 Token 的隐藏状态 $x_t \in \mathbb{R}^D$，第 $i$ 层异构融合层的计算过程定义如下：

### 2.1 分布对齐与输入截断

为截断深层梯度、避免底座前置层激活占用显存，采用显式 `detach`：

$$ h_{t, m}^{aligned} = \text{stop\_grad}(x_t) \odot \gamma_m + \beta_m $$

其中 $\gamma_m, \beta_m \in \mathbb{R}^D$ 为可训练的逐通道缩放与偏移参数。PyTorch 等价实现为 `x.detach() * gamma_m + beta_m`。

### 2.2 量化感知 FFN 计算

底座 FFN 权重冻结，采用 SwiGLU 激活：

$$ F_m^{exact} = \left( \text{SiLU}(h_{t, m}^{aligned} \cdot W_{gate}^{(m)}) \odot (h_{t, m}^{aligned} \cdot W_{up}^{(m)}) \right) \cdot W_{down}^{(m)} $$

在 FFN 输出端注入 INT4 量化噪声，让噪声通过残差连接自然传播：

$$ F_m^{noisy} = \text{FakeQuant}_{STE}(F_m^{exact}, \text{bits}=4, \text{group\_size}=128) $$

### 2.3 稀疏门控路由

Router 基于未被噪声污染的原始 $x_t$ 计算路由概率：

$$ z_{t, m} = x_t \cdot W_{router}^T, \quad \alpha_{t, m} = \text{Softmax}(z_{t, m}) $$

采用带 Mask 的 Straight-Through Estimator (STE) 实现硬 Top-K 路由，防止非 Top-K 位置梯度泄漏。前向硬截断，反向仅透传 Top-K 位置梯度：

- **前向**：$\hat{\alpha}_{t, m} = \begin{cases} \alpha_{t, m} & \text{if } m \in \text{TopK}(\alpha_{t, :}) \\ 0 & \text{otherwise} \end{cases}$
- **反向**：$\frac{\partial \hat{\alpha}_{t, m}}{\partial \alpha_{t, m}} \approx \mathbb{I}_{m \in \text{TopK}}$

### 2.4 残差融合输出

所有专家的输出通过门控标量 $\alpha_m$ 注入回主干：

$$ y_t = x_t + \sum_{m=1}^{M} \hat{\alpha}_{t, m} \cdot \alpha_m \cdot F_m^{noisy} $$

## 3. 优化目标与损失函数

系统的总优化目标包含语言建模损失、负载均衡损失和 Router Z-Loss：

$$ L_{total} = L_{LM} + \lambda_1 L_{balance} + \lambda_2 L_{z} $$

### 3.1 语言建模损失

$$ L_{LM} = -\frac{1}{B \cdot S} \sum_{b,s} \log P(y_{b,s}^{true} | y_{b,s}) $$

### 3.2 负载均衡损失

$$ f_m = \frac{1}{B \cdot S} \sum_{b,s} \hat{\alpha}_{b,s,m}, \quad P_m = \frac{1}{B \cdot S} \sum_{b,s} \mathbb{1}[m \in \text{TopK}(\alpha_{b,s})] $$

$$ L_{balance} = M \cdot \sum_{m=1}^{M} f_m \cdot P_m $$

### 3.3 Router Z-Loss

$$ L_{z} = \frac{1}{B \cdot S} \sum_{b,s} \left( \log \sum_{m=1}^{M} \exp(z_{b,s,m}) \right)^2 $$

## 4. 训练协议：冷启动与渐进解锁

为防止 Router 早期在 $L_{balance}$ 盲目优化下退化为平凡解，采用渐进式解锁与学习率隔离策略：

### 4.1 参数初始化设定

- $W_{router}$：高斯分布 $\mathcal{N}(0, 0.01^2)$，形状为 $[M, D]$（满足 `F.linear` 的 `[out, in]` 约定）。
- $\gamma_m$：恒等初始化（全 1）。
- $\beta_m$：零初始化（全 0）。
- $\alpha_m$：**正值区间初始化** $\text{Uniform}(0.01, 0.1)$，避免 $10^{-4}$ 级梯度衰减导致的死锁。每个 $\alpha_m$ 作为独立 `nn.Parameter` 包装在 `ParameterList` 中，避免切片非叶节点问题。

### 4.2 Phase 1（预热阶段，前 10% Steps）

- **冻结 $W_{router}$**（`requires_grad=False`），使用不包含 $W_{router}$ 的独立优化器。
- **强制均匀路由**：$\hat{\alpha}_{t,m} = (\frac{1}{M}).\text{detach}()$，彻底切断计算图，双重保险防止 $W_{router}$ 接收梯度。
- **Loss 约束**：强制 $\lambda_1 = 0$，避免非均匀 $P_m$ 干扰适配器训练。损失函数为 $L_{LM} + \lambda_2 L_{z}$。
- **学习率隔离**：适配器参数组（$\gamma_m, \beta_m$）设置 100 倍补偿学习率（$1e^{-2}$），$\alpha_m$ 设置 $1e^{-3}$。

### 4.3 Phase 2（解锁阶段，后 90% Steps）

- 解冻 $W_{router}$，恢复 $\lambda_1 > 0$，启用 Top-K 稀疏路由。
- 优化器包含全部可训练参数，维持学习率隔离（Router $1e^{-4}$，适配器 $1e^{-2}$，$\alpha_m$ $1e^{-3}$）。

## 5. 推理部署规范：容量与溢出

### 5.1 容量因子约束

设容量因子 $C \geq 1$（推荐 $C=1.25$），专家 $m$ 的最大处理容量为 $Capacity_m = C \cdot \frac{B \cdot S}{M}$。

### 5.2 溢出降级与动态重归一化

当首选专家溢出降级到次选时，必须对实际激活的专家集合做重归一化，防止残差幅值被压缩导致分布偏移。

设 $\text{Valid}$ 为未溢出的实际激活专家集合：

$$ \tilde{\alpha}_{b,s,m} = \frac{\alpha_{b,s,m}}{\sum_{m' \in \text{Valid}} \alpha_{b,s,m'}} \quad \text{for } m \in \text{Valid} $$

若所有候选均溢出，$\text{Valid} = \emptyset$，Token 跳过 FFN 层，直接 $y_t = x_t$。若某专家持续溢出超过 5% Token，需提升 $C$ 或检查 Router 分布漂移。

## 6. 并行与量化策略

### 6.1 并行策略约束

对于 $M=4$ 等小规模系统，禁用专家并行（EP），优先使用张量并行（TP）：
- 将每个专家的 $W_{gate}, W_{up}, W_{down}$ 沿 $D_{ff}$ 维度拆分到多卡，避免跨节点 All-to-All 通信开销。
- 仅当 $M \geq 8$ 或单专家参数量超过单卡显存上限时，才启用 EP。

### 6.2 INT4 量化感知

底座量化为 INT4 时，反量化噪声在 FFN 输出端通过 Fake Quantization 模拟，并通过残差流自然传播至下一层 Router 输入端。FakeQuant 的反向传播必须使用 STE，防止 `torch.round` 丢失梯度。真实实现需按 `group_size=128` 分块计算 scale，原型中 per-row 简化仅供验证梯度流。

## 7. 核心参考实现 (PyTorch Prototype)

以下代码经多轮工程审查，准确映射了 v4.0 数学定义。修正了层间传递 Bug，确保 2-Layer 网络为真实深层验证而非独立单层并行。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class FakeQuantSTE(torch.autograd.Function):
    """模拟 INT4 量化噪声，反向传播使用 STE。"""
    @staticmethod
    def forward(ctx, x, bits=4, group_size=128):
        scale = x.abs().max(dim=-1, keepdim=True).values / (2 ** (bits - 1) - 1)
        scale = torch.clamp(scale, min=1e-5)
        return torch.round(x / scale) * scale

    @staticmethod
    def backward(ctx, grad_output):
        return grad_output, None, None


class SparseRouterSTE(torch.autograd.Function):
    """带 Mask 的 Top-K 稀疏路由，防止非 Top-K 梯度泄漏"""
    @staticmethod
    def forward(ctx, alpha, k):
        val, idx = torch.topk(alpha, k, dim=-1)
        mask = torch.zeros_like(alpha).scatter_(-1, idx, 1.0)
        ctx.save_for_backward(mask)
        return alpha * mask

    @staticmethod
    def backward(ctx, grad_output):
        mask, = ctx.saved_tensors
        return grad_output * mask, None


def swiglu_forward(x, w_gate, w_up, w_down):
    h_gate = F.linear(x, w_gate)
    h_up = F.linear(x, w_up)
    h_act = F.silu(h_gate) * h_up
    return F.linear(h_act, w_down)


class HeteroFusionLayer(nn.Module):
    def __init__(self, d_model, d_ff, num_experts, top_k):
        super().__init__()
        self.num_experts = num_experts
        self.top_k = top_k

        # 冻结底座
        self.w_gates = nn.ParameterList([
            nn.Parameter(torch.randn(d_ff, d_model) * 0.02) for _ in range(num_experts)
        ])
        self.w_ups = nn.ParameterList([
            nn.Parameter(torch.randn(d_ff, d_model) * 0.02) for _ in range(num_experts)
        ])
        self.w_downs = nn.ParameterList([
            nn.Parameter(torch.randn(d_model, d_ff) * 0.02) for _ in range(num_experts)
        ])
        for p_list in [self.w_gates, self.w_ups, self.w_downs]:
            for p in p_list:
                p.requires_grad = False

        # 可训练参数
        self.W_router = nn.Parameter(torch.randn(num_experts, d_model) * 0.01)
        self.gammas = nn.ParameterList([
            nn.Parameter(torch.ones(d_model)) for _ in range(num_experts)
        ])
        self.betas = nn.ParameterList([
            nn.Parameter(torch.zeros(d_model)) for _ in range(num_experts)
        ])
        self.alphas = nn.ParameterList([
            nn.Parameter(torch.empty(1).uniform_(0.01, 0.1)) for _ in range(num_experts)
        ])

    def forward(self, x, phase1=False):
        B, S, D = x.shape
        x_residual = x

        z = F.linear(x, self.W_router)
        alpha = F.softmax(z, dim=-1)

        if phase1:
            alpha_hat = (torch.ones_like(alpha) / self.num_experts).detach()
        else:
            alpha_hat = SparseRouterSTE.apply(alpha, self.top_k)

        out_sum = torch.zeros_like(x)
        for m in range(self.num_experts):
            x_detached = x.detach()
            h_aligned = x_detached * self.gammas[m] + self.betas[m]
            f_m_exact = swiglu_forward(
                h_aligned, self.w_gates[m], self.w_ups[m], self.w_downs[m]
            )
            f_m_noisy = FakeQuantSTE.apply(f_m_exact)
            out_sum = out_sum + alpha_hat[..., m:m+1] * self.alphas[m] * f_m_noisy

        y = x_residual + out_sum
        return y, z, alpha_hat


def run_verification():
    torch.manual_seed(42)
    B, S, D, D_FF, M, K = 2, 8, 16, 32, 4, 2

    model = nn.Sequential(
        HeteroFusionLayer(D, D_FF, M, K),
        HeteroFusionLayer(D, D_FF, M, K)
    )

    x = torch.randn(B, S, D)
    target = torch.randn(B, S, D)

    # === Phase 1 ===
    print("=== Phase 1 验证 ===")
    for layer in model:
        layer.W_router.requires_grad = False

    opt_p1 = torch.optim.AdamW([
        {'params': [p for l in model for p in l.gammas] + [p for l in model for p in l.betas], 'lr': 1e-2},
        {'params': [p for l in model for p in l.alphas], 'lr': 1e-3},
    ])

    model.train()
    opt_p1.zero_grad()

    y = x  # 层间传递：第一层输出作为第二层输入
    for layer in model:
        y, z, _ = layer(y, phase1=True)

    loss = F.mse_loss(y, target) + 0.001 * (torch.logsumexp(z, dim=-1) ** 2).mean()
    loss.backward()
    opt_p1.step()

    l0 = model[0]
    print(f"Loss: {loss.item():.4f}")
    print(f"W_router.grad: {l0.W_router.grad}")
    print(f"gamma[0] grad: {l0.gammas[0].grad.norm().item():.2e}")
    print(f"alpha[0] grad: {l0.alphas[0].grad.norm().item():.2e}")

    # === Phase 2 ===
    print("\n=== Phase 2 验证 ===")
    for layer in model:
        layer.W_router.requires_grad = True

    opt_p2 = torch.optim.AdamW([
        {'params': [p for l in model for p in [l.W_router]], 'lr': 1e-4},
        {'params': [p for l in model for p in l.gammas] + [p for l in model for p in l.betas], 'lr': 1e-2},
        {'params': [p for l in model for p in l.alphas], 'lr': 1e-3},
    ])

    opt_p2.zero_grad()

    y = x  # 层间传递：第一层输出作为第二层输入
    for layer in model:
        y, z, ah = layer(y, phase1=False)

    lm = F.mse_loss(y, target)
    lz = (torch.logsumexp(z, dim=-1) ** 2).mean()
    lb = M * (ah.mean(dim=(0, 1)) * (ah > 0).float().mean(dim=(0, 1))).sum()

    loss = lm + 0.01 * lb + 0.001 * lz
    loss.backward()
    opt_p2.step()

    l0 = model[0]
    print(f"Loss: {loss.item():.4f}")
    print(f"W_router grad: {l0.W_router.grad.norm().item():.2e}")
    print(f"alpha[0] grad: {l0.alphas[0].grad.norm().item():.2e}")
    print(f"Sparsity: {(ah[0, 0] > 0).sum().item()} / {M}")


if __name__ == "__main__":
    run_verification()
```

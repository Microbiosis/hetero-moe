# v4.0 四类模型适用性分析

## 评分维度（修正后）

- 1.1 Attention 可共享
- 1.2 FFN 结构同构
- 1.3 残差流维度一致
- 1.4 训练目标兼容性（真正的第 4 验收轴，原 1.4 detach/内存优化是机制非约束）

## 评分结果

| 模型类 | 总分/8 | 判定 | 根因 |
|---|:---:|---|---|
| Embedding | 5 | 条件适用 | Router token 级 vs InfoNCE sequence 级，梯度信号被平均稀释 |
| Rerank | 5 | 条件适用 | 计算单元是 (query,doc) pair，token 级路由破坏跨文档注意力上下文 |
| VLM | 5 | 条件适用（严格） | image patch 信息密度远大于 text token，模态边界处负载偏斜 |
| LM | 8 | 完全适用 | 设计原点 |
| 跨四类融合 | 0 | 不适用 | 注意力掩码互斥/损失不可组合/维度不一，超 v4.0 |

## v4.0 三条隐藏假设

1. **Token 级可分解性** —— Embedding（句级）、Rerank（文档级）不成立
2. **单一训练目标** —— 跨类别需多目标优化
3. **同构架构族** —— 跨类别架构差异无法由 FFN 层对齐消除

## v5.0 扩展方向（三项机制）

- 5.1 路由粒度泛化 $G \in \{\text{token}, \text{span}, \text{sequence}\}$
- 5.2 多目标损失框架（alpha 用固定权重 baseline）
- 5.3 模态投影层 $P_m$（$D_m \to D_{shared}$）

## 1. 主线 1：晶壁系（大球 · 小球 · 膜）

### 1.1 类比 → 工程量的逐项翻译

| 类比 | 工程量 | 状态 |
|---|---|---|
| N 个小球 | N 个异构底座（Qwen / BERT / ViT，架构+tokenizer+模态全不同） | ✅ |
| 小球绕成一个圆 | N 个底座在共享空间中的排布 | ✅ |
| 圆心撑起的三维膜 | 共享对齐空间 `d_shared=256`，逐槽正交映射 | ✅ |
| 膜扩张到半径 = 球半径 + 球心距 | 底座投影后的支撑半径不超出共享空间的可用半径 | ✅ |
| N 球与大球内切 | 同功能跨架构的权重谱相似性 | ✅ |
| 大球内资源共享、互相持有一部分 | `canonical [B,S,4,256]` 结构化 token（槽轴 × 模型轴） | ⚠️ 每模型各出一份、**顶层拼接**；模型之间**中途**不互持（§1.3.1） |
| 绕球心运行轨道 | 稀疏路由（top-k + 负载均衡） | ⚠️ 只有**顶层**槽门控 + 专家 top-k；**没有跨模型跨层的环道**（§1.3.1） |
| 信息流/token/状态相互承担 | 融合层 `FusionOverProjSpace`（50.3M，解冻） | ⚠️ 只在**顶层**聚合：模型之间唯一的通道就是这一个融合层（§1.3.1） |
| 膜的「三维」分层 | 功能槽 Q / K / V / O（+ expand / contract） | ✅ |
| **解体** | 按功能槽拆开各底座权重 | 🟡 |
| **重组** | 槽级成对对齐 `align[s|a>b]`，可复合 + 环路一致性 | ✅ |
| **相消相融** | 在公共槽空间做**权重级**符号消解，得到新权重 | **⬜** |

### 1.2 三处「类比与实测吻合」的地方

这不是事后附会——几何直觉在这些点上和实测一致，说明类比是有约束力的，不是修辞。

**① 「膜刚好」＝等维对齐。** 几何说膜扩张到恰好包住球心的距离；实测给出同一条结论，而且是反直觉的：

| rank | CKA | 保真度 |
|---:|---:|---:|
| 24 | 0.9982 | **0.165**（丢 83% 信息） |
| **256** | 0.9982 | **0.9998** |
| 768 | 0.9983 | 1.0000 |

CKA 从 8 维到 768 维**全程 0.998**——对齐质量与维度无关；**保真度才是维度的函数**。所以「刚好」不是拍脑袋，是有实测支撑的精确刻度。（证据：`research/aligner/v62_dimension_projection_space/SPEC.md` §5）

**② 「内切」＝同功能权重谱相似 —— ⚠️ v75 实测后必须加族构成限定。** JS 散度：同功能 **0.0302** vs 不同功能 **0.0401**，置换检验 p=**0.0002**（n=1728 对），Cohen d=0.252。各槽通用性差异很大：`contract` 0.0087 最通用，`K` 0.0504 最特异。

但这条 headline 混入了**族/形状构成**：「异功能」一侧的 1440 对里有 768 对是**跨族**（同槽对按构造必同族）⇒ 族平衡分离度仅 **+0.00104**，族分层置换 **p=0.3318 不显著**；函数相似度（CKA）口径的原生基线同样不显著（p=0.7014）。⇒ **它是族/形状效应的证据，不是功能槽对应的证据**。（证据：`research/weight_fusion/v75_weight_conjugation/SPEC.md` §3）

**③ 类比本身要求对「共用一个变换」打补丁。** 一个全局变换对齐 3 个模型必然过定失败：Q **0.6767** / O **0.7168**；去掉 Qwen 就回到 0.988 ⇒ 失败变量是**模型数**不是功能类型。改成成对对齐（`A_ac = A_bc ∘ A_ab`）+ 环路一致性后，三模型对齐 **0.9925**，直达与复合路径差 0.0038。

> 也就是说：**N 个球共用一个球心膜**在 N>2 时不成立，必须拆成成对可复合的局部对齐。几何直觉需要这条修正才自洽——而这条修正恰好是 v62 的机制。

### 1.3 用户预测的形式化

> 原话：「模型小球在大球中需要先解体，然后重组结构，他们的权重会在解体重组中进行相消相融得到新的权重。」

形式化为四步：

1. **解体**：把每个异构底座按功能槽（Q/K/V/O/expand/contract）拆成槽权重矩阵。
2. **重组**：用槽级成对对齐把各底座的槽权重搬到公共槽空间，使「同槽跨架构」可比。
3. **相消相融**：在公共槽空间做符号/幅度消解（task-arithmetic 式加和 + TIES 式冲突裁剪），得到一套**新的**槽权重。
4. **产出**：新权重构成的融合模型，替代或补充激活级融合层。

### 1.3.1 轨道的新定义：信息流在计算图内部跨模型跨层流动（2026-11-13 补充）

> 用户补充：在传统 MoA 里，一道信息流（一个 token / 一条消息）**只能在一个模型内部流动**，最后**集中到一个聚合层**处理；而晶壁系要求它**从一个模型的一个层流向另一个模型的另一个层**，**不经过集中的分配网关层** ⇒ 这需要**计算图算子层面**的信息流处理能力。

**按这个定义，§1.1 里「共享/持有」「轨道」「信息流」三行的 ✅ 都不成立** —— 现状是「每个底座跑到底 → 只取最后一层 → 顶层一个融合层聚合」，即**顶层聚合器 + 槽/专家路由**，没有中途的跨模型流动。§1.1 已按此降级标注。

**工程量翻译**（这一条比类比更决定成败）：

| 要件 | 具体是什么 | 现状 |
|---|---|---|
| 分段前向 | 底座必须能**取到第 l 层输出、接受注入、再继续跑完后面的层**（回灌）；否则一次注入就退化成又一个聚合器 | ❌ 三个骨干都只取 `.last_hidden_state`（`modeling_hetero_moe_projspace.py:617-647`） |
| 注入单位 | 注入的不是 hidden state（跨架构不可通约），而是**槽级 token**（Q/K/V/O 的 256 维投影）—— 槽是跨模型跨层可通约的语义单位 | 槽有了，但只在顶层拼接 |
| 轨道 = 有向图边 | (模型 m, 层 l) → (模型 m', 层 l')，边上的算子就是轨道 | ❌ 无 |
| 局部门 | 不设集中网关 ⇒ 每次在**层边界内部**决定「接收谁的哪些槽」，per-edge / per-boundary 局部可计算、可被梯度优化 | ❌ 现为集中式槽门控 + 顶层专家 top-k（`fusion.py:68`） |

**这条是主线的前置关卡**：激活级的跨模型跨层环道是「信息流能不能互通」，G1/G2/G3 是「权重能不能合并」，两者正交，但**前者是后者的载体** —— 没有环道，相消相融出来的新权重也没有通道去推动信息。⇒ 建议在 G1 之前增设 **A1（激活级信息流关）**。

**已知硬骨头**（先写下来，别等撞上）：

- **梯度归属**：A 的第 l 层注入 B 的第 j 层后，loss 的梯度会同时回传 A 与 B ⇒ 必须显式定归属（各自 loss / 共享 / 截断边梯度）。v62 那条「router 从未被优化 ⇒ 三组端到端数字作废」是同一类陷阱的放大版。
- **塌缩面 × 层数**：塌缩风险从「槽级 4 选」放大到「每层每边」，且门必须真的被优化，否则端到端数字再次作废（v62.6 正反馈致 V 槽独占，熵 0.076）。
- **深度语义错配**：ViT 第 2 层 ≠ BERT 第 2 层 ⇒ 槽只解决「功能」坐标，**「深度」坐标还没有**：需要定义 (m, l) → 功能槽 的映射，否则轨道只是层号对齐的假象。
- **计算图代价**：分段前向 + 跨模型注入会打断 HF 一次性 `model(...)` 调用（要逐层驱动并续接 attention mask / position embedding / cache）。

### 1.4 这条路线要撞的真正问题：激活级 ≠ 权重级

这是主线里最容易被跳过、但决定成败的一处接缝。

v62 的 `proj[s|m]` / `align[s|a>b]` 全部作用在**激活空间**上：它们把各底座的 hidden state 映到公共槽空间，融合发生在 `canonical token` 这一层。**权重级合并需要的是权重到权重的映射**，v62 现有算子一个都不提供。

要走通「相消相融」，至少要先过三关 —— 外加一个**激活级前置关卡 A1**（§1.3.1）：没有环道，相消相融出来的新权重也没有通道去推动信息。

| 关卡 | 要求 | 现状 |
|---|---|---|
| **A1 激活级信息流** | 一道信息流能从模型 A 的第 l 层流到模型 B 的第 j 层，且流过去对 B 有用；**不经过集中的分配网关层** | 🔴 **v82 S4-P 裁决 `S4PIPE_FAIL`**（§4.14）：管道形态（正文前开 8 位专属通道 + 按通道编号寻址）把「贯通」做到了比 S3 更强（**P5c Δ 中位 +0.004419，置换 p = 0.0**）、**通道寻址在块级成立**（**P5b p = 0.0**，相对 S3 的 P1b p = 0.9521 是质变）；但 **P5a 管道连通 / P5d 选择性 / P2′ 深度语义 三项未过** ⇒ 管道**不被按内容读取**（块级 p = 0.3108、逐样本 p = 1.0）、**非目标槽仍普涨**、**深度对应仍不存在**（跨层比同层高 11 倍）⇒ **A1 激活级路线仍无可用载体**（v81 的 `S3_FAIL` 结论未被推翻：仍无跨模型槽对应、也无深度对应）；⚠️ **post_hoc 读出端补测更正了「卡在读出端」的判断**：正文侧内容特异 **+0.011373（p = 0.0）**、槽特异 **+0.002700（p = 0.0，仅 BERT→Qwen）** ⇒ **容器关与传递关都过了**，剩下的是 **深度对应（P2′）** 与 **非目标槽普涨（P5d）** ⇒ 指向**源侧语义本身**（§4.14） |
| **G1 权重级共轭** | 从 `proj/align` 导出作用在权重上的映射：`W'_s = A_s · P_s · W_s · P_s⁻¹`，且共轭后同槽跨架构权重确实可比 | 🟡 v75 导出了**单边**输出基搬运 `N = M1·Aᵀ`（权重级映射确实存在）；但本表写的**双边**共轭未实现，且它要的「共轭后可比」那一半未成立 |
| **G2 共轭有效性** | 共轭后「同槽跨架构」的权重相似度显著高于「异槽跨架构」——把 §1.2② 的结论从激活搬到权重 | ❌ v75 实测：G2-a **不可判定**（原生基线无功效）、G2-b **证伪**（§4.7） |
| **G3 合并可用性** | 合并出的权重在 held-out 上超过激活级融合与单底座 | ⬜ 全新（G2 未过 ⇒ 按 §4.6 不进 G3） |

G2 是整条主线的**生死线**：如果槽级共轭后权重不再保持功能相似性，那么「按槽解体再融合」失去依据，第 3 步的符号消解就退化成噪声相加。

### 1.5 外部证据：为什么必须走到权重级

这一条独立于本项目，且直接支持用户对「这些变体只是普通 MoA」的判断。

arXiv **2606.27288**《When Does Combining Language Models Help?》（67 个模型 / 21 家机构）给出结论：

- 对任何**输出取某个成员模型答案**的策略（路由、投票、级联、融合、MoA），精度上界是 `1 − β`，β = 所有模型在同题上同时答错的比例。
- 实测 β：开放域数学 **0.052**、执行判分代码 **0.079**、GPQA 自由作答 **0.127**（改成自由作答就重新打开尾部 ⇒ 共同失效在**答案格式**里，不在学科里）。
- 「Gains come from models failing on different questions, not from adding more models.」
- 「combining models rarely beats the single best model without a strong query-level routing signal」。
- 「At matched quality, low-rho heterogeneous ensembles beat high-rho Self-MoA」——**异构优于同质**。

**推论**：用户列的那一串变体（SMoA / Self-MoA / RouteMoA / Attention-MoA / RMoA / MMoA）全部在**输出级或激活级**做组合，因此全部受同一堵 β 墙约束。把它们「搬进训练」若不改组合层级，撞的是同一堵墙。

**权重级是唯一能突破 β 的层级**——因为融合后产生的不是任何成员的答案。这也解释了为什么「异构底座权重合并」（论文 `reconstruct.tex` §Model merging 明确写了「异构底座无法这样合并」）值得正面推翻，而不是绕开。

## 2. 路线本体（一句话版）

> **晶壁系**：N 个异构底座是 N 个小球，共享对齐空间是球心的膜，膜的半径要**刚好**（等维、无损）；N 球在膜内各占一个功能槽、各持有一份信息流/token/状态，绕球心轨道运行（稀疏路由 —— **现状只有顶层路由，跨模型跨层环道待建，见 §1.3.1**）；**但普通 MoA 及其全部变体都在输出级/激活级做组合，受共同失效率 β 封顶**——要突破必须走到权重级：小球先按功能槽解体，在公共槽空间重组对齐，再做符号相消相融，产出**一套新权重**。

### 4.14 S4-P 管道（v82）：**给信息一条带地址的独立通路**

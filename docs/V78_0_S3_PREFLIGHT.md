## ✅ 本代是诊断代（机器裁决 `PREFLIGHT_DIAGNOSED`）

- **D1｜有效秩塌陷的根因 = 少数维主导 + BOS token**：Qwen 深层（top1 维独占 95–97% 方差、top16 token 能量 0.95–0.995）；BERT 全部干净（L0–L4 raw 122.8–159.4）⇒ **Qwen 特有**，不是本仓库实现的产物。修法排序：逐 token L2（3.8→263.7）≈ 去首 token（→282.3）> 逐维标准化（→243.8）≫ 剔 top4 维（→62.5，不够）。
- **D2｜共同成分确实主导，但「去掉它」不是解法**：PC1 占 88.76% 方差、PC2 3.95%，每个槽表示被这 2 个 PC 解释的 R² mean 0.631 / max 1.000；**残差化后合并判据反而更差**（10/16，p=0.4545，中位差 +0.0507）。分槽看：**Q 槽几乎不变**（8/8，p=0.0078，中位差 +0.1078 vs 原始 +0.1074）⇒ Q 槽信号是**槽特异**的；**O 槽掉到 2/8**（p=0.289）⇒ O 槽的「匹配」几乎全是共同成分，**本来就不跨模型携带槽特异信息**。
- **D3｜样本级探针健康，token 级塌陷不影响它**：ag_news 4 类、64 训 / 64 测，Qwen L0 0.219 → L1 0.625 → L2 0.688 → L23 0.703；BERT L0 0.688 ~ L4 0.641；样本级 pooled 有效秩 **47–62**（含 v77 说「塌到个位数」的那几层 L3–L18）。

## ⚠️ 本代订正了 v77 的一条过强推论

v77 的 `falsified` 第 2 条写的是「Qwen 的 hidden state 可直接喂线性探针读语义」→ 证伪，并推论「S3 的探针读数必须控制有效秩，否则会被少数维绑架」。

**D3 实测说明这条推论过强**：

- 「token 级有效秩塌陷」这个**事实**成立（v77 的数字没错）；
- 但「探针会被绑架」**不成立**：样本级 mean-pool 的表示有效秩 47–62、标签准确率 0.61–0.70。massive activation 之所以没伤到探针，是因为它是**与标签无关的常量方向**——它占了方差，但不是信号，线性探针有自由度把它忽略掉。

⇒ **订正后的表述**：token 级有效秩在 Qwen 深层塌到个位数；**跨模型的样本级探针不受影响**；只有当探针单位是 **token 级**时，才必须逐维标准化或去 BOS。

## 📌 基于缺陷的解决方案（S3 预登记口径）

| # | 缺陷 | 归因（v78 实测） | 解决方案 |
|---|---|---|---|
| D-1 | Qwen token 级有效秩塌到 3.8–10.5 | 少数维主导 + BOS token | 探针单位取**样本级 mean-pool** |
| D-2 | B5 功效不足（12/16、p=0.0768） | 共同成分主导错槽基线，但残差化对 Q 槽零影响、对 O 槽是灾难 | **不做残差化**；改为**按槽分设判据 + 扩块数**，主检验换成臂间配对置换 |
| D-3 | O 槽跨模型对应不成立（4/8） | O 槽的「匹配」几乎全来自共同成分 | 首代**只把 Q 槽当跨模型信息流载体**，O 槽预登记为「预期不成立」的反向对照 |
| D-4 | 注入方向在深层不可靠（alignment −0.162） | 残差流不原样携带注入方向 | 判据改用**可读性**（探针 R² 增量），alignment 只作描述性曲线 |
| D-5 | 符号检验的块数瓶颈（n=16 需 ≥13 个正号） | 功效由块数决定 | 块数扩到 ≥32；**开跑前先过功效门槛**，不达标不开跑 |

## 边界（引用本代的一切数字都必须带上）

1. 本代是**诊断代**：不产生任何 P1a/P1b/P2/P3 判据，**不改 v77 的裁决**（仍是 `S1B_FAIL`）⇒ **S3 仍未开跑，A1 整体仍未判定**。
2. D2/D4 的「去掉共同成分后重测」口径是**看到 v77 结果后定的**，属诊断性复测，**不作为 P1b 判据**；S3 若采用，须在新语料/新块上**重新预登记**确认。
3. 共同成分的 PCA 在**全部样本**上估计（无监督变换）；若 S3 采用，须在训练集上估计、测试集上应用。
4. 标签探针只用 128 条（64 训 / 64 测），准确率是**粗读**，不是能力结论。
5. 诊断只覆盖 Qwen/BERT（首代范围）；ViT 只在 v77 B4 里有健康度读数，不进本代诊断。
6. ⚠️ 本代初稿「推荐加 ViT（已健康且能 ×3 块数）」只解除了 ViT 的**层栈健康**限制，**未解除输入同源限制**（ViT 只吃图像）；已按 2026-11-16 拍板更正为「ViT 进首代，但以自跨层臂 + 槽特异性对照参与」。

复现需要真模型权重（约 1.3 GB）与语料缓存，步骤见 SPEC.md §8。

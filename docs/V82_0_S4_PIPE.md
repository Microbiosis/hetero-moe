# V82.0 — S4-P：管道 —— 给信息一条带地址的独立通路

> 本文件是指针。权威规范在
> `research/weight_fusion/v82_s4_pipe/SPEC.md`](../research/weight_fusion/v82_s4_pipe/SPEC.md)

**一句话**：S3 查清了「信息流分不清」的根因 —— 同层内 Q 槽与 O 槽高度可互换（BERT L0/L1 的 R²(a_Q→a_O) = 0.44/0.45），倒进同一个残差流容器必然分不清；本代不再指望信息自发流，改为**显式修管道**：在目标模型的正文**之前**开 K=8 个专属位置，把源信息写进去并让模型把它们当真 token，**按通道编号**区分槽身份 ⇒ 把「分不清」从容器问题变成可证伪的管道问题。

## 机制（预登记，正本见 `SPEC.md` §2）

```text
序列布局   [ 管道 K=8 位 | 正文 120 位 ]      管道必须在正文之前（因果解码器）
管道位置   attention_mask = 1（模型把它们当真 token）
写入点     目标模型第 0 层的输入 hidden_states（forward_pre_hook）
写入内容   Δ_B = (a_s @ P_Aᵀ) @ P_B            共享空间载体，不学任何映射
写入范围   只写管道位置，正文位置一律零增量
强度       逐样本 ||Δ_i||₂ = λ · (正文 token 在第 0 层的 hidden 平均范数)
地址       通道 0 = 管道位 0..3；通道 1 = 管道位 4..7（Q 槽→通道 0，O 槽→通道 1）
```

| 臂 | 管道内容 | 通道 | 作用 |
|---|---|---|---|
| `arm0_pipe_zero` | **管道开、内容为 0** | — | 配对基线（布局与其它臂完全相同） |
| `arm1_slot_Q` | 源第 l 层 **Q 槽**激活 | 通道 0 | 主臂 |
| `arm2_wrong_slot_O` | 源同层 **O 槽**激活 | 通道 1 | 槽特异性对照（按专属通道编号） |
| `arm3_random_dir` | 共享空间内**随机方向** | 通道 0 | 排除「随便什么内容都能被读」 |

## 判据总表

**裁决 `S4PIPE_FAIL`**（退出码 1，契约内）。跑批 1280 行（64 文本块 × 4 臂 × 5 种子）+ 240 条注意力记录，**λ = 1.0**，分 5 批断点续跑约 5.9 ks（本机 CPU）。

| 判据 | 块集合 | 实测 | 结果 |
|---|---|---|:--:|
| **P5a 管道连通** | 12 组 | `arm1−arm0` 中位 **+0.000463**（34/60 正），p = **0.3108**；`arm1−arm3` 中位 **−0.000983**（24/60 正），p = **0.9053** | ❌ |
| **P5b 管道可分（槽）** | 12 组 | `flip` 的 `arm1−arm2` 中位 **+0.002305**（39/60 正），p = **0.0** | ✅ |
| **P5c 贯通（正文可读）** | 64 文本块 | 正文 r2_q 增量中位 **+0.004419**（236/320 正），p = **0.0** | ✅ |
| **P5d 选择性** | 64 文本块 | 非目标槽 r2_o 增量中位 **+0.001921**（250/320 正），p = **0.0** | ❌ |
| **P2′ 深度语义** | 64 文本块 | 同层 **+0.000399** vs 跨层 **+0.004495**，p = **0.9351** | ❌ |
| **P3① 守门** | 960 注入臂行 | 末层扰动 min **0.062012** / max **0.292561**，越界 **0** | ✅ |

**必须成对引用**：①**贯通成立且比 S3 更强**（P5c Δ 中位 +0.004419 vs S3 的 P1a +0.003232，口径不同不可直接比）；②**但信息不是靠「模型注意到管道」过去的**（P5a 块级 p = 0.3108、逐样本 p = 1.0，arm1−arm3 甚至为负）；③**通道寻址只在块级聚合上成立**（P5b 块级 p = 0.0，逐样本 p = 0.787）。 ④**⚠️ 读出端补测推翻了「卡在读出端」**（post_hoc_only，裁决不变）：正文侧内容特异 arm1−arm3 块级中位 **+0.011373**（281/320 正，p = 0.0）、槽特异 arm1−arm2 **+0.002700**（p = 0.0，**仅 BERT→Qwen 成立**）⇒ **容器关与传递关都过了**，剩下的是 **P2′ 深度对应** 与 **P5d 非目标槽普涨**（详见 `SPEC.md` §4.4）。

## 引用本代必须带上

1. **管道机制 ≠ 残差流容器**：写入点在**第 0 层**、只写管道位、正文被截断到 120 位、探针只读正文真实 token —— 与 S3 的「层边界注入」**不可直接比大小**。
2. **arm0 口径不同**：本代 arm0 是「管道开、内容为 0」（管道位**可见**），S3 的 arm0 是「管道不可见」⇒ 两代的 Δ **不可直接比大小**。
3. **注意力只在写入层（第 0 层）测**：深层注意力对内容不稳定（`pipe_probe3` 实测）⇒ P5a/P5b 回答的是「模型在内容进入的那一层读不读、按不按通道读」，**不是**「深层还在不在看管道」。
4. **ViT 臂已整臂撤出**（跑前修订 9）：本代**只覆盖文本两个方向**（BERT↔Qwen），ViT 上的结论外推不了；撤出实测依据见 `SPEC.md` §0.1 修订 9（末层扰动越守门上限 + 通道寻址 5/5 块全负）。
5. **λ* = 1.0** 由写死候选集 {0.5, 1, 2, 3} + 写死选择规则标定得出（`results/calib.json`）；λ=2/3 因安全闸门（末层扰动 > 0.3）不可行。
6. 本代**不训练**任何底座权重、**不产生**任何能力指标、**不产生** A1 的总判定。
7. **载体是线性映射**（共享空间 = 256 维**线性**子空间；唯一非线性是逐样本范数归一化）⇒ 失败**不能**归因于「空间是线性的」：「换非线性」不解决可分性、「扩维度」只补幅度（详见 `SPEC.md` §4.5）。

复现步骤见 `SPEC.md` §6（本机 CPU，分批跑批 + `--aggregate` 汇总）。

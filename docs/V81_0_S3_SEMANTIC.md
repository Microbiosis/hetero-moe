## 引用本代必须带上

1. **「信息流存在」与「没有槽/深度选择性」必须成对引用** —— 只引前者会读成「晶壁系的信息流成立」，只引后者会读成「完全没有信息流」，两个都不对。
2. **绝对 R² 不是穿透量**：arm0 零注入基线最高 **0.400**（共享成分）⇒ 引用 `r2_q` 必须同时给 arm0 与 Δ。
3. **穿透强度与注入幅度在 Qwen 中层是同一件事**（最强处 j ∈ {3,6,12} = 残差流量级爆炸层，放大 ~117 倍）。
4. **P4 未触发**：协议没有因本代强制「A1 转训练版」；A1 激活级语义关卡**未通过**，原因不是效应太小。
5. **ViT 臂的 P1c 不可判定**（train/test 类别不相交 ⇒ 标签探针恒 0），不得当负结果引用。
6. 本代不训练任何底座权重、不产生能力指标、不产生 A1 的总判定。

## 机理（post_hoc_only，不参与裁决）

- **同层内 Q 槽与 O 槽高度可互换**（留出集 R²(a_Q→a_O)：BERT L0/L1 = 0.44/0.45，ViT L0 = 0.55）⇒ 在可互换的 32 个块上 **arm2 反而高于 arm1**（中位 −0.007875）；在不可互换的 52 个块上 **arm1 ≈ arm2**（中位 −0.000185）⇒ 效应来自**跨槽公共成分**。
- **信息天花板**（注入能带走的方差比例）：**BERT 1.000000**（隐层就 256 维 ⇒ 共享空间载体对 BERT 无损）/ ViT 0.3318 / Qwen 0.2882 ⇒ BERT→Qwen 是「源侧零损失」的传输（Δ/r2_project = +0.069396）；Qwen→BERT 输在源侧**且**传输近乎为零。

# A1 设计 — 激活级跨模型跨层信息流（环道）

> **文档 ID**: HMF-A1-DESIGN-1.0
> **日期**: 2026-11-13
> **状态**: 🟢 **S1 已完成并回填**（v76：机制层 PASS；**语义层改走路线 β**）；**S2 已做并回填**（v80：三步链 ⇒ 闸门重跑**六项全过**，裁决 `S2_OPERATOR_READY`；λ\* = 0.03 已重新预登记）；S3–S4 未做 ⇒ **A1 整体未判定**（§10）
> **归属**: weight_fusion 线（v75 之后），正本路线见 [`docs/MAINLINE_ROUTE.md`](MAINLINE_ROUTE.md) §1.3.1 / §1.4 / §4.8
> **一句话**: 让一道信息流在**计算图内部**从模型 A 的第 l 层流到模型 B 的第 j 层，不经过集中的分配网关层。

---

## 0. 这份设计要回答的问题

一句话可证伪形式：

> 在同一条信息流上，把模型 A 第 l 层的**槽 s** 注入模型 B 第 j 层之后，B 的后续层输出里是否**携带了 A 槽 s 的信息**，且这个增益**大于注入错槽/随机方向**时的增益？

这条问题有四个子问，每个都要能单独判：

| 子问 | 对应判据 |
|---|---|
| ① 信息**流过去了**吗？ | P1a：注入后 B 深层输出对 A 槽 s 激活的线性可读性上升 |
| ② 是**槽特异**的流，还是随便什么都能流？ | P1b：匹配槽的增益 > 错槽/随机方向的增益（配对置换） |
| ③ **深度语义**对不对得上？ | P2：同层注入增益 ≥ 跨层注入增益 |
| ④ 注入**没把 B 搞坏**吗？ | P3：输出未崩 + 非目标槽未被污染 |

## 1. 机制翻译：注入算子长什么样

**关键结论（省掉大量新设计）：A1 不需要新的对齐机制，只需要把 v62 已有的 `proj` / `align` 从「顶层聚合」下沉到「层边界」，再补上分段前向与回灌。**

### 1.1 注入的完整形式（逐项写死）

```text
A 第 l 层 hidden  h_A^{l}          ∈ R^{D_A}
  ↓ 槽 s 的权重 (切片里的真实权重)
A 槽 s 激活      a_s^{l} = W_s^A h_A^{l}      ∈ R^{D_A}
  ↓ v62 的槽投影 P_A : D_A → 256（正交）
共享空间槽 token  z = P_A a_s^{l}             ∈ R^{256}
  ↓ v62 的成对对齐 align[s|A→B]（两两 CKA 0.988，可复合、有环路一致性）
对齐后槽 token    z~ = align[s|A→B] z          ∈ R^{256}
  ↓ 映回 B 的隐空间 (P_B 正交 ⇒ 逆即转置)
注入量            Δ_B = P_B^T z~              ∈ R^{D_B}
  ↓ 加性注入 + 残差缩放 λ
B 第 j 层输入    h_B^{j} ← h_B^{j} + λ · Δ_B
```

> ⚠️ **本节的 `align[s|A→B]` 一步已被 v79 实测否掉**（真模型激活上没有任何可用版本：四个候选的留出集 matched−noalign 中位差全 ≤ 0）⇒ **2026-11-17 拍板：保留共享空间载体、去掉对齐这一步**。最终口径见 §13 与 [`docs/S3_PROTOCOL.md`](S3_PROTOCOL.md) §2.3。

**为什么用槽 s 的激活而不是 hidden state**：hidden state 跨架构不可通约（Qwen 896 / BERT 256 / ViT 768，且语义各不相同）；**功能槽（Q/K/V/O）是跨模型跨层可通约的语义单位** ⇒ 这正是「膜必须按槽张成和、而不是一个矩阵」的架构理由，也是 v62 那套槽设计在环道里的真正用途。

### 1.2 三种注入形式的取舍（只选一种进首代）

| 形式 | 定义 | 取舍 |
|---|---|---|
| (a) 加性 + 残差缩放 | `h_B ← h_B + λ·Δ_B` | ✅ **首代选它**：不动 B 原有语义，B 的自身能力大概率不崩，守门指标可测 |
| (b) 替换 | `h_B ← Δ_B` | ❌ 直接摧毁 B 的信息，且在无训练条件下几乎必然崩 |
| (c) 门控注入 | `h_B ← h_B + g·Δ_B`，g 由局部门给出 | ⏭ **推到 A2**：门不训练 ⇒ 分不清「门选错」与「信息本身没用」；v62.0/1/2 的 router 死代码就是这么毁掉三组端到端数字的 |

### 1.3 局部门：首代**不设门**，但接口先留

- 首代用**固定全槽注入**（λ 固定，不学），把「注入本身有没有用」测清楚。
- 注入器做成可插拔接口：`inject(h_B^{j}, z~, λ, edge) -> h_B^{j}`，首代只实现 `Identity`（=不注入）与 `AddSlot` 两种。
- **门的分数、门的位置、梯度归属全部推到 A2**（训练版）—— 见 §6。

## 2. 最小配置（一次只动一个变量）

| 维度 | 首代选定 | 理由 |
|---|---|---|
| 模型对 | **Qwen ↔ BERT**（双向各测） | 同为文本、序列长同为 128 ⇒ 不引入模态/序列对齐变量；ViT↔BERT 留到机制成立后（**且 ViT 另有硬缺陷，见 §10**） |
| 可比槽 | **Q、O** 两个 | ⚠️ Qwen 的 K/V 是 GQA `[128,896]` 非方阵，与 v75 同一口径被排除 ⇒ Qwen↔BERT 只有 Q/O 是同形状可比槽（FFN 复合算子只含线性部分，噪声大，首代不用） |
| 层对 | 同层 `l=j=2` 为主 + 跨层 `l=1→j=3` 为辅 | 同层歧义最小；跨层专门测「深度语义错配」这条硬骨头 |
| 注入方向 | 双向（Qwen→BERT、BERT→Qwen） | 避免单向偶然 |
| 随机种子 | 5（nuisance，各种子观测并入同一块） | 沿用 v75 的统计口径 |

**层与槽的语义坐标问题（§1.4 的硬骨头之一）**：首代用「同层号 + 同槽名」作为 (m,l)→功能槽 的映射近似，并**显式把它登记为已知近似**。若 P2（同层 ≥ 跨层）成立，说明这个近似是必要的修正；若不成立，说明「深度」不是瓶颈，映射规则要重做。

## 3. 离线可行性：两条路，先便宜后保真

### 3.1 路线 α：切片重建逐层前向（**首代走这条**）

原料：`redmingwei/backbone-slices`（v75 已用同一份原料复现 v62 §2 谱统计到 5.2e-8 ⇒ 口径已验证）。

- 切片含 layer0–3 × 6 槽（Q/K/V/O/expand/contract）的真实权重 ⇒ 可重建**近似层栈**：attention 用 Q/K/V/O 走标准注意力，FFN 用 `contract∘expand` 复合。
- 由此得到逐层 hidden state ⇒ 能在第 j 层边界做注入，再把 B 的第 j+1… 层接着跑完（**回灌**）。
- 已知近似（必须随数字引用）：**SwiGLU 的 gate 路缺失**（FFN 只剩线性部分）、norm/残差形式简化、无 position embedding。⇒ 结论只对「近似模型」成立。
- ⚠️ **S1 实测出的能力边界（本路线只承载机制层判据）**：随机输入下任一槽的输出都是同一个随机输入的线性函数 ⇒ 任意两槽彼此线性可预测、槽身份不可分辨 ⇒ **P1a/P1b/P2/P3 属语义层，不能在路线 α 上执行**（见 §10）。

### 3.2 路线 β：真 HF 逐层驱动（复现用）

- 用 `output_hidden_states=True` 取真逐层状态，注入在真前向里做（逐层调用 `model.layers[i]`，续接 mask / position embedding / cache）。
- 代价：三个底座权重下载（约 1.6 GB）+ 逐层驱动工程。
- **定位（已改）**：S1 证伪了「路线 α 能承载 P1/P2」这一前提 ⇒ 路线 β 不再只是「复现用」，而是**语义层判据（P1a/P1b/P2/P3）的唯一可行路线**。

### 3.3 为什么不能直接用现成缓存

`redmingwei/hetero-moe-cache` 里每个模型只有**一个** hidden state（最终层），**没有逐层** ⇒ 任何「第 l 层注入、第 j 层继续」的设计都绕不开重建或真跑。

## 4. 三臂与指标

### 4.1 四臂（arm3 是可选加强）

| 臂 | 注入内容 | 作用 |
|---|---|---|
| `arm0_no_inject` | 无 | 基线：B 自己跑到底 |
| `arm1_slot_inject` | A 第 l 层**槽 s** 的激活（对齐后加性注入） | **主臂** |
| `arm2_wrong_slot` | A 第 l 层**另一个槽 s′** 的激活（强度同、语义错） | 槽特异性强对照 |
| `arm3_random_dir` | 与 `Δ_B` **同范数**的随机方向 | 排除「任意扰动都能涨」 |

### 4.2 主指标：信息穿透的可读性

**探针 R²**：用 A 第 l 层槽 s 的激活 `a_s^{l}`（对每个样本一个标量或低维向量）作预测目标，用 B 第 j+k 层的 hidden state 作特征，训练**线性探针**，测 R²。

- `arm0` 的 R² = 基线（不注入时，B 深层本来就可能含有 A 的信息吗？——同一批样本、同一个 A，若 A、B 高度相关则基线可能不低，**这正是要看清的**）。
- `arm1` 的 R² 相对 `arm0` 的**增量** = 注入带来的额外可读性。
- `arm2` / `arm3` 的增量 = 平凡解释的基线。

**选择性守门**：注入槽 s 后，**其他槽** s″ 的可读性不应上升（否则是整体扰动把所有探针都抬起来 ⇒ 平凡解释）。

### 4.3 守门指标：B 没被搞坏

- **输出未崩**：注入后 B 最终输出与 `arm0` 的相对扰动 `||Δ||/||y||` 在阈值内。
- **能力未降**（若手上有标签）：B 在注入前后的自身可分性不下降（**v75 的诚实性原则**：没有端到端数字时不要声称能力变化）。

## 5. 判据与预注册预期（跑之前写死）

| 判据 | 阈值 | 含义 |
|---|---|---|
| **P1a 穿透** | `arm1 − arm0` 的目标槽 R² 增量，块内分层置换 **p < α** | 信息确实流过去了 |
| **P1b 槽特异** | `arm1 − arm2`、`arm1 − arm3` 的配对置换 **p < α** | 不是随便什么都能流 |
| **P2 深度语义** | 同层注入增量 ≥ 跨层注入增量 | 深度错配这条硬骨头确实存在 |
| **P3 守门** | 输出未崩 且 非目标槽可读性无普涨 | 注入不破坏 B |
| **P4 否决** | 若 `arm1 ≈ arm0` | **离线前向下无可测效应 ⇒ A1 必须转训练版**，不得以「训练后就好了」搪塞 |

- **执行路线（已改）**：P1a/P1b/P2/P3 属语义层判据 → **在路线 β 上执行**（见 §10）；路线 α 只承担机制层自检（C1–C5）与 S2 注入算子的调试。
- **α 预登记为 0.01**（沿用 v75 的 `P_G2`），事后不得改阈；`arm1 − arm2` 若落在 0.05 上下，**照样不放行**（v75 的同款纪律）。
- 统计单位 = **(模型对 × 层对 × 槽) 块**；种子是 nuisance；块内分层置换 + 臂间配对置换（口径沿用 v75 的 `strat_perm` / `paired_perm`）。
- **P4 是硬否决条款**：它承认「前向可能测不出」，这与 v75 的 `G2a_INCONCLUSIVE` 是同一种诚实。

## 6. 梯度归属（A2 议题，首代不碰但先定原则）

离线前向**没有梯度** ⇒ 首代不回答「能不能训出来」。但原则先写死，免得训练版临场决定：

| 方案 | 规则 | 评价 |
|---|---|---|
| 共享梯度 | 注入边不截断，梯度同时回传 A 与 B | ⚠️ A 的浅层会被 B 的深层目标拉动 ⇒ 跨模型梯度冲突，且「谁受益谁负责」不清 |
| 局部梯度 | A、B 各算各的 loss（deep supervision） | ✅ 可解释、可归责，但可能与共享目标不一致 |
| **截断（推荐）** | 注入输出处 `detach` ⇒ A 只被 A 自己的 loss 更新，B 的 loss 训练 B 侧注入算子 | ✅ 谁受益谁被优化；也与 v62「router 必须真被优化」的精神一致 |

⇒ 训练版默认 **detach 于 A 的注入输出**，且 A、B 各自带一份辅助 loss。

## 7. 已知边界（引用本设计的一切数字都必须带上）

1. 路线 α 是**近似重建前向**（缺 SwiGLU gate 路、norm/残差简化、无 position embedding）⇒ 结论只对近似模型成立。
2. **离线前向无梯度** ⇒ A1 首代只回答「信息有没有流过去、是不是槽特异」，**不回答**「能不能训出来」。
3. 注入**不改变任何底座权重** ⇒ 与权重级 G1/G2 正交，不构成对权重级结论的支持或反驳。
4. 首代只覆盖 **Qwen↔BERT 的 Q/O 槽** ⇒ ViT 参与、FFN 槽、K/V 槽全部未测（ViT 另有硬缺陷，§10）。
5. 「同层号=同深度语义」是**已知近似**，由 P2 负责检验。

## 9. 这个实验可能给出的三个答案（都要能接住）

1. **P1 成立**（信息流过去且槽特异）⇒ 环道在激活级可行，主线得到第一个「模型间真正互通」的证据 ⇒ 进 A2（门 + 梯度归属 + 训练）。
2. **P1 不成立但 P3 成立**（流过去了、但不是槽特异）⇒ 与 v75 的 G2 结论同源：**槽身份本身没被搬运** ⇒ 主线的真正瓶颈是「槽对应关系」，不是信息流机制 ⇒ 回头攻槽定义/对齐，而不是继续加机制。
3. **P1/P3 都不成立**（离线前向测不出任何效应）⇒ 转训练版（A2），并把「离线探针测不出」如实登记（与 v75 的 INCONCLUSIVE 同款诚实）。

## 10. S1 回填：两条设计前提被证伪（2026-11-13）

S1 已跑完（实现与数字正本：[`research/weight_fusion/v76_cross_layer_flow/`](../research/weight_fusion/v76_cross_layer_flow/)，parent = 75.0）。**结论两面**：

| 面 | 结论 |
|---|---|
| ✅ **机制层** | 五项机械自检全过 ⇒ 「层边界打断 → 注入 → 续跑」在计算图层面成立 |
| ❌ **语义层** | 路线 α 测不了语义层 ⇒ 本设计的 P1a/P1b/P2/P3 **改在路线 β 执行** |

**证伪一：路线 α 测不了语义层判据。** 随机输入下任一槽的输出都是同一个随机输入的线性函数 ⇒ 任意两槽彼此线性可预测、槽身份不可分辨 ⇒ 原设计把 P1a/P1b/P2/P3 放在路线 α 是错的。**处置**：语义层归路线 β（真模型逐层驱动 + 真输入 + 标签）；路线 α 只承担机制层自检与 S2 注入算子的调试。

**证伪二：ViT 不能与 Qwen/BERT 同等入局。** 首层残差膨胀、有效秩塌缩，根因是切片缺 norm gain / embedding 尺度、非仿射 RMSNorm 压不住 FFN 分支量级。**处置**：ViT 修好前不纳入首代范围（候选：按分支量级做残差缩放 / 补 embedding 尺度 / 直接走路线 β）。

⇒ **A1 整体仍未判定**：S2（注入算子下沉）、S3（语义判据）、S4（真模型复现）三项未做。S1 只证明「路修得通」，不证明「信息有用」。

## 11. 路线 β 的回填（v77，2026-11-13）

S1β 已在**真 HF 预训练底座**上跑完（实现与数字正本：[`research/weight_fusion/v77_true_model_flow/`](../research/weight_fusion/v77_true_model_flow/)，parent = 76.0）。

| 面 | 结论 |
|---|---|
| ✅ **机制层（B1–B4）** | 全过，且 B1/B2 是**位级**证据：切片权重与真模型参数 72/72 块**逐位相同**；零注入的「打断→续跑」与原前向逐层**位级相同** ⇒ 路线 β 与路线 α 用的是同一批权重 |
| ⚠️ **对照测量（B5）** | 未过但方向为正（占优 12/16、中位差 +0.0738）⇒ **不可判定（功效不足）**，不是否证；阈值未放宽 |

**本设计 §10 的两条证伪，v77 正面确证了它们的后果**：路线 α 无信号（11/24、中位差 −0.00008）vs 路线 β 有信号（12/16、+0.0738）⇒ **语义层确实必须走真模型真输入**；另外 ViT 在真模型上**没有**路线 α 的那个缺陷 ⇒ v76 的根因假设（切片缺 norm gain / embedding 尺度）成立。

**S3 开跑前必须先做三件事**（v77 给出）：

1. **判据粒度对齐机制粒度**：事后拆到槽看，Q 槽 8/8 占优（p=0.0078）、O 槽 4/8 ⇒ 本设计 §5 把 P1b 定义成「匹配槽 vs 错槽/随机」的合并判据，粒度太粗；S3 须按槽分设并**重新预登记**（不得拿 v77 这 16 块既当判据集又当确认集）。
2. **先做功效设计**：符号检验的瓶颈是**块数**（n=16 需 ≥13 个正号）⇒ 扩块数（更多层对/槽/模型对），而不是只加样本。

## 16. S4-P 的回填（v82，2026-11-18）：**管道方案 —— 给信息一条有地址的独立通路**

S3（§15）查清了「信息流分不清」的**根因**：同层内 Q 槽与 O 槽**高度可互换**（BERT L0/L1 的 R²(a_Q→a_O) = 0.44/0.45）⇒ **两个内容高度重叠的东西倒进同一个残差流容器，必然分不清**。这是**容器**问题，不是探针不灵。

所以本代不再指望信息自发流，改为**显式修管道**（用户指令原话：「信息流分不清，你就做导流啊，他不知道往哪流你不会做管道吗」）：

| 项 | 机制 |
|---|---|
| 序列布局 | `[ 管道 K=8 位 | 正文 (SEQ−K)=120 位 ]` —— 管道必须在正文**之前**（因果解码器只能注意更早的位置） |
| 管道位 | `attention_mask = 1`（模型把它们当真 token，自己算 key/value） |
| 写入点 | 目标模型**第 0 层**的输入 `hidden_states`（forward_pre_hook），**只写管道位** |
| 写入内容 | `Δ_B = (a_s @ P_Aᵀ) @ P_B` —— 共享空间载体，**不学任何映射**（沿用 v80/v81 口径） |
| 强度 | 逐样本 `||Δ_i||₂ = λ · (该样本正文 token 在第 0 层的 hidden 平均范数)` |
| **地址** | **按专属通道编号**：通道 0 = 管道位 0..3，通道 1 = 管道位 4..7；Q 槽 → 通道 0，O 槽 → 通道 1 |

**四臂**（arm0 与其它臂**布局完全相同**，是干净的配对基线）：

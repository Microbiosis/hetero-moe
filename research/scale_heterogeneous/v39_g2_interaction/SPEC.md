# V39.0 γ2 真实数据跨模态 — 加性 vs 交互融合框架 (架构修正)

> **版本**: v39.0 | **状态**: ✅ Verified (架构修正已实测确认; 原快照 v9.0-γ2)
> **归属路线**: 大模型容器 + 异质入口 (外部快照 v9.0-γ2 → 本项目 v39.0)
> **前置**: v38.0-α (γ, 其"三臂打平"结论经本版判定为**架构人工产物**)
> **核心修正**: 融合头从**加性** `Linear(h_base + P(c))` 改为**交互** `MLP(concat[h_base, P(c)])`
> **复现命令**: `bash run.sh v39` (默认 adult+concat)

---

## 1. V38 (γ) 的架构缺陷 — 本版修正动机

V38 (γ) 的核心结论是"**在真实复杂数据上 C/D/E 三臂打平 (~0.76), 自训练>被动不成立**".
V39 (γ2) 判定: 该结论是**加性融合头的表达力上限造成的伪边界**, 不是任务的真实性质.

### 1.1 为什么加性头不能解 XOR

V38 的框架:
```
logits = head(h_base + P(c))        head = nn.Linear(D_BIG, N_CLS)
       = W·h_base + W·P(c) + b      ← 两侧贡献**线性求和**
```

而 XOR 标签 `y = a XOR b` (a 只在文本侧, b 只在表格侧) **不可加性分解**:
不存在一元函数 f,g 使 `a XOR b = f(a) + g(b)`. 因此该框架下**任何入口**都
无法把任务做到天花板以上, 所有臂被压在同一个退化平台.

### 1.2 构造性验证 (已锁定为单元测试)

`tests/test_v39_g2_interaction.py` 用构造 XOR 数据直接对比两框架:

| 融合头 | XOR 准确率 | 说明 |
|---|---|---|
| `add` (v38 旧框架) | **0.543** | ≈ 随机, 数学上无法表达 XOR |
| `concat` (v39 γ2 框架) | **1.000** | 完全解出 |

### 1.3 修正后的框架

```
logits = head(concat[h_base, P(c)])     head = MLP(D_BIG*2 → 128 → GELU → N_CLS)
```
concat 保留两侧独立维度, 经 MLP 可表达跨模态**交互** → 能解 XOR.

## 2. 实验设置

| 参数 | 值 |
|---|---|
| 数据集 | `adult` (UCI Adult, 人口普查) · `shoppers` (UCI Online Shoppers, 电商会话) |
| 融合模式 | `add` (v38 旧) · `concat` (v39 交互) |
| 入口 | TabLDM 被动中间表征 (α2) / E 自训练 (β) / E 蒸馏初始化 (先验+自训练) |
| N / 留出 | 512 / 384:128 |
| STEPS | 500 |
| seeds | 5 |
| 容器 | MSA-4B 浅层 (1 层, D=2560) |

**跨模态必需性**: 两个数据集都用人工 XOR 标签, 两条件分居文本侧/表格侧:
- Adult: `y = (职业∈高薪 [文本侧]) XOR (工时≥45 [表格侧])`
- Shoppers: `y = (VisitorType==New_Visitor [文本侧]) XOR (ProductRelated≥18 [表格侧])`
两者均做了表格侧解耦 (非条件列样本间随机置换) 与四格均衡采样.

## 3. 实验结果 (本环境实测, 5 seeds × 4 组合)

### 3.1 主表 (test_acc 均值)

| 数据集 / 融合 | A 无入口 | B 随机 | C 被动TabLDM | D 自训练 | E 先验+自训练 |
|---|---|---|---|---|---|
| **adult / add** (复现 v38) | 0.753 | 0.545 | 0.781 | 0.762 | 0.766 |
| **adult / concat** (γ2) | 0.741 | 0.536 | **0.997** | **0.994** | **0.988** |
| **shoppers / add** | 0.539 | 0.491 | 0.561 | 0.500 | 0.494 |
| **shoppers / concat** | 0.586 | 0.478 | **0.881** | **0.925** | **0.912** |

### 3.2 关键量: 换头带来的抬升 (concat − add)

| 数据集 | A 无入口 | B 随机 | C 被动 | D 自训练 | E 先验+自 |
|---|---|---|---|---|---|
| adult | −0.012 | −0.009 | **+0.216** | **+0.232** | **+0.222** |
| shoppers | +0.047 | −0.013 | **+0.320** | **+0.425** | **+0.418** |

**这是"架构天花板"的指纹**: 换头只抬升**携带真实信息**的臂 (C/D/E, +0.22~+0.43),
而对**无信息**的臂 (A 无入口 / B 随机) 几乎无影响 (−0.01~+0.05) ——
因为交互头需要两路信号才能产生交互, 没有入口就无从交互.

### 3.3 与 v38 (γ) 公布数字的对照

| 臂 | v38 规范 (γ, 500步) | 本环境 adult/add | 一致性 |
|---|---|---|---|
| A | 0.750 | 0.753 | ✅ |
| B | 0.545 | 0.545 | ✅ |
| C | 0.767 | 0.781 | ✅ |
| D | 0.764 | 0.762 | ✅ |
| E | 0.755 | 0.766 | ✅ |

`add` 模式**逐臂复现了 γ 的数字** → 证明本实现的旧框架与 v38 等价, 差异只来自融合头.

## 4. 修正后的结论

### 4.1 v38 的"三臂打平"是架构伪边界 (核心修正)

γ 报告的 "C/D/E 打平 0.755-0.767" 并非"三种入口等价"的证据, 而是
**三种入口都被同一个表达力天花板压住**的证据. 换成交互头后, 同样的入口、同样的数据、
同样的步数, C/D/E 从 ~0.77 跃升到 **0.99 (adult) / 0.88-0.93 (shoppers)**.

### 4.2 入口必需性大幅增强 (修正后更强)

| | add (旧) | concat (新) |
|---|---|---|
| adult: A 无入口 vs C/D/E | 0.753 vs ~0.77 (差 0.02, 淹没) | 0.741 vs ~0.99 (**差 0.25**) |
| shoppers: A 无入口 vs C/D/E | 0.539 vs ~0.52 (无差) | 0.586 vs ~0.90 (**差 0.32**) |

在有效框架下, **"注入真实信息 vs 不注入/注入噪声"的差距变得巨大且无歧义**:
- A (无入口) 与 B (随机入口) 在 concat 下仍接近随机 → 无信息的注入无效
- C/D/E 全部接近解出 → 有信息的注入是跨模态任务的前提

### 4.3 "自训练 > 被动"仍不成立, 但理由变了 (重要)

| 数据集 | C 被动 | D 自训练 | D 胜 C | 解读 |
|---|---|---|---|---|
| adult | 0.997 | 0.994 | 1/5 | **天花板饱和**, 无区分空间 |
| shoppers | 0.881 | 0.925 | 2/5 | D 名义更高, 但胜率不显著 (噪声内) |

修正后的解释 (比 γ 的"边际增益被噪声淹没"更准确):
**一旦有了真实入口且融合头足以表达任务, 任务就饱和到接近天花板, 入口的"获取方式"
(C 被动 / D 自训练 / E 先验+自训练) 不再产生可区分的差异。**

即: v37 (β) 的"自训练 > 被动"结论**只在任务未饱和、且表征质量是瓶颈时**成立
(合成符号规则, 被动表征只有 0.56-0.65); 当预训练先验已足够好 (真实数据),
自训练没有额外空间. **结论方向与 γ 相同, 但证据基础从"伪边界"替换为"天花板饱和"**.

---

## 5. 诚实声明与边界

1. **修正针对架构, 不针对数据**: 两个数据集的 XOR 标签仍是人工构造的 (用于建立"必需性"),
   非数据集原生任务.
2. **shoppers 的 D>C 不显著**: 2/5 胜率, 不能宣称自训练更优; 结论是"打平".
3. **adult 的 concat 接近 100%**: C=0.997 意味着任务在该框架下几乎被解出,
   此时任何臂间比较都失去分辨力 (这是"饱和", 不是"等价").
4. **容器仍为浅层**: MSA-4B 只加载 1 层 (~1GB), 未体现 4B 深层语义.
5. **A 臂偏高 (adult 0.74)**: 文本侧仍有边际泄漏 (教育/婚姻等与工时相关),
   严格零泄漏需切断所有相关类别字段. 但在 concat 下 A 与 C/D/E 差距已足够大 (0.25+).
6. **单侧天花板数字 (0.52/0.68/0.84) 来自 v38 (γ) 的旧框架**, 在交互框架下未重测;
   本版只用五臂对照, 不依赖该组数字.

# V37.0 β 自训练预测编码入口规范

> **版本**: v37.0 | **状态**: ✅ Verified (原快照 v9.0-β)
> **归属路线**: 大模型容器 + 异质入口 (外部快照 v9.0-β → 本项目 v37.0)
> **前置**: v36.0 (α2 修复后的逐样本入口基线)
> **核心原理**: 入口编码器 E 参与端到端梯度, 唯一监督 = 容器对目标的预测误差
> **实验结果**: 5/5 PASS, β=0.781 vs α2=0.719 (seed 0 本环境复现)
> **复现命令**: `bash run.sh v37`

---

## 1. 相对 v36 的进步

| | v36 (α2 被动入口) | v37 (β 自训练入口) |
|---|---|---|
| 表征来源 | TabLDM `icl_predictor` 输入中间量, **取一次即冻结** | 入口编码器 E(x_table), **参与梯度** |
| 是否为注入任务优化 | 否 (预训练任务的副产物) | 是 (唯一训练信号 = 容器对目标的预测误差) |
| 语义 | "捡现成的表征" | **预测编码**: E 必须自己发现"哪些表格维度携带类别信息" |

β 才是真正的"感官入口" — 生物感官皮层在发育中学会编码对生存相关的刺激, 而非被动转发所有信号.

---

## 2. 预测编码闭环设计

```
容器 h_base = MSA-4B 浅层 (随机 token 文本, 与表格无关, 预计算一次)   [N, 2560]
入口 E: x_table → c        (MLP 6→256→512, 可训练)               ← β 核心: 这里学
注入 P: c → [N, 2560]       (Linear, 可训练)                      
头  : h → logits           (Linear 2560→10)
损失: CE(h_logits, y_table) 反传到 E+P+头; h_base 固定
```

**工程红利**: 容器只前向一次 (预计算 h_base), 全部训练在 2560 维注入空间完成, 无需每步 4B 前向.

---

## 3. 四臂对照 (同结构同参数量, 只差入口信息来源)

| 臂 | 入口 | 可训练 | 语义 |
|---|---|---|---|
| A 无入口 | c = 0 | 头 | 纯容器基线 |
| B 随机入口 | c = randn 冻结 | P+头 | 容量对照 (同结构, 只差信息内容) |
| C 被动入口 | c = TabLDM 中间表征 冻结 | P+头 | **α2 对照** |
| D 自训练入口 | c = E(x_table) | **E+P+头** | **β 核心** |

任务: 表格类别 = 前三维符号模式 (10类); 文本为随机 token, 与表格**完全无关** → 入口信息为任务所必需.

评估: 96/32 留出集准确率 + k-NN leave-one-out 无参数佐证.

---

## 4. 实验结果 (5 seeds × 3 组配置)

| 配置 | β (自训练) | C (α2 被动) | B 随机 | A 无入口 | β 胜 α2 |
|---|---|---|---|---|---|
| 300步 / split-1234 | **0.781** | 0.650 | 0.081 | 0.206 | 5/5 ✅ |
| 300步 / split-999 | **0.781** | 0.631 | 0.100 | 0.106 | 5/5 ✅ |
| 500步 / split-4242 | **0.762** | 0.556 | 0.075 | 0.106 | 5/5 ✅ |

k-NN 佐证与留出集准确率一致 (β ≈ 0.80, α2 ≈ 0.56).

**层级关系**: β(自训练) > α2(被动) > 无入口 ≈ 随机.

- β 大幅领先: E 直接学到符号规则 (符号阈值对 MLP 是可学的), 注入携带类别信息
- α2 中等: TabLDM 预训练表征**部分**编码符号结构 (对符号阈值有残余敏感性), 但非为任务优化
- 随机 < 无入口: 注入**无信息噪声**反而稀释 h_base 可用结构 → 证实"注入无信息会干扰", 与 v9.0-α 负结果方向一致

---

## 5. 结论

1. **入口参与梯度是关键**: 被动取中间量 (α2) 只能利用表征中恰好存在的任务相关信息; 自训练 (β) 让编码器主动学到任务相关编码
2. **预测编码语义成立**: 编码器的唯一监督是下游预测误差, 独立发现了符号规则
3. **结论稳健**: 3 组配置 (2 种步数 × 3 种 split) 全部 5/5

---

## 6. 诚实声明 (局限)

1. **容器为浅层**: MSA-4B 只加载 1 层 (~1GB), 未体现 4B 深层语义能力
2. **任务为合成规则**: 类别 = 符号模式, 可被 MLP 轻松学到; 真实业务表格的信息结构更复杂
3. **文本随机化**: 容器输入是随机 token, 排除了文本-表格关联, 凸显入口贡献, 但也使 A 臂基线偏低
4. **未跨架构**: 入口仅 TabLDM 表格类型, 未同时验证 embedding/reranker 文本入口的自训练
5. **容器固定**: h_base 不微调, 注入是唯一信息通道 (这是实验设计意图, 但限制了容器侧协同适应)

**γ 边界**: v37 在合成规则上成立, 在 v38 (真实 Adult XOR) 上**不显著** — 见 V38_0_SPEC.md.

## 1. 核心命题

**命题 V34**: 在显式路由(意识层)之外, 加一个"表层意识休息间隙激活"的 DMN 联想层,
做跨专家×跨时刻×跨模态的创造性联想, 产生涌现表征 r (≠ 任何输入加权和), 经双管
注入(先验铺垫 + 路由调制)下一步意识层, 使融合增益**超过 v33 纯线性路由选择**。

即 **"灵光一现"(联想) > "理性选择"(路由)**。

---

## 2. 脑科学依据

| 脑科学现象 | 机制 | 映射 |
|---|---|---|
| DMN 间隙激活 | 表层意识休息时立刻接管, 不依赖固定时段 | 每步意识处理后穿插一次联想 |
| 创造性联想 | 跨域远距离关联, 产生涌现新信息 | 跨专家×跨时刻 cross-attention |
| 情景记忆回放 | NREM/REM 回放历史经验 | memory bank 存历史全专家摘要 |
| 突触稳态 (SHY) | 慢变累积, 保留重要削弱无关 | 慢变状态 C ← C + η·r |
| 直觉影响判断 | 潜意识铺垫影响意识决策 | 双管注入: prior + 路由调制 |

## 3. 数学定义

```
符号: a_m^t = 第 t 步专家 m 激活, M = 专家数, W = 时刻窗口

① 意识层 (TPN, 快, 已有 v33):
   x_m → P_m投影 → 路由选专家 → SwiGLU → 输出, 各专家激活 a_m^t

② Memory Bank (情景记忆, 滑动窗口 W):
   ℳ_t = { a_m^τ | m=1..M, τ=t-W..t }   (跨专家×跨时刻; 结构支持跨模态)

③ DMN 联想 (慢, 每步意识后穿插, 有主导):
   Q  = a_big^t         (大专家当前时刻激活, 主导)
   KV = ℳ_t             (全部历史全专家, 被联想)
   r^t = CrossAttn(Q, KV) → 涌现联想表征 (非线性跨域组合, ≠ Σa_m)
   ★ r 参与梯度: 联想权重 (q/k/v/o_proj) 通过 loss 学习

④ 慢变状态 C (突触稳态累积, buffer 记录):
   C ← C + η·r^t

⑤ 双管注入下一步意识层 (用当前联想 r):
   先验铺垫:  x' = x + λ·r                    (prior)
   路由调制:  z' = z + μ·g(r)  g: D→M         (直觉影响选择)
```

## 3b. v34c:C 接进前向路径(2026-10-10 新增,负结果)

### 问题

原 v34 的 `C` 是**只写不读的 buffer**。`dmn.py:update_C` 每步写 `C ← C + η·r`,
但前向路径只用 `r`,`C` 全仓只有测试读它 —— SPEC §2 脑科学表里
"突触稳态 (SHY): 慢变累积 / 保留重要削弱无关" 这条机制**从未真正生效**。

### 接法

新增 `DMNSubconscious.inject()`,`FusionLayer` 本身不改:

```
Ĉ  = (C / (‖C‖ + ε)) · ‖r‖        慢变累积态的方向, 幅度对齐 r
r_eff = r − Ĉ                       双管注入改用 r_eff
```

三条性质:
- **完美退化**: `C=0 ⇒ Ĉ=0 ⇒ r_eff = r`,与原 v34 逐元素一致
- **数值稳定**: `C` 无界累积,但幅度由 `‖r‖` 归一,不会淹没 `r`
- **纯前向门控**: `Ĉ` 经 `C/‖C‖` 与 `r.detach().norm()` 两条非可微路径构成,
  对 `r` 完全不可微 —— 稳态只改**前向数值**,梯度场与未接 C 时逐元素相同,
  模型无法通过操纵 `‖r‖` 绕过门控

### 结果(3 臂同初始化 × 5 seeds)

**以下为修复广播错配后的复测值(2026-10-10),取代此前受 bug 影响的数字。**

| 指标 | v33 | v34 | **v34c** |
|---|---:|---:|---:|
| 相对 v33 融合损失降低(均值) | — | **+6.8%** | **−0.7%** |
| 优于 v33 的种子 | — | **5/5** | 4/5 |
| 优于 v34 的种子 | — | — | **0/5** |

> **C 接前向带来的净效应: −7.49 个百分点。**

### 裁决:负结果

把 C 接进前向后,v34c 在 **5/5 个种子上都不如 v34**,退化到 v33 的水平,
其中 3/5 甚至略差于 v33。突触稳态门控**没有增益,它抵消掉了 DMN 联想本身**。

### 机制解释

`C = Σ η·r_τ` 累积的是联想方向的历史平均。但 runner 里每一步的 `r` 由
**同一个固定输入**驱动:

```python
big_summ = F.linear(h_big.mean(dim=(0, 1)), layer.P_m[0])   # 一个 seed 内恒定
r_inj = dmn.associate(big_summ)
```

于是 `r` 几乎不随步变化,`C` 的方向与 `r` 高度重合 ⇒ `Ĉ ≈ r` ⇒ 注入被自身抵消。
单元测试 `test_inject_subtracts_accumulated_direction` 直接观察到同向时
**1.0000 → 0.0000 的完全抵消**。

> **C 与 r 同源, 因此 C 只是 r 的低通版本, 不携带独立信息 ——
> 「抑制已累积的部分」退化为「抑制自己」。**

### 设计教训

要让慢变状态携带真正独立的信息,**它的驱动信号必须与被门控的信号不同源**。
这是同族教训的第 4 种形态: 机制层看似接通(v34c),却因信息冗余而空转 ——
与 v35 的 mean-pool 塌缩、v36 的折回正值,属同一类别(接口接上了,信息没接上)。

若要重试,合理方向是让 `C` 由**独立信号**驱动(如专家间差异、跨模态残差、
或跨 seed 的历史),而不是当前步的 `r` 的累积。

## 4. 与 v33 的区别

## 7. 关键发现

### 7.1 联想 > 线性路由
v34 相对 v33 融合损失降低 +6.8% (全部为正), 证明跨专家×跨时刻创造性联想的涌现 r
确实提升了融合, 超过 v33 纯线性路由选择。**"灵光一现" > "理性选择"** 成立。

### 7.2 增益下限提升
v34 增益 vs 单大范围 [+23.9%, +28.0%], 下限 23.9% > v33 的 22.4%。
DMN 联想不仅提升均值, 还提升了最差情况 (更稳健)。

### 7.3 联想权重可学习是关键
r 参与梯度 (q/k/v/o_proj 通过 loss 学习), 联想不是随机 cross-attention,
而是学到了"哪些历史专家表征值得联想"。

## 8. 诚实审查与边界

### 已验证
- ✅ DMN 联想权重可学习 (r 参与梯度)
- ✅ 跨专家×跨时刻联想 (memory bank 回放)
- ✅ 大专家主导 (Q=a_big^t)
- ✅ 双管注入 (先验 + 路由调制)
- ✅ 5/5 v34 < v33

### 简化与局限
1. **跨模态**: memory bank 结构支持跨模态, 当前配置专家同模态(文本),
   跨模态实验待 TabLDM(表格)接入。
2. **外挂式**: DMN 当前是外挂在融合层旁的模块, 未嵌入大模型架构内部。
   (用户提出的"大模型作为容器容纳小模型自训练"是更深方向, 见 v35)
3. **联想频率**: 每步联想一次 (呼吸式), 非"表层真正空闲才联想"。
4. **慢变 C**: 当前 C 仅记录累积, 未直接注入 (注入用当前 r)。C 的回注作用待深化。

### 真实边界 (永久)
- CPU 4 核/14GB ARM, 无 GPU — MSA-4B 浅层加载 (1层)

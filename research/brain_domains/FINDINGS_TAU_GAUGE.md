# τ 的规范依赖性：诊断与修正

> 2026-10-19 · exp49 / exp50 / exp51 / exp52
>
> **结论**：exp39–43 用的 τ 估计量是基依赖的。在头皮 EEG 上偏差 6%，结论不变；
> 在 20 ms spike 数据上偏差 39 倍，量到的是噪声底，原来的 τ 无效。

---

## 一、问题

旧流程（exp39、exp40、exp42、exp43 四处相同）：

```python
U, S, _ = np.linalg.svd(Zc, full_matrices=False)
P = U[:, :d] * S[:d]                                   # 前 d 个主成分得分
a = np.median(acf_fft(P, max_lag), axis=1)             # ← 逐成分 ACF 取中位数
tau = curve_fit(exp_decay, lags, a)
```

两步都依赖基的选取：

1. `acf_fft(P)` 给出的是**这 d 个成分各自**的 ACF，换一组基就换成另一组曲线。
2. `median` 是非线性泛函，`median(Qᵀ·ACF·Q) ≠ median(ACF)`。

因此 τ 可能是分析管线的性质，而不是数据的性质。

## 二、规范不变量

对任意正交 `Q`，

```
tr C(τ) Qᵀ = tr(Qᵀ C(τ) Q) = tr C(τ)
```

所以

```
R(τ) = tr C(τ) / tr C(0) = Σ_k ⟨x_k(t) x_k(t+τ)⟩ / Σ_k ⟨x_k(t)²⟩
```

是正交不变量。它是**按方差加权**的平均 ACF，方差大的成分权重大。

这正是它与「逐成分中位数」的关键差别：中位数对每个成分等权，
而信号往往集中在少数成分上，等权就会被大量噪声成分主导。

实现在 `research/brain_domains/lib/tau.py`。

### 为什么两个模态相反

头皮 EEG 经颅骨空间低通，63 个导联高度相关，**每个成分都带时间结构**
（ACF(1) 中位数 0.810）。逐成分中位数取到的是信号。

单个神经元的放电计数在 20 ms 上近乎独立（ACF(1) 中位数 0.049），
共享的低维状态只占 PC1（43.8%），其余 63 个成分是噪声。**逐成分中位数取到的是噪声底。**

## 四、可操作的判据

> **先用 top-1 特征值占比判断能不能用逐成分统计。**
> 超过 20% 时，逐成分中位数 / 平均值都会被少数成分或噪声主导，必须改用不变量。

本项目的两个模态分别落在判据两侧：EEG 5.2%（可用），spike 43.8%（不可用）。

两个结论：

1. **τ 在中位数 3.52 ms，小于一个 bin（4 ms）。** 600 ms 的 spike 窗口上，
   逐试次 τ 低于采样分辨率，不可辨识。
2. **旧估计量对全部 502 个试次都给出了数值**，即使数据是白噪声。
   这就是逐成分中位数的危险性：它总能产出一个可拟合的平滑曲线。

所以 exp43 的「τ 不预测行为」这个负结果成立，但成立的理由比原先写的更强：
**那个 τ 从来没有被测出来过。**

## 六、一个已知的下限问题

窗长 800 ms，τ ≈ 200 ms，所以每窗只装 **4 个 τ**。估 τ 一般需要 5–10 个。

从 100 ms 走到 20 ms 提高的是**时间分辨率**，不是**时间跨度**，
这个比值一分没动。要真正估准 τ，需要更长的连续段或更短的 τ 定义域。

## 七、可复用的检验代码

```python
import numpy as np
from scipy.optimize import curve_fit


def weighted_acf(x, max_lag):
    """tr C(k) / tr C(0)。正交不变。x: (T, d)"""
    T = x.shape[0]
    xc = x - x.mean(axis=0, keepdims=True)
    n = 1
    while n < 2 * T:
        n <<= 1
    f = np.fft.rfft(xc, n=n, axis=0)
    a = np.fft.irfft(f * np.conj(f), n=n, axis=0)[:max_lag + 1]
    norms = np.arange(T, T - max_lag - 1, -1)[:, None]
    a = a / np.maximum(norms, 1)
    return a.sum(axis=1) / max(a[0].sum(), 1e-12)


def gauge_test(x, max_lag, n_rot=5, seed=0):
    """返回 (不变量在旋转下的极差, 逐成分中位数在旋转下的极差)。

    第一个应为 0（到浮点精度）；第二个不为 0 说明该统计量依赖基。
    """
    rng = np.random.default_rng(seed)
    d = x.shape[1]
    inv, med = [], []
    for _ in range(n_rot):
        Q, _ = np.linalg.qr(rng.standard_normal((d, d)))
        xq = x @ Q
        inv.append(weighted_acf(xq, max_lag))
        med.append(np.median(_acf_cols(xq, max_lag), axis=1))
    return (float(np.ptp(inv, axis=0).max()),
            float(np.ptp(np.array(med), axis=0).max()))


def top1_fraction(x):
    """top-1 特征值占比。> 0.2 时不要用逐成分统计。"""
    xc = x - x.mean(axis=0, keepdims=True)
    s = np.linalg.svd(xc, compute_uv=False) ** 2
    return float(s[0] / s.sum())
```

## 九、结论

**能报告的**：头皮 EEG 的 τ ≈ 202 ms（148.8–250.9），正交不变，5/5 通过分辨率检验。

**不能报告的**：
- 20 ms spike 上的任何 τ（旧值 6.9 ms 是噪声底，不变量是 271.8 ms）
- 逐试次 spike 的 τ（中位 3.52 ms，低于 bin 宽，不可辨识）
- 用 PC1 算的 τ（EEG 上高估 86%）

**方法学结论**：规范依赖性的量级由信号在成分间的分布决定，不是固定偏差。
top-1 占比是判断的先验指标。

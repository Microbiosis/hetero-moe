# 脑域条件建模：六个实验的完整记录（含失败）

> 2026-10-17 · 本文件记录 `research/brain_domains/` 研究线从可行到否定的全过程。
>
> **结论先行**：脑区/功能域标签（L1 六大类与 L2 七十三区）在信息论意义上与原始活动信号**冗余**。
> 可被解码，但对任何下游任务无增量价值。这条研究线应当终止。

---

## 一、出发点

**假说**：把「脑功能域」作为显式的架构约束（条件建模），能让模型更好地预测神经活动。

依据：
- 不同脑区的时间常数、连接模式、功能分工确实不同
- 若模型显式知道"当前是哪个域"，应能选对动力学参数

**数据**：OmniBrain（本项目自建，485,587 样本 / 三视图 / 三物种）

---

## 二、六个实验

### Phase 0 — 域可解码吗？ ✅ 是

**设计**：session 内时间切分 70/30，128 维简单特征 + 逻辑回归，组内打乱标签对照。

**结果**（spike_view，39 个 session）：

```
real 0.745  vs  shuffled 0.317  (Δ = +0.428)   多数类基线 0.513
```

39 个 session 全部成立（Δ +0.107 ~ +0.825）。

**结论**：域信息确实存在于活动模式中。

**注意**：eeg_view 只有 Δ=+0.115，且 real 0.572 ≈ 多数类 0.575 —— 那是**实验设置不足**
（训练/测试跨 session 且图像不同），不是"无信号"。后续只在 spike_view 上推进。

---

### Phase 1 — 域作为输入特征有用吗？ ❌ 否

**设计**：三臂 MLP 做"下一步活动预测"（自监督）：
- A `no_domain`：只吃 x
- B `with_domain`：x + domain one-hot
- C `rand_domain`：x + 打乱的 one-hot

**结果**：

```
平均 MSE:  none 0.5060 | domain 0.5024 (+1.1%) | random 0.5025 (+1.0%)
域胜随机:  24/39 个 session（≈ 50/50，噪声水平）
```

**关键**：domain (+1.1%) 与 random (+1.0%) 几乎相同 → 那 1% 来自多了 6 个输入参数，
不是域信息。

---

### exp2 — 域调制时间常数（合成任务）✅ 理论可行

**设计**：构造 K=8 个域，每域独立 AR(1) 过程 `x_t = a_d·x_{t-1} + b_d·u_t`，
a_d ∈ [0.17, 0.89]，差异显著。三臂：shared_A / domain_A / random_A。

**结果**：

| seed | shared | domain | random | 域胜共享 | 域胜随机 |
|---|---:|---:|---:|---:|---:|
| 0 | 0.3356 | **0.0198** | 0.0776 | +94.1% | +74.5% |
| 1 | 0.2290 | **0.0091** | 0.0609 | +96.0% | +85.1% |
| 2 | 0.2082 | **0.0135** | 0.0684 | +93.5% | +80.2% |

**机制证据**：学到的 |A_eff| 与真实 a_d 的 Spearman ρ = **−0.60**
（a_d 是保留率，|A| 是衰减率，负相关即"学到了正确排序"）。

**结论**：**如果**域真的对应不同的时间常数，域调制能学到它。
但这只是证明方法可行，前提是我自己构造的。

**踩坑记录**：
- 初版 `C_BOUND=1.5` 导致发散 NaN（φ ∈ [0.22, 4.5] 太宽）
- 降到 0.5 后正常
- 初版判据写成 `ρ > 0.5`（符号搞反），把成功结果误判为"部分成立"

---

### exp2b — 域调制时间常数（真实数据）❌ 否

**设计**：同一模型，换成 OmniBrain spike_view 真实数据。

**结果**（39 session）：

```
域 vs 共享:  +0.70%   (39/39 都"略好")
域 vs 随机:  -0.04%   (仅 15/39)
ρ(经验τ, |A|): +0.319  (12/37 为负，预期应为负)
```

**关键**：`域 vs 随机 = -0.04%` —— 那 0.70% 是噪声。打乱标签后反而略好。
且 ρ 方向错误（+0.32，应为负），说明没学到"域与时间常数的对应"。

**结论**：真实数据的 L1 域标签**不对应不同的时间常数**。

---

### Phase 3 — 域之间到底差在哪？ mean_abs 最强

**设计**：对每个窗口算 7 类统计量，按域分组做 Kruskal-Wallis，报告效应量 ε²。
打乱对照 20 次。

**结果**（39 session 中位）：

| 统计量 | ε² | 打乱后 | 降幅 | 显著 session |
|---|---:|---:|---:|---:|
| **mean_abs** | **0.161** | 0.0001 | 99.9% | 97% |
| ac1 | 0.089 | 0.0001 | 99.9% | 100% |
| std | 0.086 | 0.0001 | 99.9% | 100% |
| hf_ratio | 0.079 | 0.0001 | 99.9% | 97% |
| eff_dim | 0.036 | 0.0001 | 99.7% | 92% |
| spectral_slope | 0.025 | 0.0001 | 99.6% | 100% |
| **sparsity** | **0.000** | 0.0001 | — | **0%** |

**结论**：域差异首要体现在**活动幅度**（mean_abs, ε²=0.161），
是第二名（ac1, 0.089）的 1.8 倍。

**这解释了 exp2b 为什么失败**：域调制的是 A（时间常数），但域真正不同的是活动幅度。

---

### Phase 4A — 控制活跃度后还剩什么？ 只剩 eff_dim

**设计**：按 mean_abs 分位分层，层内重算各统计量的 ε²（偏相关近似）。

**结果**：

| 统计量 | 原始 ε² | 控 mean_abs 后 | 保留率 | 判定 |
|---|---:|---:|---:|---|
| **eff_dim** | 0.036 | 0.030 | **99.2%** | ✅ 独立 |
| hf_ratio | 0.079 | 0.030 | 56.0% | ⚠️ 部分 |
| spectral_slope | 0.025 | 0.012 | 44.1% | ⚠️ 部分 |
| sparsity | 0.000 | 0.001 | 0% | ✗ 无差异 |

**结论**：ac1 / std / hf_ratio 的域差异有一半以上是 mean_abs 的副产物。
唯一独立的 eff_dim 效应量仅 0.036，几乎无法利用。

---

### Phase 4B — 该调哪个参数？ 都不行

**设计**：同一个域条件 SSM，只改"域调制哪个参数"：
- `mod_A`：调制状态转移 A（时间常数）
- `mod_gain`：调制输出增益（对应 mean_abs）
- `mod_C`：调制读出投影 C
- `mod_gain_rand`：调制增益但打乱标签 ← **关键对照**

**结果**（39 session 平均提升，相对 shared）：

| 调制目标 | 平均提升 | 胜出 |
|---|---:|---:|
| **mod_gain** | **+1.08%** | 38/39 |
| **mod_gain_rand** | **+0.93%** | 38/39 |
| mod_A | +0.70% | 39/39 |
| mod_C | +0.69% | 36/39 |

**决定性判据**：`mod_gain (+1.08%)` vs `mod_gain_rand (+0.93%)` → **差值仅 0.15pp**。

那 1% 的提升，0.93% 来自"多了一组可训练参数"，只有 0.15% 可能归功于域标签。

---

### Phase 5b — L2 细粒度解剖区有增量吗？ ❌ 否

**动机**：L1 失败可能因为过粗（7 个视觉区合并成 "sensory"）。
L2 用 73 个原始解剖区，粒度细得多。

**设计**（关键：避免 exp5 的循环论证）：
1. 从未经 PCA 的原始 spike 计算区域级活动
2. 同一批窗口上，分别用 L1 与 L2 标签
3. 打乱对照量化"类别数增加"带来的基线提升

**结果**：

```
ε²(L2)/ε²(L1) 中位:      1.101
打乱后的同一比值:         1.095     ← 几乎相同
真实信号比:              1.006 ≈ 1.0
```

**结论**：L2 的"提升"完全来自类别数增加（自由度效应），无真实增量信息。

---

## 三、为什么"可解码"却"无用"——最终解释

**L1/L2 域标签编码的是空间信息**：这个窗口里哪群电极/神经元活跃。

而 `mean_abs` 的 ε²=0.161 说明域标签主要捕捉**"活跃程度"**——
这个量在数据里**本身就是可观测的**。模型不需要域标签，直接从输入就能读到。

> **域标签提供了冗余信息，没有任何增量价值。**

Phase 4B 的 `mod_gain ≈ mod_gain_rand` 完全印证：模型自己就能从输入算出增益，
给它域标签等于重复告知。

---

## 四、这个负结果的价值

**它否定了本项目的一个核心前提**：即"脑区标签是有用的架构约束"。

更准确的表述：

> **脑区/功能域标签在信息论意义上与原始活动信号冗余。**
> 可被解码（反映空间分布），但没有任何主输入之外的增量信息，
> 因此在任何条件建模中都无收益 —— 无论调制 A、C 还是 gain，无论 L1 还是 L2。

**唯一的例外**是 `eff_dim`（表征复杂度），它独立于活跃度（保留 99.2%），
但 ε² 仅 0.036，几乎无法利用。

## 五、方法学失误记录（比结果本身更重要）

### 失误 1：exp5 的循环论证

```python
q = pd.qcut(vv, 4)              # 用 mean_abs 分组
groups = [vv[q == g_] for ...]  # 再测 mean_abs 的组间差异
epsilon_sq(groups)              # → 必然 0.937
```

**症状**：39 个 session 的 ε² 几乎完全相同（0.9372–0.9374）。

**教训**：见到"跨所有 session 几乎相同"的统计量，第一反应应是查方法学 bug，
而非庆祝。真实生物数据不会如此一致。

### 失误 2：判据符号写反（exp2）

真实 a_d 是 AR **保留率**（大=记忆长），模型学到的是 |A_eff| **衰减率**（大=记忆短）。
二者天然负相关。我把判据写成 `ρ > 0.5`，导致把 ρ=−0.60 的成功结果判成"部分成立"。

**教训**：写判据时要先确认两边量的物理含义与符号约定。

### 失误 3：性能测试未验证正确性（更早，cloud_bench）

曾测出 `torch.compile` 有 3.9× 提速，但脚本只计时、不检查输出是否有限 ——
实际算的是 NaN。补上逐元素 + 梯度对拍后才发现。

**教训**：任何性能数字必须与正确性检查绑定。

## 六、结论与建议

| 假说 | 测试 | 结果 |
|---|---|---|
| H1 域作为输入特征 | Phase 1 | ❌ |
| H2 域作为动力学调制（合成）| exp2 | ✅（但前提是构造的）|
| H2 域作为动力学调制（真实）| exp2b | ❌ |
| H3 域调制的目标参数 | Phase 4B | ❌（gain/A/C 都无效）|
| H4 更细粒度（L2）| Phase 5b | ❌ |

**建议**：终止这条研究线。若将来重启，需要**重新定义"域"**——
不是在解剖位置，而是在**动力学属性**上（如：按实测时间常数聚类，而非按脑区）。

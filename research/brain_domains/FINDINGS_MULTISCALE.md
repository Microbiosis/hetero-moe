# 多区域 × 多时间尺度：τ 的结构分解

> 2026-10-17 · OmniBrain / Steinmetz 小鼠数据（39 session × 71 区域）
>
> **结论**：神经动力学确实需要**双时间尺度**才能描述（ΔAIC=10.7）。
> 慢成分 τ_slow 在区域间跨度达 56 倍，且约 **59%** 的区域间方差是真实的。
> 但快成分 τ_fast ≈ 37ms **低于 100ms 的分辨率**，不可解释。

---

## 一、为什么用这个设计

前面所有跨物种比较都栽在混淆上（模态 / 记录规模 / 脑区 / 任务 / 被试）。
本实验改用**同一 session 内的多区域对照**：

> 同一只动物、同一时刻、同一根 Neuropixels 探针、同一行为状态，
> 只是 unit 所属解剖区不同。

这样 session 内比较可控制掉除"区域"以外的一切变量。

**数据**：39 session × 平均 8.4 区域 = 305 个 (session, region) 组合，
覆盖 71 个解剖区（每区中位 58 个 unit）。

---

## 二、多时间尺度：真实存在

单指数 `R²(k)=a·exp(-k/τ)+c` 隐含"只有一个时间尺度"。改为双指数：

```
R²(k) = a_fast·exp(-k/τ_fast) + a_slow·exp(-k/τ_slow) + c
```

### 结果

| 指标 | 值 |
|---|---:|
| 双指数更优的比例 | **76.7%**（230/300）|
| ΔAIC 中位（单−双）| **+10.68**（强证据）|
| τ_fast 中位 | 0.37 bins = **37 ms** |
| τ_slow 中位 | 10.3 bins = **1030 ms** |
| 慢/快 倍率 | **26.8×** |

**神经动力学需要至少两个时间尺度，相差约 27 倍。**

---

## 三、三个必须承认的限制

### 限制 1：τ_fast 低于时间分辨率，不可解释

```
bin 宽度 = 100 ms
τ_fast 中位 = 37 ms      ← 小于一个 bin
τ_fast < 0.5 bins 的占比 = 80%
```

**100ms 分箱无法分辨 <100ms 的时间常数。** τ_fast 反映的是"相邻 bin
之间的去相关"，是分辨率的下限效应，不能解释为生物时间常数。

佐证：τ_fast 与任何区域属性都无关
（vs n_units ρ=+0.059, vs R²(1) ρ=+0.104, vs 噪声地板 ρ=+0.007）。

### 限制 2：τ_slow 有 27% 撞到拟合上界

拟合的上界设为 60 bins，结果 **82/300（27%）恰好等于 60.0**。

这些是**截尾值**（censored），真实 τ 可能更大。它们分布在
DG(8)、MOs(6)、CA1(5)、SUB(4)、ACA(3)、VISp(3) 等区域。

**排除截尾后**：n=218，中位 **4.66 bins（466ms）**，IQR 2.54–13.81，
范围 1.0–57.5 bins（**100ms – 5.75s**）。

任何使用 τ_slow 的汇总都必须区分"截尾组"与"未截尾组"。

### 限制 3：区域效应的证据是弱到中等

见下节。

---

## 四、区域特异性：约 59% 的真实方差

### 正确的零假设

exp14 首版用"session 内打乱 τ 值"做置换 —— **这个检验完全无效**，
因为**标准差对组内置换是不变量**，导致 observed ≡ null、ratio 恒为 1.00。

正确做法：**随机把 unit 分到"伪区域"**（保持各区域原有的 unit 数量），
重做 PCA → 分窗 → R²(k) → τ。这检验的是"解剖标签是否优于任意分组"。

### 结果（12 个多区域 session，每个 20 次置换）

| 指标 | 值 |
|---|---:|
| 观测 SD / 伪区域 SD（中位）| **1.56** |
| 显著的 session（p<0.05）| **2 / 12** |
| 比值 < 1 的 session | 2 / 12 |

### 怎么读这个 1.56

若 `观测方差 = 真实区域方差 + 估计噪声`，而 `伪区域方差 = 估计噪声`：

```
ratio² = 1 + 真实/噪声
1.56²  = 2.43  →  真实 : 噪声 ≈ 1.43 : 1
```

**即约 59% 的区域间方差是真实的解剖结构，41% 是 τ 的估计噪声。**

但只有 2/12 个 session 单独达到显著（20 次置换下最小可达 p=0.048），
且 2 个 session 的比值小于 1。**证据是弱到中等，不是强证据。**

### 区域特征表（排除截尾后的 τ_slow）

| 区域 | n | τ_slow (bins) | slow_frac | R²(1) |
|---|---:|---:|---:|---:|
| SCig | 4 | 4.6 | 0.236 | 0.165 |
| SSp | 4 | 3.7 | 0.226 | 0.172 |
| CP | 5 | 3.4 | 0.071 | 0.191 |
| LP | 10 | 2.8 | 0.051 | 0.053 |
| MOp | 3 | 2.7 | 0.228 | 0.200 |
| TT | 3 | 1.1 | 0.064 | 0.065 |

（上表只列未截尾的区域；截尾的 DG/MOs/CA1/VISp 等真实 τ ≥ 60 bins）

## 五、慢成分提供独立于"可预测性大小"的信息

| 相关 | ρ | p |
|---|---:|---:|
| τ_slow vs R²(1) | **+0.013** | 0.85 |
| slow_frac vs τ_fast | +0.090 | 0.12 |
| slow_frac vs τ_single | +0.766 | 4e-59 |

**τ_slow 与 R²(1) 几乎完全无关**（ρ=0.013）。

这说明两个维度是正交的：
- **R²(1)** 回答"能预测多少"
- **τ_slow** 回答"能预测多久"

而 `slow_frac` 与 `τ_single` 高度相关（ρ=0.77），说明它主要编码的仍是
"整体偏慢还是偏快"，只有相对 τ_fast 时才提供独立信息。

## 六、结论

| 主张 | 状态 | 依据 |
|---|---|---|
| 神经动力学需要双时间尺度 | ✅ **成立** | 76.7% 双指数更优，ΔAIC=10.7 |
| 慢尺度跨度大（100ms–5.75s）| ✅ 成立 | 排除截尾后 56 倍跨度 |
| τ_slow 独立于可预测性大小 | ✅ 成立 | vs R²(1) ρ=0.013 |
| τ_fast ≈ 37ms 是生物常数 | ❌ **不成立** | 低于 100ms 分辨率 |
| 区域解释约一半的 τ 方差 | ⚠️ **弱-中等** | ratio 1.56，2/12 显著 |
| 明确的区域排序 | ❌ 不能 | 27% 截尾 + 样本量不足 |

---

## 七、要做得更好需要什么

1. **更细的时间分辨率**：用 25ms 或 10ms bin 重做，才能解析 τ_fast
2. **更宽的拟合上界**：上界设到 200 bins，避免 27% 截尾
3. **更多置换 + 更多 session**：20 次置换的最小 p 是 0.048，无法区分强证据
4. **同一探针同时记录多个区域**：Steinmetz 已满足，但需要按探针深度分层

## 八、方法学教训（本轮新增一条，累计 9 条）

**"组内置换"检验对离散度指标无效**

```python
# 错误
sh.loc[idxs, col] = rng.permutation(sh.loc[idxs, col])   # 打乱组内值
std = sh.groupby('session')[col].std()                   # 再算组内标准差
# → 标准差对置换不变，observed ≡ null
```

症状：`ratio` 精确等于 1.00，`p` 精确等于 1.000，四个指标全部如此。

**看到"完美等于 1"就该怀疑**，而不是庆幸"没有差异"。

正确做法是把**分组本身**随机化（伪区域），而不是打乱组内数值。

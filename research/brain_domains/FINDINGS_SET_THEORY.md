# 集合论审计：为什么"多源分层数据集"在数据上是空的

> 2026-10-18 · exp47（结构审计）+ exp48（方差分解）
>
> **两个结论**
> 1. 我做的不是"五级分层"，是一个偏序集，最长链长度为 0
> 2. 所有语义划分加起来只解释 **0.05%** 的方差
>
> 第 2 点不是实现问题。它说明"给数据分层"这件事在数据上没有根据。

---

## 一、为什么要用集合论

我把 5 个来源拼成 620,250 行、带 5 个标签列的数据集，称之为"五级分层"。

"层"这个词在数学上有严格含义，不能随便用。

### 定义

属性 α 定义一个等价关系 ~_α，其商集 `S/~_α` 是一个划分。

α 比 β **细**（α refines β），当且仅当 **α 的每个等价类都完整落在
β 的某个等价类内**：

```
∀ A ∈ S/~_α,  ∃ B ∈ S/~_β  s.t.  A ⊆ B
```

只有属性构成**链**（A ⊂ B ⊂ C …）时，才能称为分层。

若两个属性互不细化，它们**不可比**，不能排成层。

## 二、审计结果（exp47）

### 2.1 细化矩阵

行比列细则标 YES：

```
              src    spc    mod    reg    dom
       src    YES    YES    YES      .      .
       spc      .    YES      .      .      .
       mod      .      .    YES      .      .
       reg    YES    YES    YES    YES      .
       dom      .      .      .      .    YES
```

读法：
- `reg` 行全为 YES → region 比所有其他属性都细
- `dom` 行只有自反 → domain 不比任何属性细
- `spc` / `mod` 互相都是 `.` → **互不可比**

### 2.2 覆盖关系（Hasse 图的边）

只有三条：

```
        modality      species
             \        /
              source
                 |
               region

        domain_l1  ← 与所有属性交叉
```

### 2.3 最长链长度为 0

按"从细到粗排成序列"的严格定义，最长链为 0。

原因：`region ⊂ source` 之后，下一层只能是 `species` **或** `modality`，
不能两者串联，因为人类同时有两种模态：

| species | extracellular_spike | scalp_eeg |
|---|---:|---:|
| homo_sapiens | 86,851 | 32,000 |
| macaca_mulatta | 187,067 | 0 |
| mus_musculus | 314,332 | 0 |

`homo_sapiens` 这一行跨两列 → 二者互不细化。

### 2.4 最强证据：投影算子不可交换

若两个划分嵌套，其投影算子必然可交换：`Πa Πb = Πb Πa`。

实测（20,000 样本，`max|ΠaΠb x − ΠbΠa x|`）：

| 属性对 | max\|diff\| | 可交换 |
|---|---:|---|
| source × species | 0.00e+00 | ✅ |
| source × modality | 0.00e+00 | ✅ |
| source × region | 0.00e+00 | ✅ |
| species × region | 0.00e+00 | ✅ |
| modality × region | 0.00e+00 | ✅ |
| **source × domain** | 3.07e-02 | ❌ |
| **species × modality** | 4.11e-02 | ❌ |
| **species × domain** | 3.40e-02 | ❌ |
| **modality × domain** | 1.33e-02 | ❌ |
| **region × domain** | 4.26e-02 | ❌ |

**前 5 对精确为 0**（浮点误差内），后 5 对全部非零。

`domain_l1` 与**所有**属性都不可交换——它与整个偏序集正交。

### 2.5 笛卡儿积的空洞

理论组合 `4 来源 × 2 模态 × 35 region × 6 domain = 1680`，
实际存在 **144** 个。

**91.4% 为空。**

空位不是缺数据，是结构约束：

| 空位来源 | 原因 |
|---|---|
| `human_eeg` × 任何 region | EEG 无解剖区 |
| `flywire` × 任何时间窗 | 连接组无时间维 |
| 小鼠 × `area` 列 | 上游该列不存在 |

## 三、沿真链做方差分解（exp48）

在有 region 的 588,250 窗中采样 120,000，沿 `region ⊂ source ⊂ species`
做精确正交分解。

### 3.1 为什么这个分解是精确的

嵌套划分满足 Loewner 序 `Π_r ⪯ Π_s ⪯ Π_p`，差分算子

```
Δ_1 = Π_r
Δ_2 = Π_s − Π_r
Δ_3 = Π_p − Π_s
Δ_4 = I − Π_p
```

满足 `Δ_i Δ_j = 0 (i ≠ j)`，因此

$$\|x\|^2 = \|\Delta_1 x\|^2 + \|\Delta_2 x\|^2 + \|\Delta_3 x\|^2 + \|\Delta_4 x\|^2$$

精确成立，不需要任何近似。

### 3.2 结果

| 层 | 方差占比 |
|---|---:|
| `Π_region` | **0.03%** |
| `Π_source − Π_region` | **0.02%** |
| `Π_species − Π_source` | **0.00%** |
| **`I − Π_species`（残差）** | **100.0%** |
| 合计 | 1.0005（float32 累积误差）|

**所有语义层加起来的解释力是 0.05%。**

### 3.3 对照：把 domain 硬塞进链

若强行按 `region → domain → source` 做差，各项之和会偏离 1：

| 项 | 值 |
|---|---:|
| `Π_region` | 0.0003 |
| `Π_domain − Π_region` | 0.0027 |
| `Π_source − Π_domain` | 0.0025 |
| `I − Π_source` | 1.0000 |
| **合计** | **1.0054**（偏离 0.5%）|

这 0.5% 的偏离就是"非嵌套"的定量代价：`Δ_2` 与 `Δ_3` 有重叠，
不能相加。

## 四、这意味着什么

### 4.1 不是"分层方式不好"，是"标签不解释方差"

`Π_region x ≈ 0`，所以 `x ≈ (I − Π_region) x`。

**任何基于这些标签的分层、调制、条件化，作用对象都是接近零的分量。**

### 4.2 统一解释了之前的每一个负结果

| 之前的实验 | 当时的解释 | 集合论解释 |
|---|---|---|
| exp1 域作输入特征无效 | 域与活动冗余 | `Π_domain x ≈ 0` |
| exp2b 域调制 A 无效 | 域不对应时间常数 | 同上 |
| exp4 调 gain/C 都无效 | 无差别 | 同上 |
| exp5b L2 无增量 | 粒度无用 | `Π_L2` 也不比 `Π_L1` 多解释方差 |
| exp14 区域解释 59% τ 方差 | 弱信号 | 那 59% 是 τ 的方差，不是数据的方差 |

**同一个事实，之前用了 6 个实验分别发现，集合论一次说清。**

### 4.3 为什么"层次数据集"这个目标本身有问题

我一直在问"怎么把多个数据集组织成更好的层次"。

若任何标签划分都只解释 0.05% 方差，那么无论怎么组织层次，
都是在一个几乎为零的信号上做文章。

问题不在组织方式，在于**标签与数据方差解耦**。

## 五、可复用的检验代码

三项检查，各不到 50 行。**动手之前先跑这三项。**

### 检查 1：细化关系

```python
def refines(a: pd.Series, b: pd.Series) -> bool:
    """a 是否比 b 细：a 的每个等价类是否只取 b 的一个值。"""
    df = pd.DataFrame({"a": a.fillna("__NA__"), "b": b.fillna("__NA__")})
    return (df.groupby("a")["b"].nunique() > 1).sum() == 0
```

### 检查 2：投影可交换性

```python
def proj(x, labels):
    """Π：把每行替换为其等价类内的均值。"""
    out = np.empty_like(x)
    for lab in np.unique(labels):
        m = labels == lab
        if m.any():
            out[m] = x[m].mean(axis=0, keepdims=True)
    return out

def commutes(x, la, lb, tol=1e-6):
    Pab = proj(proj(x, la), lb)
    Pba = proj(proj(x, lb), la)
    return np.abs(Pab - Pba).max() < tol
```

### 检查 3：方差分解

```python
def decompose(x, labels_chain):
    """labels_chain: [最细, 次细, ..., 最粗]，必须严格嵌套。

    返回各层的方差占比 + 残差，末项与 1 的差即非嵌套程度。
    """
    x2 = float((x ** 2).sum())
    prev, out = None, []
    for lab in labels_chain:
        P = proj(x, lab)
        comp = P if prev is None else (P - prev)
        out.append(float((comp ** 2).sum()) / x2)
        prev = P
    out.append(float(((x - prev) ** 2).sum()) / x2)
    return out          # 末项是残差；sum(out) 应 == 1
```

**若 sum(out) 与 1 差 > 1e-4，说明链不嵌套，分解无效。**

## 六、诚实的结论

### 关于已完成的工作

**`omnibrain-multi` 作为一个"分层数据集"是失败的。**

它确实把 620,250 个样本拼在一起，也确实带了 5 个标签列。
但这些标签不能解释数据的方差（0.05%），所以"分层"没有实际含义。

它仍然有用的地方：

- 提供统一张量，可直接送进序列模型
- 提供逐样本 source/species/modality 标签，可做域适应实验
- 提供 91.4% 稀疏的标签空间，可用于约束研究

### 关于"层次数据集"这个目标

**在当前数据上，这个目标无法达成。** 不是因为我做得不够好，
而是因为语义标签与数据方差正交。

要让它有意义，需要满足以下之一：

1. 找到能解释 >10% 方差的划分（数据驱动，不是语义）
2. 放弃划分，改用关系结构
3. 放弃"用标签组织数据"，改为纯自监督

## 七、建设性的替代：从划分到关系

集合论里除了划分，还有**关系**。

| | 划分 | 关系 |
|---|---|---|
| 定义 | 每个元素属于恰好一个块 | 任意两元素间可有权重 |
| 结构 | 树 / 格 | 图 |
| 要求 | 互斥且覆盖 | 无此要求 |
| 适合 | 分类、分层 | 相似度、迁移、聚类 |

若语义标签不能**划分**数据，也许能定义**关系**：

- `E1` 同 session → 时间连续
- `E2` 同 region → 空间同源
- `E3` 同 species → 跨源

### 可检验的设计

对每种边，检验两端样本的活动相似度是否显著高于随机配对：

```
H0: 相似度(E_ab) = 相似度(random pair)
```

若三种都显著 → 关系结构有信息，图模型值得做
若只有 E1 显著 → 只有时间关系有用
若都不显著 → 连关系也没有，只能纯自监督

**成本：一次矩阵乘 + 置换检验。否证条件明确。**

## 八、方法学教训（第 24 条）

### 第 24 条：**先验证结构是否存在，再构建结构**

24 个实验里有一半在"构建层次/结构"，
但**从未先验证这个结构在数据里是否存在**。

集合论给了三件检验工具：

| 检验 | 类型 | 代码量 | 耗时 |
|---|---|---:|---:|
| 细化矩阵 | 二值 | ~20 行 | < 1s |
| 投影可交换性 | 二值 | ~30 行 | < 1s |
| 方差分解 | 定量 | ~40 行 | < 10s |

**三项都不到 10 秒，我一次都没做就直接开始了。**

**判据：任何"层次化/结构化"的设计，先在标签上跑这三项。
若三项都不过，不要开始构建。**

# 集合论审计：为什么"多源分层数据集"在科学上是空的

> 2026-10-18 · exp47（结构审计）+ exp48（方差分解）
>
> **两个结论**
> 1. 我做的不是"五级分层"，是一个偏序集（poset），最长链长度为 0
> 2. **所有语义划分加起来只解释 0.05% 的方差，99.95% 在残差里**
>
> 第 2 点不是实现问题。它说明"给数据分层"这件事在数据上没有根据。

---

## 一、集合论定义：什么叫"层"

属性 α 定义一个等价关系 ~_α，商集 S/~_α 是一个划分。
α 比 β 细（α refines β），当且仅当 α 的每个等价类都完整落在 β 的某个类内。

只有属性构成**链**（A ⊂ B ⊂ C …）时，才能称为分层。

若两个属性互不细化，它们**不可比**，不能排成层。

### 覆盖关系（只有三条）

```
        modality      species
             \        /
              source
                 |
               region

        domain_l1  ← 与所有属性交叉
```

### 最长链长度为 0

`species` 与 `modality` 互不细化——人类同时有头皮 EEG 与皮层内记录：

| species | extracellular_spike | scalp_eeg |
|---|---:|---:|
| homo_sapiens | 86,851 | 32,000 |
| macaca_mulatta | 187,067 | 0 |
| mus_musculus | 314,332 | 0 |

所以 `region ⊂ source` 之后，下一层只能是 `species` **或** `modality`，不能两者串联。

### 最强证据：投影算子不可交换

若两个划分嵌套，其投影算子可交换（Πa Πb = Πb Πa）。实测：

| 属性对 | max\|diff\| | 可交换 |
|---|---:|---|
| source × species | 0.00 | ✅ |
| source × modality | 0.00 | ✅ |
| source × region | 0.00 | ✅ |
| species × region | 0.00 | ✅ |
| modality × region | 0.00 | ✅ |
| **source × domain_l1** | **3.07e-02** | ❌ |
| **species × modality** | **4.11e-02** | ❌ |
| **species × domain_l1** | **3.40e-02** | ❌ |
| **modality × domain_l1** | **1.33e-02** | ❌ |
| **region × domain_l1** | **4.26e-02** | ❌ |

`domain_l1` 与**所有**属性都不可交换——它与整个 poset 正交。

### 笛卡儿积的空洞

理论组合 `4 × 2 × 35 × 6 = 1680`，实际存在 **144** 个。

**91.4% 为空。**

空的位置不是缺数据，是结构上不可能：
- `human_eeg` 没有解剖区
- `flywire` 没有时间窗
- 小鼠没有 `area` 列

## 三、沿真链做方差分解（exp48）

在有 region 的 588,250 窗中采样 120,000，沿 `region ⊂ source ⊂ species`
做精确正交分解：

$$\|x\|^2 = \|\Pi_r x\|^2 + \|(\Pi_s - \Pi_r)x\|^2 + \|(\Pi_p - \Pi_s)x\|^2 + \|(I - \Pi_p)x\|^2$$

| 层 | 方差占比 |
|---|---:|
| `Π_region` | **0.03%** |
| `Π_source − Π_region` | **0.02%** |
| `Π_species − Π_source` | **0.00%** |
| **`I − Π_species`（残差）** | **100.0%** |
| 合计 | 1.0005（float32 累积误差）|

**所有语义层加起来的解释力是 0.05%。**

---

## 四、这个结果意味着什么

### 不是"分层方式不好"，是"标签不解释方差"

我试过：
- 五级语义分层（source/species/modality/region/domain）
- 数据驱动的 k-阶梯（exp14, exp28）
- 域条件建模（6 个实验）
- 时间常数作为组织维度（5 轮）

全失败。集合论给出统一解释：

> **语义标签定义的划分，其投影算子几乎不捕捉数据方差。**
> `Π_region x ≈ 0`，所以 `x ≈ (I − Π_region) x`。
> 任何基于这些标签的分层、调制、条件化，作用对象都是接近零的分量。

### 这解释了之前的每一个负结果

| 之前的实验 | 当时的解释 | 集合论解释 |
|---|---|---|
| exp1 域作输入特征无效 | 域与活动冗余 | Π_domain x ≈ 0 |
| exp2b 域调制 A 无效 | 域不对应时间常数 | 同上 |
| exp4 调 gain/C 都无效 | 无差别 | 同上 |
| exp5b L2 无增量 | 粒度无用 | Π_L2 也不比 Π_L1 多解释方差 |
| exp14 区域解释 59% τ 方差 | 弱信号 | 那 59% 是 τ 的方差，不是数据的方差 |

### 为什么"层次数据集"这个目标本身有问题

我一直在问"怎么把多个数据集组织成更好的层次"。

集合论告诉我们：**如果任何标签划分都只解释 0.05% 方差，
那么无论怎么组织层次，都是在一个几乎为零的信号上做文章。**

问题不在组织方式，在于**标签与数据方差解耦**。

## 五、建设性的替代：从"划分"到"关系"

集合论里除了划分（partition），还有**关系**（relation）。

| | 划分 | 关系 |
|---|---|---|
| 定义 | 每个元素属于恰好一个块 | 任意两个元素间可以有权重 |
| 结构 | 树 / 格 | 图 |
| 要求 | 必须互斥且覆盖 | 无此要求 |

如果语义标签不能划分数据，也许它们能定义**关系**：

- "这两个窗口来自同一 session"（时间相关）
- "这两个窗口来自同一物种"（统计相似）
- "这两个窗口来自同一脑区"（空间邻近）

这些关系不需要嵌套、不需要互斥，可以共存。

**这提示一个可检验的替代方案**：把数据集组织成图（节点=窗口，
边=关系），用图神经网络而不是层次模型。

**但我必须先验证这个关系是否有用**——否则又是空话。

### 可检验的具体设计

构造三种边：
- E1 同 session（时间连续）
- E2 同 region（空间同源）
- E3 同 species（跨源）

检验：
1. 每种边的两端样本，其活动相似度是否显著高于随机配对？
2. 若 E1 显著、E2/E3 不显著，说明只有时间关系有用
3. 若三种都显著，说明关系结构比划分结构更有信息

这个实验成本低，且有明确的否证条件。

## 六、诚实的结论

### 关于已完成的工作

**`omnibrain-multi` 作为一个"分层数据集"是失败的。**

它确实把 620,250 个样本拼在了一起，也确实带了 5 个标签列。
但这些标签不能解释数据的方差（0.05%），所以"分层"没有实际含义。

它仍然有用的地方：
- 提供了一个统一张量，可直接送进序列模型
- 提供了逐样本的 source/species/modality 标签，可做域适应实验
- 提供了一个 91.4% 稀疏的标签空间，可用于约束研究

### 关于"层次数据集"这个目标

**在当前数据上，这个目标无法达成。** 不是因为我做得不够好，
而是因为语义标签与数据方差正交。

要让它有意义，需要满足以下之一：
1. 找到能解释 >10% 方差的划分（数据驱动，不是语义）
2. 放弃划分，改用关系结构
3. 放弃"用标签组织数据"，改为纯自监督

## 七、方法学教训（第 24 条）

### 第 24 条：**先验证结构是否存在，再构建结构**

我在 24 个实验里，有一半是在"构建层次/结构"，但从未先验证
"这个结构在数据里是否存在"。

集合论给了检验工具：细化关系（二值）、投影可交换性（二值）、
方差分解（定量）。这些可以在动工之前就做完。

**判据：任何"层次化/结构化"的设计，先在标签上做三件事：
① 细化矩阵 ② 投影可交换性 ③ 方差分解。
若三者都不过，不要开始构建。**

这三项检查各需要不到 100 行代码，但我一次都没做过就直接开始了。

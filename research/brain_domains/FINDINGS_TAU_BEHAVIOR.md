# τ 与真实计时行为无关（逐试次，n=502）

> 2026-10-18 · exp43 · DANDI 000130 DMFC_RSG（sub-Haydn）
>
> **结论**：τ 与真实计时准确度**完全无关**（ρ = +0.013，置换 p = 0.784）。
> 这是对 exp42 的关键补强：那次用解码代替行为（n=10），
> 这次用**真实行为**（n=502）。

---

## 一、为什么必须做这个

exp42 发现 τ 不预测解码准确率（ρ=−0.10, n=10），但有两个缺陷：

1. **用解码代替行为** —— 文献的"整合窗口"论断是关于行为的
2. **n=10 功效不足** —— 需 |ρ|>0.65

DMFC_RSG 解决了这两个问题。

---

## 二、数据

**DANDI 000130**（CC-BY-4.0，15.7 MB，2 个 NWB 文件）

> Sohn, Jazayeri. *Bayesian computation through cortical latent dynamics.*
> Neuron 2019. 猕猴背内侧额叶（DMFC）计时任务。

### 任务：ready-set-go

```
ready ──t1── set ──t2── go
```

被试看到两个刺激（ready → set，间隔 t1），然后必须让自己的反应
（go）与 set 的间隔 **复现 t1**，即目标：t2 ≈ t1。

### 行为字段（`intervals/trials`）

| 字段 | 含义 |
|---|---|
| `ready_time` | ready 刺激时刻 |
| `set_time` | set 刺激时刻 |
| `go_time` | 被试反应时刻 |
| `is_outlier`, `is_short` | 试次质量标记 |

### 行为分布

| 量 | 值 |
|---|---:|
| 有效试次 | 1029 / 1160 |
| 目标间隔 t1 | 中位 800 ms（范围 500–1200）|
| 产生间隔 t2 | 中位 808 ms |
| **计时误差 t2−t1** | 中位 **−2 ms**，SD **147 ms** |
| **\|误差\| 中位** | **69 ms**（相对 9.0%）|

被试整体无偏（−2 ms），但逐试次变异很大（SD 147 ms）——**这正是可检验的行为变异**。

---

## 三、设计：逐试次 τ

只有 1 个被试，不能做跨被试。改用**逐试次**：

```
每个试次：
  τ_i      = set 后 600 ms 窗口内神经活动的 ACF 衰减时间
  err_i    = |t2 - t1|  该试次的计时误差
问：τ_i 大的试次，err_i 是否更小？
```

**窗口选择**：set 后固定 600 ms（不是"set 到 go 的全部"），
否则窗口长度会随 t1 变化，引入混淆。

### τ 估计（沿用 exp41 验证过的方法）

- 4 ms bin（250 Hz）
- 逐 unit z-score → PCA 到 16 维
- 多列中位 ACF → 拟合 `R(t) = exp(−t/τ)`
- 只用 `0.02 < ACF < 0.99` 的段（避免长 lag 噪声）

## 四、结果

### 主要相关（n = 502）

| 关系 | Spearman ρ | p |
|---|---:|---:|
| **τ vs \|计时误差\|** | **+0.013** | **0.771** |
| τ vs 相对误差 | +0.004 | 0.925 |
| τ vs 产生间隔 t2 | −0.024 | 0.586 |
| τ vs spike 总数 | **−0.160** | **3.1e-4** |
| spike 总数 vs \|误差\| | −0.076 | 0.091 |

### 置换对照（1000 次打乱 τ 与行为的配对）

```
零分布：中位 +0.004，95% 区间 [−0.085, +0.083]
观测 ρ = +0.013  →  置换 p = 0.784
```

**观测值落在零分布正中间。**

### 按目标间隔分层（控制任务难度）

| 分层 | n | t1 中位 | ρ | p |
|---|---:|---:|---:|---:|
| Q1（短）| 207 | 800 ms | +0.052 | 0.460 |
| Q2 | 98 | 1000 ms | +0.017 | 0.868 |
| Q3 | 93 | 1100 ms | −0.114 | 0.278 |
| Q4（长）| 104 | 1200 ms | −0.010 | 0.918 |

**四层全部不显著，符号还不一致**（两正两负）。

## 五、一个次要发现

`τ vs spike 总数 ρ = −0.160 (p = 3.1e-4)` —— 显著。

含义：**spike 多的试次，估出的 τ 更短**。

这很可能是**估计伪影**而非生物现象：
- spike 少 → ACF 噪声大 → 拟合偏向长 τ
- spike 多 → ACF 平滑 → 拟合出真实的短 τ

这提醒：**τ 的估计本身受发放率影响**。若要严格使用 τ，
必须控制 spike 数（按发放率分层或回归校正）。

---

## 六、为什么只有 502/1029 试次可用

窗口 600 ms @ 4 ms = 150 bins，理论上都够。
损失来自 `estimate_tau` 要求 `ok.sum() >= 4`（ACF 在 0.02–0.99 区间的点数）——
spike 稀疏的试次 ACF 抖动剧烈，落在区间外的点太多。

**这本身也是一个信号**：约一半试次的神经信号不足以稳定估计 τ。
在真实应用（如 BCI）中，这是一个实际限制。

## 七、与 exp42 合起来看

| | exp42 | exp43 |
|---|---|---|
| 数据 | THINGS-EEG 4D | DMFC_RSG |
| 行为指标 | 解码准确率（代理）| **真实计时误差** |
| 设计 | 跨被试（n=10）| **逐试次（n=502）** |
| 结果 | ρ = −0.103, p = 0.777 | **ρ = +0.013, p = 0.784** |
| 功效 | 不足（需 \|ρ\|>0.65）| **充足（n=502）** |

**两次独立检验，两个数据集，两种设计，都得到 ρ ≈ 0。**

exp43 的功效是充足的：n=502 时，检测 ρ=0.1 的检验功效 > 0.8。
观测 ρ=0.013，**这个否定是可信的**。

## 八、最终结论

### 能说

> 在猕猴 DMFC 的 ready-set-go 计时任务中（502 个试次），
> set 后 600 ms 窗口内估出的神经活动时间常数 τ
> **与试次级计时准确度无相关**（ρ = +0.013，置换 p = 0.784）。
> 该检验的功效足以检测 ρ ≥ 0.15。

### 不能说

| 主张 | 为什么 |
|---|---|
| τ 在所有脑区/任务都无功能 | 只测了 DMFC 的计时任务 |
| τ 无任何神经意义 | τ 确实反映了活动的自相关衰减（信度已验证）|
| τ 与"整合窗口"论断无关 | 该论断是关于**群体层面的信息维持**，逐试次 τ 是个粗略代理 |

### 但可以确定

**"τ 越长 → 计时越准"这个具体预测被否定了。**

文献的"整合窗口"论断若成立，在 ready-set-go 这种**纯时间整合任务**上
应该最明显——被试必须在 set 后维持 t1 的记忆并倒计时。
这是我们能设计的最有利的检验场景。

**它失败了。**

## 九、方法学教训（第 21 条）

### 第 21 条：**用最有利的场景检验假设**

检验一个假设时，应该选**最有利于它成立**的条件，而不是最容易做的条件。

我们本来可以在任何数据上测"τ vs 解码"，但那是最弱的检验
（解码受多种因素影响，且不是文献论断的对象）。

选择 ready-set-go：
- 任务**纯粹是时间整合**（没有视觉辨别、没有运动规划）
- 脑区是 **DMFC**（文献中最高 τ 的区域之一）
- 有**逐试次行为**（可做 n=502 的检验）

**在这三个"最有利"条件叠加下仍然失败，这个否定才有分量。**

判据：**否定一个假设时，必须证明你在它最该成立的地方检验过它。**

# 脑域结构 (brain_domains)

把「脑功能域」从比喻变成架构约束的研究线。目标是: 让模型内部结构显式对应
脑区的功能分化, 并用神经数据检验这种对应是否真的有用。

## 设计要点

### 只改造状态转移矩阵 A

mamba 类 SSM 由三组参数控制: `A` (状态转移/时间常数)、`B`/`C` (输入输出投影)、
`D` (跳跃连接)。**本项目只把 A 改为域条件, 其余全部跨域共享。**

理由: A 控制状态衰减速率, 即「记忆保持多久」。不同脑区的更新频率与时滞
确实不同, 这是四个组件里与脑域对应关系最直接的一个。而 B/C 是输入输出映射,
跨域共享更省参数, 也更符合「共享基 + 域特化偏移」的设定。

### 低秩域偏移 (保号形式)

早期设计直接相加 `A_d = A_shared + offset`, 2026-10-17 首跑 GPU 时暴露缺陷:
offset 可正可负, 使 `A_d > 0`, 破坏 mamba「A 恒负 ⇒ 状态恒衰减」的稳定性保证
(实测输出爆炸至 1e19、反向梯度 nan)。现行实现改为**保号参数化**:

```
A_d = −( exp(A_log) · φ ),    φ = exp( tanh(offset) · c ),    offset = Σ_r α_r(d) · U_r
```

- `φ > 0` 恒成立 ⇒ `A_d < 0` 恒成立, 衰减保证不破
- `offset = 0` 时 `φ = 1`, 严格退化为原版 SSM (消融前提保持)
- `c` (默认 0.3) 限制域调制强度在 ±26% 内, 可经 `DOMAIN_C_BOUND` 覆盖
- 实测 `A_eff > 0` 元素数为 0

**参数占比更正**: 早期 README 写的 0.08% 只计了 `α` (K×R), 漏算低秩基 `U`
(R×d_inner×d_state = 196,608/层)。实测 mamba-130m 规模 24 层:
域专属参数 4,721,856 / 总 119.89M = **3.94%**。

域系数 `α` 压缩了「哪些脑区动力学相似」, 本身即可解释为一份脑区相似性地图。

### 初始化必须打破对称

`U` 与 `α` **不能同时零初始化**。因为 ∂offset/∂α ∝ U 而 ∂offset/∂U ∝ α,
两者皆零时梯度恒为零, 参数永远锁在原点。

这个 bug 极其隐蔽: 模型照常训练、损失照常下降, 但**域路由静默失效**, 光看
训练曲线完全发现不了。本项目的处理是 `U` 用小随机初始化、`α` 保持零 ——
起点仍严格等价于原版 mamba (消融前提不破), 同时 `α` 一开始就能收到梯度。

## 训练阶段域对照实验 (2026-10-17)

协议见下方陷阱 #4。受控任务: K=8 个功能域的粘性切换 AR(1) 过程
(每域独立系数 `a ~ U[0.30,0.98]`, `b ~ U[0.30,1.50]`), 模型只看输入 `u_t`,
域信息仅经路由进入 —— 干净单变量。5 种子 × 3 变体 × 900 步, 留出集 512 条序列。

| seed | A real | B shuffled | C none |
|---|---:|---:|---:|
| 0 | **0.0447** | 0.2940 | 0.4310 |
| 1 | **0.0127** | 0.1652 | 0.1897 |
| 2 | **0.0265** | 0.1767 | 0.2232 |
| 3 | **0.0223** | 0.1706 | 0.2066 |
| 4 | **0.1100** | 1.1379 | 1.4162 |

逐种子配对 (Δ = 前者 − 后者; 负 = 前者更好):

| 配对 | Δ 中位数 | Δ 均值 ± 样本 std | 胜出 |
|---|---:|---:|---:|
| real vs shuffled | **−0.150** | −0.361 ± 0.402 | **5/5** |
| real vs none | −0.178 | −0.368 ± 0.413 | 5/5 |
| shuffled vs none | −0.027 | −0.051 ± 0.063 | 5/5 |

**结论**: A 显著优于 B —— 域对齐有增益, 域结构设计得到支持。
关键判据在此: 若 A ≈ B 则增益来自参数量而非域划分; 实测 5/5 种子上 A 大幅胜出。

**保留的疑点** (不作结论, 记录待查):
- seed 4 三变体绝对值整体偏高 (real 0.081 vs 其他种子 ~0.015) —— 该种子环境参数更难,
  属环境难度差异; 配对设计已抵消此影响, 但不掩盖"绝对难度跨种子不均"这一事实。
- shuffled > none 的 5/5 一致小增益 (中位 0.053) 尚未解释: 置换后的标签仍保留
  序列级分布, 可能提供等效于"域先验"的弱信号。属后续调查项。

## 已知陷阱

**1. 域标签覆盖率有上限。** FlyWire 的 `cell_class` 有 22.9% 缺失 (全部来自
optic 类未细分神经元), 因此任何前缀归并方案的覆盖率上限都是 77%。这不是
实现问题, 是数据本身的性质。

**2. 节点特征泄漏。** FlyWire README 的基线显示, 仅用节点特征的 MLP 就能达到
98.5% 准确率 —— 因为 174 维特征含 79 个神经发生地的进出突触计数, 等于直接
编码了脑区身份。**域结构实验必须 mask 掉这部分**, 否则测不出域建模有没有用。

**3. 物种边界要显式标注。** Steinmetz 是小鼠, FlyWire 是果蝇, Schaefer 是人。
三者不可直接混用, 跨物种比较须注明。

**4. 必须有随机标签对照。** 打乱 domain_id 重跑, 若与真实标签表现相当, 说明
收益来自参数量而非脑区划分, 该结论必须被推翻重来。

> **2026-10-17 状态: 已执行。** 见上文「训练阶段域对照实验」。
> 结果: 真实标签 5/5 种子胜出 (Δ中位数 −0.157), 随机标签对照通过。
> 注意此对照只在**训练后**有意义 —— init 阶段模型对 id 的响应来自随机初始化的
> `α`, 与 id 是否真实无关 (对称性), 此时比较会产出误导性数字。

**5. `A_log` 必须钳制, 否则长训练必然 NaN。** ⚠️ 最贵的一个坑。

`A = -exp(A_log)` 里 `A_log` 是自由可训练参数, **无下界**。训练中 `|A|` 单调
增长 (实测 900 步内从 16 漂到 27.6)。单步衰减 `exp(-2.76)` 看着无害, 但块并行
扫描的块内累积是 `|A|·δ·block`:

```
-27.6 × 0.1 × 32 = -88.3   →   exp(-88.3) = 4.4e-39
float32 最小正规数 = 1.18e-38  →  下溢到次正规区
w = dBu / ea  →  除以接近 0 的数  →  inf / NaN
```

**这不是实现 bug, 是 mamba 的已知问题**: `state-spaces/mamba` issue #72 里
官方给的 root cause 描述完全一致 ——「`A = -exp(A_log)` has no lower bound」。

修复: 把 `A_shared` 的模长钳在物理有意义的区间

```python
a_shared = -torch.exp(self.A_log).clamp(0.5, 16.0)
```

- 下界 0.5: 最短记忆 ~2 token, 再小则退化为无状态
- 上界 16: 单步衰减 `exp(-1.6)=0.2`, mamba 原始 S4D-real 谱的上端

钳制后 `|A_eff| ≤ 16·exp(C_BOUND) ≈ 21.6` 与训练无关恒定, block=32 时累积
≥ −69.1 (`exp(−69.1)=1.1e−30`), 距 float32 下界还有 8 个数量级裕度。

**排查过程中的两个反面教训** (都曾让我得出错误结论):

1. **测速必须同时验正确性**。曾测出 `torch.compile` 有 3.9× 提速 (26.3 vs 102.6 ms),
   但测速脚本只计时、不检查输出是否有限 —— 实际上它算的是 NaN, 那个提速是假的。
   `verify_compile.py` 补上了逐元素 + 梯度对拍后才可信。
2. **eager 也 NaN, 与编译器无关**。`trace_nan.py` 显示 eager 在 step 465 崩溃、
   compile 在 618 —— 先怀疑 compile 是错误方向。诊断要先排除"与优化无关"。

诊断工具: [`arch/trace_nan.py`](arch/trace_nan.py) (逐 100 步记录 loss/梯度/
`a_eff` 范围), [`arch/verify_compile.py`](arch/verify_compile.py) (编译前后
前向+梯度对拍)。

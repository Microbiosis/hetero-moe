# 脑域研究线（brain_domains）

> 2026-10-14 至 2026-10-19 · 52 个实验 · 24 份文档
>
> **一句话结论**：脑区/功能域标签在信息论意义上与活动信号**冗余**。
> 但在这条探索路上，建立了**一个数据集、一套可信度量、24 条方法学教训**。

---

## 一、最终结论：能报告什么

| 量 | 值 | 信度 | 效度 |
|---|---|---|---|
| **净可预测性 R²(1)** | 0.18–0.22 | ✅ 三种分辨率稳定 | ⚠️ 未检验 |
| **200 类解码** | 7.6–24.8%（15–50× 随机）| ✅ 置换基线确认无泄漏 | ✅ 定义即功能 |
| **τ（主导时间尺度）** | **202 ms**（p10–p90 149–251） | ✅ 5/5 通过分辨率检验<br>✅ 正交不变（旋转下 0 变化） | ❌ **不预测解码** |
| **四轴不可替代** | 损失 82–97% | ✅ 消融一致 | ✅ 定义即功能 |

**唯一同时具备信度和效度的是解码本身**——因为它的定义就是功能。

### 不能报告

| 主张 | 为什么 |
|---|---|
| 脑区标签可改善模型 | 6 个实验全否定 |
| 跨物种守恒的动力学常数 | 唯一候选（kurtosis）被证明是 PCA 伪影 |
| τ 的解剖/功能意义 | 不预测解码能力 |
| 20 ms spike 上的 τ | 旧估计量量到噪声底（6.9 vs 271.8 ms）|
| τ 的跨物种比较 | 小鼠数据 50ms 分箱，无法做同样分析 |
| 存在客观稳定的层次划分 | 两种方法 ARI≈0，bootstrap <0.5 |

## 二、三个主要方向的结果

### 方向 A：域条件建模（6 个实验，全否定）

| 实验 | 问题 | 结果 |
|---|---|---|
| Phase 0 | 域可解码吗 | ✅ real 0.745 vs shuffle 0.317 |
| Phase 1 | 域作输入特征 | ❌ 域 ≈ 随机（+1.1% vs +1.0%）|
| exp2 | 域调制时间常数（合成）| ✅ +94.6%（但前提我构造）|
| exp2b | 同上（真实数据）| ❌ 域 vs 随机 −0.04% |
| exp3 | 域差异在哪 | mean_abs 最强 ε²=0.161 |
| exp4 | 该调哪个参数 | ❌ gain/A/C 全无效 |
| exp5b | L2 更细粒度 | ❌ 真实信号比 1.006 |

**结论**：域标签与活动信号冗余。可解码，但对任何下游任务无增量价值。

### 方向 B：跨物种统计量（4 轮，无守恒量）

| 轮次 | 关键发现 |
|---|---|
| exp6 | 人类离群 = **模态差异**（EEG vs spike），非物种 |
| exp7 | n_units 与物种零重叠，**校正不可识别** |
| exp8 | 补人类侵入式后，ε² 0.57–0.83，**规模匹配后不减** |
| exp8b | **kurtosis 是 PCA 流程产物**：纯噪声得 −0.828，真实 −0.792 |
| exp29 | **超额曲线形状跨物种一致**（r=0.72–0.96，高斯 r≈0）← 唯一正结果 |

### 方向 C：时间常数 τ（五轮，最终成功但无功能意义）

| 轮次 | 方法 | 结果 |
|---|---|---|
| exp11–14 | R²(k) 指数拟合 | ❌ 窗口重叠伪影 |
| exp15–19 | 固定窗口 + 双分辨率 | ❌ τ 固定在 bins 数 |
| exp20–21 | 多元 VAR(1) | ❌ 数据长度不足 |
| exp39 | VAR + 降采样验证 | ❌ 比值 1.6–1.9，0/5 |
| **exp40–41** | **ACF 全曲线拟合** | ✅ **5/5 通过，比值 0.993–1.000** |
| **exp42** | **τ vs 解码（构念效度）** | ❌ **ρ=−0.10，不预测** |
| **exp49–52** | **τ 的规范依赖性** | ⚠️ **估计量基依赖：EEG 偏 6%，spike 偏 39×** |


**② `primate-spike-20ms`（Dataset 仓库）**

https://huggingface.co/datasets/illusion-brain/primate-spike-20ms

273,918 个时间窗，猕猴与人类皮层内记录，均在 20 ms 放电计数栅格上，未做时间重采样。

| source | 物种 | 片段 | 窗口 | 区域 |
|---|---|---:|---:|---|
| `macaque_nlb` | *Macaca mulatta* | 72 | 187,067 | M1 / PFC / S1 |
| `human_intracortical` | Homo sapiens | 103 | 86,851 | M1 |

每窗 `(64, 40)` float16 = 64 个主成分 × 40 个 20 ms bin（800 ms），1.40 GB。

只有 `M1` 覆盖两个物种（254,899 窗）。

**②b bucket 内的其它视图**（不在 Dataset 仓库里）

```
hf://buckets/illusion-brain/brain-domains/
├── omnibrain/spike_view/        小鼠 Steinmetz     314,332 窗（50 ms）
├── omnibrain/eeg_view/          人类头皮 EEG       32,000 窗（旧子集，供追溯）
├── omnibrain/graph_view/        果蝇 FlyWire      139,255 节点
└── omnibrain4d/                 THINGS-EEG 四轴    26.53 GB（250 采样原生）
```

100 ms 版本的多源融合（1,409,850 窗）曾作为 `omnibrain-multi` 发布，已删除。
重建脚本 `build_omnibrain.py`、`build_macaque_view.py`、`build_human_invasive_view.py`、
`build_multi.py` 均在 `data/` 下。

**为什么只发布 20 ms 这一对**：五个来源的 bin 宽分别是 50 / 20 / 20 / 4 ms，
只有猕猴与人类皮层内这一对相同。想要「同一张量」就必须向最粗看齐，
而向最粗看齐等于对细的来源做不可逆的降采样。20 ms 这一对不需要任何重采样。

## 四、方法学教训（24 条）

| # | 教训 | 症状 |
|---|---|---|
| 1 | 循环论证 | ε²=0.9372–0.9374（所有组几乎相同）|
| 2 | 判据符号反 | ρ=−0.60 被误判为失败 |
| 3 | 正则化未标定 | α=1 时随机数据 R²=−1.86 |
| 4 | 窗口抽样破坏时序 | R²=−0.64，比噪声地板（−0.34）还差 |
| 5 | 假设未检验 | unit 数假说 ρ=−0.198, p=0.228 |
| 6 | 校正混淆协变量 | 效应量暴涨 −1404% |
| 7 | 降采样 ≠ 匹配 | 三个统计量全部朝噪声方向移动 |
| 8 | 特征合并列冲突 | 8 维曲线退化为 1 维 |
| 9 | 组内置换对标准差无效 | ratio 精确等于 1.00，p 精确等于 1.000 |
| 10 | 窗口重叠 + 窗内平均 | τ_bins 恒 3.5，17 个实验的 τ 结论作废 |
| 11 | 先做正控再读真实数据 | exp20 的 τ 比值完美（0.949/1.000/1.065）但 R²=−6.36 |
| 12 | 归一化不是中性的 | 同一数据纠缠熵 0.245 → 0.962 |
| 13 | "取前 N 个" ≠ "取最大的 N 个" | 人类数据静默消失 5 次 |
| 14 | "结构存在" ≠ "可稳定识别" | 有效秩 2.8/64 但需满秩才能 5% 精度 |
| 15 | Fisher z 在嵌套数据上失效 | [0.39,0.96] vs bootstrap [0.52,0.90] |
| 16 | 性能优化不能破坏正确性 | 批处理后准确率 15.6× → 3.1×，四组低于随机 |
| 17 | 先看平台资源再设计并行 | 优化 Job 内部一天，答案是不用 Job（Space 192 核）|
| 18 | 模型参数 ≠ 数据属性 | τ = 真实动力学 + 模型阶数 + 采样率 的混合 |
| 19 | 用多少点拟合决定稳健性 | AR(1) 用 1 点（1.71 漂移）/ ACF 用 250 点（1.000）|
| 20 | 信度 ≠ 效度 | τ 通过 5/5 分辨率检验，但不预测解码 |
| 25 | 统计量依赖基 | 逐成分 ACF 取中位数，旋转 5 次后 τ 变化 1.65 倍 |
| 26 | 中位数总能给出数值 | 502 个白噪声试次，旧估计量全部"拟合"成功 |
| 21 | 用最有利的场景检验假设 | ready-set-go 三条件叠加仍失败，否定才有分量 |
| 22 | 排除配置需独立于结论的理由 | 否则是挑数据 |
| 23 | 对比必须控制样本量 | exp45 的 A 每类 1 样本、B 每类 8 个 |
| 24 | 先验证结构是否存在，再构建结构 | 细化矩阵/可交换性/方差分解三项全不过，仍建了 24 个实验 |

## 六、如果要继续

### 最有价值的三个方向

1. **超额曲线的跨物种一致性**（`FINDINGS_DENSE_K.md`）
   - 唯一通过全部对照的正结果（高斯 r≈0，真实 r=0.72–0.96）
   - 但只有 3 个物种、10 个 k 点
   - 需要：更多物种、更多 k 点、留出验证

2. **用行为而非解码检验 τ**
   - 文献的"整合窗口"论断是关于行为的
   - THINGS-EEG 无行为数据，需换数据集（如 DANDI 上的决策任务）
   - 这是唯一能真正检验 τ 效度的路径

3. **四维数据集的张量方法**
   - 目前只用了「展平成 630 维 + 线性分类器」
   - CP/Tucker 分解可能揭示时间×频率×空间的结构
   - 但注意 exp26 的教训：可压缩性必须先验证

### 不建议继续

- 继续调 τ 的估计方法（已五轮，信度够了，问题在效度）
- 继续找域标签的用法（6 个实验全否定，且理论上冗余）
- 继续做跨物种统计量比较（混淆无法分离）

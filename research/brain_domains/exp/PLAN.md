# 实验依赖链（按执行顺序）

## Phase 0 — 域信号可行性 ✅ 已完成
**问题**: OmniBrain 的窗口是否携带 L1 域信息?
**设计**: session 内时间切分 70/30, 简单特征 + 逻辑回归, 组内打乱标签对照
**结果**: spike_view 明确存在
```
sess 04: real 0.783 vs shuf 0.057 (Δ +0.726)
sess 05: real 0.865 vs shuf 0.422 (Δ +0.443)
sess 06: real 0.764 vs shuf 0.412 (Δ +0.352)
sess 07: real 0.637 vs shuf 0.511 (Δ +0.126)
sess 08: real 0.769 vs shuf 0.083 (Δ +0.686)
```
**结论**: 域信息可解码 → 进入 Phase 1

## Phase 1 — 域条件建模 ⏳ 运行中
**问题**: 把 domain_id 作为输入, 能否提升**预测任务**性能?
（可解码 ≠ 对预测有用, 这是更强的命题）
**任务**: 下一步活动预测（自监督, 无需外部标签）
**三臂对照**:
- A `no_domain`: 只吃 x
- B `with_domain`: x + domain one-hot
- C `rand_domain`: x + 打乱 domain ← 排除"多了 6 个参数"的混淆
**判据**: B ≫ A 且 B ≫ C → 域有实质信息; B ≈ C > A → 收益只来自参数

## Phase 2 — 消融：域条件接入 SSM（待做）
**问题**: 把 Phase 1 验证过的 domain 条件接进 SSM 的状态转移矩阵,
是否优于同等参数量的无域 SSM?
**前提**: Phase 1 必须通过。若 Phase 1 失败, Phase 2 无意义。
**设计**: 沿用 domain_ssm.py 的 A_d = -(exp(A_log)·φ) 保号参数化,
对比 (a) 共享 A, (b) 域条件 A, (c) 域条件 A + 随机标签

## Phase 3 — 跨视图迁移（待做）
**问题**: 在 spike_view 上训练的域表征, 能否迁移到 eeg_view?
**前提**: Phase 1 通过 + 两视图都需要有可比的域标签
**难点**: EEG 只有 3 个 L1 域, spike 有 6 个, 交集为 sensory/association/motor
**设计**: 在交集 3 类上训练 spike → 测试 eeg, 对比从零训练

## Phase 4 — 跨物种泛化（待做）
**问题**: 小鼠(314k) → 人类(32k) 的域结构是否共享?
**前提**: Phase 3 通过
**设计**: leave-one-species-out; 报告"跨物种 vs 同物种"的性能落差

---

## 每一步的失败判据（避免自欺）

| Phase | 失败条件 | 后续动作 |
|---|---|---|
| 0 | Δ < 0.03 | 停止，域假说在该视图不成立 |
| 1 | B ≈ C 且都 > A | 域标签无信息，只增加参数 |
| 2 | 域条件 SSM ≈ 共享 A SSM | 域路由对动力学无贡献 |
| 3 | 迁移 ≤ 从零训练 | 跨视图表征不共享 |
| 4 | 跨物种 ≤ 随机 | 域结构不跨物种 |

**任何一步失败，都不修改判据去"抢救"结论。**

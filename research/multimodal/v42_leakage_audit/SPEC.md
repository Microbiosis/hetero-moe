# V42.0 — 多模态蒸馏泄漏审计:β_h 连续过渡扫描

> **日期**: 2026-10-10
> **状态**: ✅ Verified (10/10 单元测试 PASS, 11 β_h × 5 seeds = 55 学生 run + 5 教师 run)
> **复现命令**: `python3 examples/run_v42_leakage_audit.py` (CPU 约 24 分钟)
> **审计对象**: `v21_multimodal` 的 **+50.5%** 主张
> **一句话**: **该裕度全部来自泄漏。** 把损失里的直接目标项关掉(β_h=0),
> 学生从优于教师 **49.8%** 变为**略差于教师 0.5%**。

---

## 1. 泄漏通道:与 v16 结构完全相同

`examples/run_v21_multimodal_distill.py` 的学生蒸馏损失:

```python
loss = 0.7 * F.mse_loss(y_student, teacher_targets.detach()) + \
       0.3 * F.mse_loss(y_student, targets_truncated)
```

参数化后即 ``w_teacher = 1 − β_h``, **β_h = 0.3**。

> 这正是 v32 在 `v16_bert_student` 上判定为泄漏源、并压到 0 的那一个系数。
> v21 与 v16 的损失**结构完全相同**,裕度也应当同样归零 —— 本代就是去验证这一点。

## 3. 裕度裁决

| 口径 | 学生 | 教师 | 裕度 |
|---|---:|---:|---:|
| v21 原始 (β_h=0.3) | 0.1635 | 0.3255 | **+49.8%** |
| **关掉泄漏 (β_h=0)** | **0.3270** | 0.3255 | **−0.5%** |
| 捷径全开 (β_h=1) | 0.0001 | 0.3255 | +100.0% |

β_h=0 时 **5/5 个种子学生都不优于教师**。

> **结论:+50.5% 的裕度 100% 来自损失里的直接目标项。** 蒸馏机制本身没有带来任何
> 超越教师的能力 —— 纯蒸馏下学生与教师持平(略差 0.5%)。
>
> 与 v32 在 v16 上的结果**同构**:+47.5% → −0.1%。两次独立复现,同一机制。

## 4. 形状裁决:是平滑曲率,不是阈值

必须区分两种可能:

- **线性插值**: 效应与 β_h 成正比,无机制
- **阈值机制**: 关系在某处有折点

实测曲线单调且**平滑凸**衰减到 0:

```
一阶差分: -0.058 -0.054 -0.051 -0.044 -0.037 -0.031 -0.023 -0.016 -0.010 -0.003
二阶差分: +0.0035 +0.0030 +0.0077 +0.0064 +0.0062 +0.0080 +0.0071 +0.0062 +0.0065
```

二阶差分**全部同号且量级相当**(峰值集中度 `kink_ratio = 1.31 ≈ 1`,阈值判据是 3.0)。

> **裁决:`smooth_curvature` —— 曲率真实存在(second/噪声 = 2.24)但没有孤立折点,
> 因此不存在阈值机制。** 形状本身就是"逐步把损失从教师换成目标"的饱和曲线。

## 5. 本代工具的两处自我纠正

这两次都是**实测踩出来的**,值得单独记:

1. **除零产物被当成信号**: 第一次冒烟只有 1 个 seed,各 β_h 的 sd 均为 0,
   残差/噪声算出 `1e10` 量级,把一条平滑曲线判成 `threshold`。
   已加 `MIN_USABLE_NOISE` 护栏 —— **无重复样本 ⇒ 噪声未定义 ⇒ 拒绝下结论**。
2. **判据只看幅度不看形状**: 修好护栏后 5 seed 仍判 `threshold`,因为函数只比较
   曲率幅度与噪声,没有看二阶差分是**孤立尖峰**还是**系统性同号**。
   已改为四分类(linear / smooth_curvature / threshold / inconclusive)并加
   `KINK_RATIO_THRESHOLD = 3.0` 显式阈值。

两条都属于同一类错误:**用一个未经验证的判据给机制下结论**。
第一次的教训(v40 的均值骗人)是同一族。

## 6. 局限(诚实边界)

- 教师基线沿用 v21 的 **in-sample** 口径,学生沿用 v21 的 **held-out** 口径。
  该不对称**不利于**学生,因此本代结论偏保守 —— 若统一口径,β_h=0 处只会更差。
- β_h=1.0 处学生 MSE 掉到 0.0001,是目标项的纯捷径形态(与 v32 的 v16 观察一致)。
- 全部在 CPU 沙箱:`D_shared=256`,序列长 16,合成 class-direction 目标。
- 本代只审 v21 的**多模态蒸馏**裕度,**未**审 v23/v23b 的 toy VQA 可行性
  (那两条已由 v23b 自身证伪)与 v24 的 CLIP 教师 pipeline(端到端从未跑通)。

> **状态**: ⏳ **跑批中**（裁决待定；本文件 §4 待回填）

> **一句话**: S3 是 A1 激活级路线的**语义层**判据 —— 前两代（v77 真模型可用性、v80 注入算子）只回答「机制能不能跑」，本代第一次回答「**注进去的信息，目标模型读不读得出来**」：用 token 级 ridge 探针在留出集上读回源槽激活，臂间配对置换检验给出 p，深度语义用块内分层置换检验，同层 vs 跨层给中位增量。

## 0. 本代做了什么 / 没做什么

| | |
|---|---|
| **做了** | 在**真模型**上按协议 §2.1 的块网格跑满四臂；token 级 ridge 探针读回源槽激活（留出集 R²）；P1a / P1b / P2 / P3① / P3② 五项主判据 + P1c（ViT 平行臂）+ P4 否决规则；臂间配对置换（10⁴ 次）与块内分层置换；5 个 nuisance 种子；逐块 JSONL checkpoint + 断点续跑 |
| **没做** | 任何底座权重训练；任何能力指标（准确率之外的）；任何 A1 总判定（S3 只是 A1 的一步）；ViT 臂不进跨模型配对统计 |

**为什么 S3 必须在 S2 之后**：v80 已把注入算子落地并证明「零注入逐位等价、注入量精确归一化、四臂跑得通、读出层扰动可见且没把模型搞坏」。S3 站在这六项机械前提上，只加**一个**机制 —— **语义读回**（探针）。

## 1. 口径（全部来自协议 §2.1–§2.6，未新增自由度）

### 1.1 块网格（协议 §2.1）

| 方向 | 源层 × 目标层 | 块数 |
|---|---|---:|
| Qwen→BERT | L_Q(8) × L_B(4) | 32 |
| BERT→Qwen | L_B(4) × L_Q(8) | 32 |
| ViT→ViT（自跨层臂） | L_V(5) × L_V(5)，排除同层 | 20 |
| **合计** | | **84** |

层阶梯：`L_Q = (0,1,2,3,6,12,18,23)`、`L_B = (0,1,2,3)`、`L_V = (0,3,6,9,11)`。

### 1.2 四臂（协议 §2.5）

| 臂 | 注入内容 | 作用 |
|---|---|---|
| `arm0_no_inject` | 零注入（hook 装着、delta 全零） | 基线；本代复核 v80 的 G1（逐位等价） |
| `arm1_slot_Q` | 源模型第 l 层 **Q 槽**激活 | **主臂** |
| `arm2_wrong_slot_O` | 同一源层的 **O 槽**激活 | 槽特异性对照 |
| `arm3_random_dir` | 共享空间内的**随机方向** | 排除「随便什么内容都能流」 |

### 1.3 注入算子（协议 §2.3 修订后口径，与 v80 逐位同款）

```text
源模型 A 第 l 层槽 s 的激活   a_s ∈ R^{D_A}      （样本级 mean-pool，原生维）
共享空间方向                   z   = a_s @ P_Aᵀ    （P_A：v62 正交投影，256 维）
映回目标模型 B 的隐空间        Δ_B = z @ P_B      （**没有任何学出来的映射**）
强度（逐样本）                 λ_i = 0.03 · `h_B^{j,i}`_F / `Δ_raw,i`_F
注入                           h_B^j ← h_B^j + λ_i · Δ_raw,i
```

- **λ = 0.03**（块 Frobenius 口径）—— 由 v80 的 S2-1 标定选出，本代**直接沿用**，不重新标定。
- 注入点 = 目标模型第 j 层输入（`forward_pre_hook`）；读出层 = 注入层 j 的**输出**。
- **样本级广播**：源槽激活按样本 mean-pool 后广播到目标的 T 个 token（两模型 token 网格不可配对，v79 已证）。

### 1.4 探针（协议 §2.6）

| 环节 | 口径 |
|---|---|
| **特征** | 目标模型读出层（第 j 层输出）的 **token 级** 隐状态，**逐维标准化**，**去掉每个样本的第 0 个 token**（去 BOS） |
| **目标** | 源模型第 l 层对应槽激活的**样本级**标量读数，按样本广播到它的 T 个 token |
| **模型** | ridge 闭式解（线性），λ 由**训练样本内** 5 折分层 CV 在写死网格 {(1e-3,1e-2,1e-1,1,10,100,1000)} 上选出 |
| **评价** | **留出集**（测试样本全程不参与选 λ）上的预测 R²，SS_tot 围绕**训练集** y 均值（诚实预测 R²） |
| **辅助读数** | 样本级 mean-pool 探针 —— **预登记、不参与任何裁决**，用于区分「信息没流过去」与「探针读不出来」 |
| **标签可读性** | 复用 v78 的 `_ridge_probe` 口径（4 类 + 留出集），λ **独立标定**（ViT 臂 32 样本下写死的 λ=1.0 欠正则，留出准确率 0.000 < 随机 0.25） |

### 1.5 统计口径（协议 §3）

| 判据 | 统计量 | 检验 |
|---|---|---|
| **P1a** 穿透 | 块级 Δ = 中位(arm1) − 中位(arm0) 的 **r2_q** | **臂间配对置换**：块内逐观测交换两臂标签；块统计量 = 块内种子中位数；总统计量 = 块间均值；10⁴ 次 |
| **P1b** 槽特异 | arm1 vs arm2、arm1 vs arm3 的 Δ | 同上（两组各一次） |
| **P2** 深度语义 | 同层块的中位 Δ vs 跨层块的中位 Δ | **块内分层置换**：在块集合内按同层/跨层重分配，保持块数不变；10⁴ 次 |
| **P3①** 区间 | 每个注入臂块的 final 输出相对扰动 | 逐行区间检查 (1e-3, 0.5] |
| **P3②** 选择性 | arm1 vs arm0 的 **r2_o**（非目标槽）中位 Δ | 臂间配对置换；规则：Δ ≤ 0 或 p ≥ 0.05 |
| **P1c**（不参与主裁决） | ViT 块的标签准确率 arm1 − arm2 | 符号检验（v75 `sign_test`），α = 0.05 |
| **P4** 否决 | P1a 的块级中位 Δ | Δ ≤ 0 或不可判定 ⇒ A1 必须转训练版 |

- **主判据集 = 64 个文本块**（协议 §2.1/§2.2）；ViT 20 块是平行臂，单独报告。
- α = 0.01；置换 10⁴ 次 ⇒ 最小可达 p ≈ 1e-4；**报告必须同时给 p 与置换次数**。
- 5 个 nuisance 种子 (0,1,2,3,4) 只影响**共享空间投影 P** 与 arm3 的随机方向；arm0 与种子无关 ⇒ 逐种子各记一行（值相同），以保证臂间配对置换每个块有同样多的观测（块内中位数才成立），且不需多跑前向。

| 方向 | arm0 基线 R² | arm1 R² | **Δ(arm1−arm0)** | 为正块数 | Δ vs 随机方向 | Δ vs 错槽 O | 非目标槽 Δ_O |
|---|---:|---:|---:|---:|---:|---:|---:|

| **BERT→Qwen** | +0.059532 | +0.134705 | **+0.069396** | **32/32** | **+0.114476** (32/32) | −0.003637 (9/32) | +0.014121 (31/32) |

三条读法：

1. **arm0 的基线不是 0**：不注入时探针已经能读出源槽（Qwen→BERT 方向中位 **0.146**，最高 **0.400**）⇒ **绝对 R² 不是穿透量**，只有 Δ 才是。这条若不扣除，P1a 会被高估两个数量级。
2. **穿透是方向不对称的**：BERT→Qwen（**32/32** 块全正）与 ViT→ViT（**20/20**）都很强，Qwen→BERT 基本为 0（+0.0008）。
3. **随机方向远不如真实槽内容**（arm1−arm3 的 p = 0.0，299/320 正）⇒ 效应**内容特异**，不是「随便注入什么都能流」。

### 4.4 三项失败的共同机理（post_hoc_only；判据结论一字未改）

**核心事实一：同层内 Q 槽与 O 槽高度可互换。**
`s3_slot_similarity.py` 实测**留出集 R²(a_Q → a_O)**（诊断快照 `results/qo_similarity.json`）：

| 源模型 | 逐层 R²(a_Q → a_O) |
|---|---|
| BERT（D=256） | L0 **+0.4399** / L1 **+0.4453** / L2 **+0.3360** / L3 +0.1460 |
| Qwen（D=896） | L0 +0.1918 / L1 −0.0029 / L2 +0.1139 / L3 +0.3315 / L6 +0.2955 / L12 −0.0118 / L18 −0.0596 / L23 −0.1820 |
| ViT（D=768） | L0 **+0.5471** / L3 +0.0452 / L6 +0.0442 / L9 +0.0371 / L11 +0.1343 |

把 84 个块按「Q/O 可互换度」分档后再看 P1b：

| 分档 | 块数 | Δ vs 错槽 O（arm1−arm2） | 为正块数 | Δ vs 随机方向（arm1−arm3） | 为正块数 |
|---|---:|---:|---:|---:|---:|
| **R²(a_Q→a_O) ≥ 0.30**（高度可互换） | 32 | **−0.007875** | **3/32** | **+0.031409** | **32/32** |
| **R²(a_Q→a_O) < 0.30**（不可互换） | 52 | **−0.000185** | 26/52 | +0.007122 | 51/52 |

**读法**：在 Q/O **高度可互换**的块上，注入 O 槽**反而**让 Q 槽更可读（arm2 明显高于 arm1）；在 Q/O **不可互换**的块上，arm1 与 arm2 **完全一样**（中位差 −0.000185，26/52 为正）。⇒ **注入起作用的部分不是「某个特定的槽」，而是源激活里那个跨槽的公共成分**。

**核心事实二：深度对应同样不存在，而且方向是反的。**
BERT→Qwen 方向：**同层中位 +0.004775（4 块）vs 跨层中位 +0.121475（28 块）** —— 跨层比同层**高 25 倍**。P2 因此以 p = 0.8714 失败。

**核心事实三：注入抬高的是「整体可读性」，不是「目标槽可读性」。**
Δ_O 中位 **+0.000836**（p = 0.0，248/320 正）⇒ 注入 Q 槽也把非目标槽抬起来了（P3② 因此失败）。

**⇒ 三条合起来的结论**：注入确实把源模型的信息搬进了目标模型（P1a 过），但搬过去的是**跨槽、跨深度、低秩的共同成分**，不是「某个槽 × 某个深度」的内容。这与 v78 D1 / v79 的机理结论**完全咬合**：跨模型共享的是低秩共同成分 ⇒ **没有可对齐的跨模型槽对应关系**（v79 的负结果）。

**⇒ 对 A1 的直接含义**：A1 激活级路线的核心前提「跨模型槽对应 + 深度对应」在语义层**被证伪**。P4 未触发（Δ_P1a 中位 > 0），所以协议**没有**强制「转训练版」；但 A1 的激活级语义关卡**未通过**，且失败原因不是「效应太小」而是「效应不是预登记的那一种」。

### 4.5 信息天花板（post_hoc_only；不参与任何裁决）

`s3_ceiling_diag.py` 实测**注入本来就带不动的部分**（快照 `results/ceiling_diag.json`）：注入量 = a_s @ P_Aᵀ @ P_B，P_A 是 256 维正交投影 ⇒

| 源模型 | 隐层维 | **r2_project（注入能带走的方差比例）** | Δ / r2_project（传输效率下界，中位） |
|---|---:|---|---:|
| **BERT** | 256 | **1.000000**（256 维投影对 256 维激活**无损**） | **+0.069396** |
| Qwen | 896 | 0.283–0.298（中位 0.2882） | +0.002855 |
| ViT | 768 | 0.326–0.341（中位 0.3318） | +0.053942 |

**BERT 那一行是关键**：BERT 隐层就是 256 维 ⇒ 共享空间载体对 BERT **完全无损**（r2_project = 1.000000）⇒ BERT→Qwen 是「源侧零信息损失」的传输，Δ = +0.069396 就是真实传输。**Qwen→BERT 输在源侧**（只带走 29% 的方差）**且传输也近乎为零**。

### 4.6 已知缺陷（留档，不得当 bug 修掉）

**ViT 臂的位置切分使标签探针恒为 0**。`fetch_vit_images` 的图序是**按类排列**的（类 0×16 → 类 1×16 → 类 2×16 → 类 3×16），而探针按**位置**切分（前 32 训 / 后 32 测）⇒ **train 类别 {0,1} 与 test 类别 {2,3} 完全不相交** ⇒ 标签岭分类器在从未见过的类上测 ⇒ 准确率**恒为 0.0000**。

- **影响面**：ViT 臂的 `label_acc`（全 0）与 **P1c**（sign_p = 1.0 ⇒ **不可判定**，不是负结果）。
- **不影响**：主裁决集（64 个文本块）的任何一项 —— 文本臂 train/test 4 类全覆盖（train 24/16/11/13、test 13/16/15/20），无此问题。
- **修正需要**：改图序（类内切分 ⇒ 位置切分）或改探针取 split ⇒ **必须重跑 ViT 臂**（约 1.4 h）。P1c 明确**不参与**主裁决，故本代**不重跑**；修复留给下一代（见 §7）。

### 4.7 引用本代必须带上

1. **P1a 过、P1b/P2/P3② 不过** ⇒ 「信息流存在」与「信息流有槽/深度选择性」**必须成对引用**；只引前者会读成「晶壁系的信息流成立」，只引后者会读成「完全没有信息流」—— **两个都不对**。
2. **绝对 R² 不是穿透量**：arm0 基线最高 0.400（共享成分）⇒ 引用 r2_q 必须同时给 arm0 与 Δ。
3. **穿透强度与注入幅度在 Qwen 中层是同一件事**（j ∈ {3,6,12} 放大 ~117 倍）。
4. **P4 未触发**：协议**没有**因本代强制「A1 转训练版」；A1 激活级语义关卡**未通过**，原因不是效应太小。
5. **ViT 臂的 P1c 不可判定**（§4.6），不得当作负结果引用。
6. 本代**不训练**任何底座权重、**不产生**任何能力指标、**不产生** A1 的总判定。

## 5. 局限（引用本代必须带上）

1. **注入量是 a_s 的 256 维投影** ⇒ 探针读回的信息上限受该投影限制，读数只作**相对增量**解读（协议 §5 第 7 条）。
2. **ViT 臂只作方向性对照**，不与文本对合并（协议 §2.2 / §5.3）；P1c 单独报告，不参与主裁决。
3. **层号 ≠ 相对深度**；「同层」指层号相同（协议 §5.1）。
4. **探针目标按样本广播** ⇒ 每样本只有 1 个独立目标值；token 级特征的泛化由训练集内 CV 选出的 λ 控制。
5. **Qwen 残差流在第 3 层量级爆炸**（v80 实测 RMS 0.277 → 2.092）⇒ 落在该层附近的注入绝对幅度被放大 ~117 倍，P2 的深度读数必须把这一放大差异记在账上。
6. **绝对 R² 被共享成分占满**（arm0 基线最高 0.400）⇒ 只有 Δ 是穿透量；引用 r2_q 必须同时给 arm0 与 Δ。
7. **注入只能带源激活的 256 维子空间**：BERT 无损（r2_project = 1.000000）、ViT 33%、Qwen 29%。
8. **ViT 臂的标签可读性探针失效**（位置切分 ⇒ 类别不相交）⇒ P1c 不可判定（见 §4.6）。
9. **本代不产生 A1 的总判定**（协议 §5.7）。
7. **本代不训练任何底座权重** ⇒ 与权重级 G1/G2 正交。

## 7. 已知缺陷与下一代

| 缺陷 | 影响 | 处置 |
|---|---|---|
| **ViT 臂位置切分 ⇒ 标签探针恒 0**（§4.6） | 仅 ViT 的 `label_acc` 与 **P1c**（不参与主裁决） | 下一代修：改 `fetch_vit_images` 的图序为「类内前一半 train / 后一半 test」，**重跑 ViT 臂**（约 1.4 h）。本代**不重跑**（P1c 不参与主裁决，阈值一条未动） |

| **P1b 的对照区分力有限**（§4.4） | P1b 失败**不能**直接读成「槽对应不存在」 | 下一代若要判槽对应，须**按可互换度分档**设判据（本文已给出分档读数），而不是用单一汇总统计量 |

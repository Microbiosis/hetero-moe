# research/weight_fusion/ — 权重级合并研究线

> 本线回答的问题：**异构底座的权重能不能在公共槽空间里合并成一套新权重？**
> 与 `aligner` 线的区别：aligner 线做的是**激活级**对齐，融合发生在 canonical token 那一层；
> 本线做的是**权重级**搬运与合并（主线「晶壁系」的相消相融那一步）。

## 开线原因

主线正本 §6 第 1 项「另开研究线还是挂到 aligner 线」—— 选**另开**。
理由：权重级合并要引用的判据（权重相似度、搬运映射、合并后的端到端指标）与 aligner 线的激活级口径不同，
混在一线会让「同槽更相似」这类主张在两套口径之间互相污染。

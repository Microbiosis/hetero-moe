**BERT 全部干净**（L0–L4：raw 122.8 / 123.2 / 147.2 / 159.4 / 148.4，top1 维占比 0.029–0.123）
⇒ 塌陷是 **Qwen 特有**的 massive activation，不是本仓库实现的产物。

**三个可执行的修法**（按效果）：逐 token L2 标准化（3.8→263.7）≈ 去首 token（3.8→282.3）
> 逐维标准化（3.8→243.8）≫ 剔除 top4 维（3.8→62.5，不够）。

> ⚠️ **两处「修法排序」口径不同，勿混读**：本节排的是**塌陷层内**的救回效果（L4：去首 token 282.3 > 逐 token L2 263.7 > 逐维标准化 243.8 ≫ 剔 top4 维 62.5）；而快照 `D4_recommendation.token_level_rescue_best` 排的是**全部层 × 两个模型**的中位数（含本来就健康的高层），该口径下**逐维标准化**中位最高（218.1）、token 去均值次之（214.9）、逐 token L2 第三（210.5）。二者回答的不是同一个问题：**塌陷层里怎么救** vs **全局默认该怎么处理**；S3 用的是前者（token 级探针）还是后者（样本级），取决于探针单位。

## 2. D2：共同成分确实主导（PC1 占 88.8% 方差），但**去掉它并不能救 Q 槽、只会杀 O 槽**

| 量 | 值 |
|---|---|
| PC1 / PC2 解释的方差 | **0.8876** / 0.0395 |
| 每个槽表示被这 2 个 PC 解释的 R² | mean **0.631** / max **1.000** |
| 原始口径（v77 的 B5） | 占优 12/16，p=0.0768，中位差 +0.0738 |
| 残差化后（去掉 2 个 PC） | 占优 **10/16**，p=0.4545，中位差 +0.0507 |
| 残差化后 **Q 槽** | 占优 **8/8**，p=**0.0078**，中位差 +0.1078（原始 +0.1074，**几乎不变**） |
| 残差化后 **O 槽** | 占优 **2/8**，p=0.2891，中位差 −0.0542（原始 −0.0154，**更差**） |

**读法**：

1. **Q 槽的槽特异信号是真的**：它**不是**共同成分带来的 —— 去掉共同成分后一点没变，
   仍然是 8/8、p=0.0078。
2. **O 槽的「匹配」几乎全部是共同成分**：去掉共同成分后 O 槽从 4/8 掉到 2/8、p=0.289 ⇒
   **O 槽本来就不跨模型携带槽特异信息**（它跨模型共享的只是句子语义）。
3. ⇒ **「去掉共同成分」不是 B5 功效不足的解法**（它对合并判据反而更差：10/16、p=0.45）。
   B5 的真正修法是 **按槽分设判据 + 扩块数**（见 §5）。

## 4. ⚠️ 对 v77 的一条订正（比本代任何数字都重要）

v77 的 `falsified` 第 2 条写的是：

> 「Qwen 的 hidden state 可直接喂线性探针读语义」→ **证伪** …… ⇒ S3 的探针读数必须控制有效秩，
> 否则 P1a/P1b 会被少数维绑架。

**D3 的实测说明这条推论过强**：

- 「token 级有效秩塌陷」这个**事实**成立（v77 的数字没错）。
- 但「探针会被绑架」**不成立**：样本级 mean-pool 的表示有效秩 47–62、标签准确率 0.61–0.70。
  massive activation 之所以没伤到探针，是因为它是**与标签无关的常量方向**——它占了方差，
  但不是信号；线性探针有自由度把它忽略掉。

⇒ **订正后的表述**：
「token 级有效秩在 Qwen 深层塌到个位数（少数维独占 95–97% 方差 + BOS token）；
**跨模型的样本级探针不受影响**（pooled 有效秩 47–62、标签准确率 0.61–0.70）；
只有当探针单位是 **token 级**时，才必须逐维标准化或去 BOS。」

## 5. 基于缺陷的解决方案：S3 的可预登记口径

| # | 缺陷（来源） | 归因（v78 实测） | **解决方案** | S3 预登记 |
|---|---|---|---|---|
| **D-1** | Qwen token 级有效秩塌到 3.8–10.5（v77 B4） | **少数维主导**（深层 top1 维独占 95–97% 方差）+ BOS token；BERT 干净 | 探针单位取**样本级 mean-pool**（无需处理）；若必须 token 级，则**强制逐维标准化或去 BOS** | P1a/P1b 的探针单位 = 样本级 mean-pool（与 v77 同口径）；token 级仅用于 P3 守门且必须逐维标准化 |
| **D-2** | B5 功效不足（占优 12/16、p=0.0768） | 共同成分（PC1 占 88.8% 方差）淹没错槽基线；但残差化对 Q 槽**零影响**、对 O 槽是**灾难** | **不做残差化**；改为**按槽分设判据 + 扩块数**，主检验换成 v75 口径的**臂间配对置换** | Q 槽单独作 P1b 主判据；块数 ≥32；α=0.01（沿用 v75） |
| **D-3** | O 槽跨模型对应不成立（4/8） | O 槽的「匹配」几乎全来自共同成分 ⇒ **不是槽特异** | 首代**只把 Q 槽当跨模型信息流载体**；O 槽**预登记为「预期不成立」的反向对照**，不再当必过项；K/V/expand/contract 待后续诊断（K/V 有 GQA 维度差） | S3 首代槽范围 = **Q 槽**；其余槽只作探索记录 |
| **D-4** | 注入方向在深层不可靠（alignment −0.162） | 残差流不原样携带注入方向 | 判据改用**可读性**（探针 R² 增量），方向只作描述性衰减曲线 | P1a = arm1−arm0 的探针 R² 增量（配对置换）；alignment **不进判据** |
| **D-5** | 符号检验的块数瓶颈（n=16 需 ≥13 个正号） | 功效由块数决定，不是由样本数决定 | 块数扩到 ≥32；**开跑前先过功效门槛** | 块数 <32 ⇒ 不开跑（与 v75 的 α 纪律同款） |

### 5.1 扩块数的现成来源（供定范围用）

| 来源 | 块数贡献 | 代价 |
|---|---:|---|
| 加模型对（ViT↔BERT、Qwen↔ViT） | ×3 | ⚠️ 路线 β 下 ViT 的**层栈健康**限制已解除（v77 B4：最大范数比 3.52、有效秩 83–273），但**输入同源**限制**未解除**（ViT 只吃图像、文本模型只吃文本 ⇒ 跨模态配对无意义）⇒ ViT 只能以「自跨层臂 + 槽特异性对照」参与 |
| 加槽（K/V/expand/contract） | ×3（再 ×2） | K/V 是 GQA 非方阵（Qwen K/V 激活维度 128 vs BERT 256）⇒ 跨模型可比性要先定义；expand/contract 维度 4864/1024/3072 差异大 |
| 加层对（l≠j 的跨层对） | ×N | BERT 只有 4 层 ⇒ 层对空间被 BERT 限制；但可加「同层 + 跨层 1→3」两类 |

### 5.2 用户拍板结果（2026-11-16）—— 已落成 S3 预登记协议

| 议题 | 拍板 | 协议去向 |
|---|---|---|
| 首代槽范围 | **Q 槽为主 + 其余槽探索** | 注入源 = Q，错槽 = O，其余槽只作读出侧探索 |
| 块数补齐 | **加跨层对** | 文本对 **64 块**（功效门槛 ≥32） |
| ViT | **进首代** | 以「自跨层臂 + 槽特异性对照」参与，**不进跨模型配对统计**（输入不同源） |
| 探针单位 | **token 级 + 逐维标准化** | token 级特征 + 逐维标准化 + 去 BOS；按样本留出读数 |

**S3 的正式预登记协议正本**：[`docs/S3_PROTOCOL.md`](../../docs/S3_PROTOCOL.md)。本节只记拍板结果与其去向，口径细节不复述。

⚠️ **本节更正一处本代自己的初稿判断**：初稿写「加 ViT（推荐，因 ViT 已健康且能 ×3 块数）」——那只**解除了 ViT 的「层栈健康」限制**（v77 B4：最大范数比 3.52、有效秩 83–273），**没有解除「输入同源」限制**：ViT 只吃图像、Qwen/BERT 只吃文本 ⇒ ViT 无法直接进入「同样本上 Q 槽↔Q 槽」的跨模型配对。拍板「进首代」后的落地口径见 S3_PROTOCOL §2.2。

## 6. 边界（引用本代的一切数字都必须带上）

1. 本代是**诊断代**：任何「去掉共同成分后更好」的读数，**口径是看到 v77 结果后定的**，
   不作为 P1b 判据；S3 若采用，必须在新语料/新块上**重新预登记**确认。
2. 共同成分的 PCA 在**全部样本**上估计（无监督变换）；若 S3 采用，须在训练集上估计、测试集上应用。
3. 标签探针只用 128 条（64 训 / 64 测），准确率是**粗读**，不是能力结论。
4. 诊断只覆盖 Qwen/BERT（首代范围）；ViT 只在 v77 B4 里有健康度读数，不进本代诊断。
5. 本代**没有**注入臂 ⇒ 任何关于「注入是否有用」的问题仍未回答。

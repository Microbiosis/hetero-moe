> **一句话**: S3 查清了「信息流分不清」的根因 —— **同层内 Q 槽与 O 槽高度可互换**（BERT L0/L1 的 R²(a_Q→a_O) = 0.44/0.45），倒进同一个残差流容器必然分不清；本代不再指望信息自发流，改为**显式修管道**：在目标模型的正文**之前**开 K 个专属位置，把源信息写进去并让模型把它们当真 token，**按通道编号**区分槽身份 ⇒ 把「分不清」从容器问题变成可证伪的管道问题。

## 1. 从 S3 到本代：为什么是「管道」

### 1.1 S3 留下的三个硬事实

1. **信息流存在**（P1a 过，p = 0.0，arm1 ≫ 随机方向臂）⇒ 信息**已经在**目标模型里，管道不需要搬运，只需要**分流 + 贴地址**。
2. **同层内 Q 槽与 O 槽高度可互换**（留出集 R²(a_Q→a_O)：BERT L0/L1 = 0.4399/0.4453、ViT L0 = 0.5471）⇒ **两个内容高度重叠的东西倒进同一个容器，必然分不清** —— 这是**容器**问题，不是探针不灵。
3. **深度对应不存在**（同层 +0.002586 vs 跨层 +0.002295，p = 0.8714）且 BERT→Qwen 方向上跨层反而高 25 倍。

### 1.2 可行性探针（**post_hoc_only，不参与任何裁决**）

探针脚本：[`pipe_probe.py`](pipe_probe.py) / [`pipe_probe2.py`](pipe_probe2.py) / [`pipe_probe3.py`](pipe_probe3.py) / [`pipe_probe4.py`](pipe_probe4.py)（本代包内）。探针**测的是机制可行性**，阈值与判据另行预登记于 §3。

**探针 2（N=128，j=0，λ=3，管道 8 位全写）**

| 读数 | 零内容 | 随机方向 | Q 槽内容 | O 槽内容 |
|---|---:|---:|---:|---:|
| 管道位置注意力权重 | 1.6332e-02 | 1.8408e-02 | **2.5301e-02** | 1.7581e-02 |
| 正文可读出 a_Q 的 R² | +0.3276 | +0.2692 | **+0.4270** | +0.2512 |
| 正文可读出 a_O 的 R² | +0.3470 | — | +0.3431 | +0.3461 |
| 最终输出相对扰动 | — | — | 0.2781 | 0.2156 |

- **Q 内容 vs 零内容**：每样本注意力差 **128/128 为正**，符号检验 p = 2.9e-39 ⇒ **管道按内容被读取**。
- **Q 内容 vs O 内容**：每样本注意力差 **128/128 为正**，p = 2.9e-39 ⇒ **模型自己分得清 Q 槽与 O 槽**（这正是 S3 的 P1b 所缺）。
- **选择性**：注入 Q 槽**没有**抬高 a_O 的可读性（+0.3431 vs 零基线 +0.3470）⇒ 非目标槽不普涨（S3 的 P3② 所缺）。
- **两通道地址**：槽 0–3（Q 管道）注意力 2.8810e-02 vs 槽 4–7（O 管道）1.9378e-02；按管读 a_Q：Q 管 **+0.3774** vs O 管 **+0.2836** ⇒ **按通道编号读能分清**。

**探针 3（写入点固定第 0 层，N=128，Qwen 目标，通道 0 = 位 0..3 / 通道 1 = 位 4..7）**

| λ | 臂 | 末层相对扰动 | 第 0 层通道 0 注意力 | 第 0 层 flip（ch0−ch1） |
|---|---|---:|---:|---:|
| 1 | zero | — | 1.5643e-02 | −1.3833e-03 |
| 1 | **Q（通道 0）** | 0.1746 | **2.1785e-02** | **+5.9576e-03** |
| 1 | **O（通道 1）** | 0.1750 | 1.5970e-02 | −1.4653e-03 |
| 1 | rand（通道 0） | 0.1505 | 1.6881e-02 | −0.0148e-03 |
| 3 | zero | — | 1.5643e-02 | −1.3833e-03 |
| 3 | **Q（通道 0）** | 0.2649 | **2.8810e-02** | **+1.3777e-02** |
| 3 | **O（通道 1）** | 0.2089 | 1.6047e-02 | −3.3312e-03 |
| 3 | rand（通道 0） | 0.2822 | 1.8704e-02 | +1.9789e-03 |

- 第 0 层上：Q 内容在通道 0 ⇒ flip **+5.96e-03**（λ=1）/ **+1.38e-02**（λ=3）；O 内容在通道 1 ⇒ flip **−1.47e-03** / **−3.33e-03** ⇒ **通道寻址在写入层成立**（模型偏向**有内容**的那条通道）。
- ⚠️ **探针 4（深度可读性）的读数不可用**：它把 token 级探针的 ridge λ **固定**在 10.0（D=896 上严重欠正则），跑出 **R² 为负**（如 j=0 的 −0.4041）⇒ 该探针只作**方法学记录**（说明 token 级探针的 λ 必须由 CV 选，不能拍一个数），**管道内容的深度剖面由正式跑批给出**（正式跑的 λ 由训练样本内 5 折 CV 在写死网格上选出）。
- Q 内容（2.18e-02 / 2.88e-02）显著高于随机方向（1.69e-02 / 1.87e-02）⇒ 注意力响应的是**内容**，不是「管道里有个大向量」。
- **深层（第 1/2/3/6/12/18/23 层）的注意力对内容不稳定**（λ=3 时 `flip(Q)−flip(O)` 在第 1/2/3/6/12/23 层全为负）⇒ **注意力只在写入层（第 0 层）作机制读数**（修订 2）。

**探针逮到的三个设计要点（直接写进正式实现的硬约束）**

| # | 要点 | 机理 |
|---|---|---|
| D1 | **管道必须在正文之前** | Qwen 是因果解码器，正文只能注意**更早**的位置；管道若放在序列末尾，注意力权重实测**恰为 0.0**、四臂读数完全相同 |
| D2 | **管道内容必须写在第 0 层**（embedding 输出） | 写深了，管道位置的固有表示（pad 位置的样本无关内容）会稀释内容：j=3/j=6 时注意力对内容**完全不敏感**（恒为 1.078e-01） |
| D3 | **正文要截断到 SEQ−K** | 布局固定为 `[K | SEQ−K]`，正文超长样本截断（实测 1/128 条） |

## 2. 管道机制（照抄 §1.2 的探针实现，不新增自由度）

```text
序列布局            [ 管道 K=8 位 | 正文 120 位 ]        （因果解码器: 管道在前）
管道位置            位置 0..K-1；attention_mask = 1（模型把它们当真 token）
写入点              目标模型**第 0 层**的输入 hidden_states（forward_pre_hook）
写入内容            Δ_B = z @ P_B，其中 z = a_s @ P_Aᵀ（256 维共享空间载体）
写入范围            **只写管道位置**，正文位置一律零增量
强度                逐样本 ||Δ_i||₂ = λ · (该样本正文 token 在第 0 层的 hidden 平均范数)
通道编号            通道 0 = 管道位 0..3；通道 1 = 管道位 4..7
```

| 臂 | 管道内容 | 写入通道 | 作用 |
|---|---|---|---|
| `arm0_pipe_zero` | **管道开、内容为 0** | — | 基线（布局与其它臂**完全相同**，只有内容不同） |
| `arm1_slot_Q` | 源模型第 l 层 **Q 槽**激活 | **通道 0** | 主臂 |
| `arm2_wrong_slot_O` | 同一源层的 **O 槽**激活 | **通道 1** | 槽特异性对照（**按专属通道编号**） |
| `arm3_random_dir` | 共享空间内的**随机方向** | **通道 0** | 排除「随便什么内容都能被读」（与 arm1 同通道 ⇒ 纯内容对照） |

> ⚠️ **arm0 的口径与 S3 不同**：S3 的 arm0 是「零注入」（hook 装着但 delta 全零，管道位置**不可见**）；本代 arm0 是「**管道开但内容为 0**」（管道位置**可见**）⇒ 与其余臂**布局完全一致**，是干净的配对基线。**S3 与本代的 arm0 不可直接比大小**。

> 📌 **写入点固定在第 0 层的两个后果**（修订 1）：① 管道内容从 embedding 层就进入模型，深层是否还读得到由模型自己决定；② **一次前向即可拿到全部读出层与全部注意力层** ⇒ 每个 (源层, 臂, 种子) 只需一次前向，跑批成本比「每块一次前向」低约 8 倍。

> ⚠️ **ViT 臂已于跑前整臂撤出**（§0.1 修订 9）：ViT 没有「空位」可放管道（每个位置都带图像块内容），管道位必然携带图像内容；第一轮标定实测：末层扰动 40 条记录里 **20 条越守门上限 0.3**，且**通道寻址完全失效**（`arm1−arm2` 的管道注意力差 5/5 块为负）⇒ **该臂测的不是同一个机制**，撤出而不是硬修。撤出前的实测证据留档在 `results/calib_records.jsonl`（`direction` 为 `ViT->ViT` 的 40 行）。本代**只跑文本 64 块**。

## 3. 判据（全部跑前写死，见源码常量 `THRESHOLDS`）

| 判据 | 内容 | 块集合 | 阈值 |
|---|---|---|---|
| **P5a 管道连通** | `arm1` 与 `arm0` 的**每样本管道注意力**之差（管道注意力 = 通道 0 + 通道 1 的平均注意力）；**并且** `arm1` 与 `arm3` 之差（内容特异性对照） | 12 个 (方向, 源层) 组 | 两项都：中位 > 0 且配对置换 p < α = 0.01 |
| **P5b 管道可分（槽）** | **通道寻址统计量** `flip = 通道0注意力 − 通道1注意力` 的 `arm1` 与 `arm2` 之差 | 12 个 (方向, 源层) 组 | 中位 > 0 且配对置换 p < 0.01 |
| **P5c 贯通（正文可读）** | `arm1` 与 `arm0` 的**正文位置** token 级探针 r2_q 增量 | 64 个文本块 | 中位 > 0 且配对置换 p < 0.01 |
| **P5d 选择性** | `arm1` 与 `arm0` 的正文 r2_o（非目标槽）增量 | 64 个文本块 | 中位 ≤ 0 或 p ≥ 0.05 |
| **P2′ 深度语义** | 同层块的 P5c 增量中位 vs 跨层块的中位 | 64 个文本块（8 同层 / 56 跨层） | 同层 ≥ 跨层且分层置换 p < 0.01 |
| **P3① 守门** | 每个注入臂块的末层输出相对扰动（正文位置） | 64 块 × 3 注入臂 × 5 种子 | ∈ (1e-3, 0.5] |

- **统计单位** = (模型对 × 源层 × 读出层) 块；主判据集 = **64 个文本块**（ViT 20 块已于跑前整臂撤出，§0.1 修订 9）。
- **注意力块的粒度**：管道注意力在**第 0 层**测（修订 2），它**不依赖读出层 j** ⇒ P5a/P5b 的块集合是 **(方向, 源层)** = 4 (BERT→Qwen) + 8 (Qwen→BERT) = **12 个文本组**，每个组 5 个种子观测 ⇒ 60 观测。
- **种子** = 5 个 nuisance 种子 (0..4)，只影响共享空间投影 P 与 arm3 的随机方向。
- **注意力权重**：需 `attn_implementation="eager"`（默认 sdpa 取不到）；本代**全部种子**都用 eager（不增成本，且保证各臂数值口径一致）。
- **探针**：沿用 S3 §2.6 的 **token 级** ridge 探针（逐维标准化、去首 body token、留出集读数、λ 由**训练样本内** 5 折 CV 在写死网格上选），**加一条 mask**：只读正文里的真实 token（pad 位不参与，修订 5）；样本级 mean-pool 探针作**预登记辅助读数，不参与裁决**。
- **verdict** = `S4PIPE_READY`（P5a ∧ P5b ∧ P5c ∧ P5d ∧ P2′ ∧ P3① 全过）否则 `S4PIPE_FAIL`；退出码 0/1。

### 3.1 λ 的标定（S4P-1，跑前写死）

**λ 必须重新标定**：v80 的 λ* = 0.03 是给「残差流同位置加法」标定的；管道口径的基准（正文 token 在第 0 层的 hidden 平均范数）完全不同，探针显示 λ ≥ 1 才有可见效应。

| 项 | 写死值 |
|---|---|
| 候选集 | {0.5, 1.0, 2.0, 3.0} |
| 选择规则 | ① **全部块** max final ≤ **0.3**（安全闸门；本代只覆盖 12 个文本组）；② **主判据集 12 个文本 (方向,源层) 组里 ≥ 8 组** `attn_pipe(arm1) − attn_pipe(arm0) > 0`；③ **主判据集里 ≥ 8 组** `flip(arm1) − flip(arm2) > 0`；三条全满足才算可行，取可行候选里**最大**的那个；无一满足 ⇒ `CALIB_NO_FEASIBLE_LAMBDA`（报回，不硬选）。**ViT 组已整臂撤出**（修订 9），不再进入标定 |
| 标定块 | 12 个文本 (方向, 源层) 组（BERT→Qwen 4 + Qwen→BERT 8），每组跑 arm1 + arm2（seed 0） |

**阈值一条未放宽**：候选集与选择规则跑前写死在源码常量里；标定后的正式跑判据与 §3 **完全相同**，只换了 λ。

## 4. 结果

**裁决 `S4PIPE_FAIL`**（退出码 1，契约内）：**P5b 管道可分 / P5c 贯通 / P3① 守门 三项通过**，**P5a 管道连通 / P5d 选择性 / P2′ 深度语义 三项未过**。

跑批：64 个文本块 × 4 臂 × 5 个 nuisance 种子 = **1280 行**（+ 240 条注意力记录），**λ = 1.0**；因单任务运行时限分 5 批执行（逐批断点续跑），合计约 **5.9 ks**（本机 CPU），最后由 `--aggregate` 从全量 checkpoint 重算判据（判据函数与正式跑批完全相同）。

| 判据 | 块集合 | 实测 | 结果 |
|---|---|---|:--:|
| **P5a 管道连通** | 12 个 (方向,源层) 组 | `arm1−arm0` 中位 **+0.000463**（34/60 观测为正），置换 **p = 0.3108**；内容特异性 `arm1−arm3` 中位 **−0.000983**（24/60 正），p = **0.9053** | ❌ |

### 4.3 引用本代必须成对给出的四个事实

1. **贯通成立且比 S3 更强**：P5c 的 Δ 中位 **+0.004419**（p = 0.0）> S3 的 P1a **+0.003232**；但两者口径不同（写入点 / 正文长度 / arm0 定义全变），**不可直接比大小**。
2. **信息不是靠「模型注意到管道」过去的**：P5a 块级 p = 0.3108、逐样本 p = 1.0，内容特异性对照 arm1−arm3 甚至为**负**（−0.000983, p = 0.9053）。
3. **通道寻址只在块级聚合上成立**：P5b 块级 p = 0.0，但逐样本 p = 0.787 ⇒ 只能说「管道提供了比残差流更好的容器」，**不能说「按地址投递已成立」**。
4. **⚠️ 读出端补测推翻了「卡在读出端」的判断（post_hoc_only，裁决不变）**：正文侧内容特异性 arm1−arm3 块级中位 **+0.011373**（281/320 正，置换 **p = 0.0**）⇒ 管道**确实按内容**把信息带到了正文；槽特异性 arm1−arm2 **+0.002700**（p = 0.0）但**只在 BERT→Qwen 成立**（+0.004155, p = 0.0；Qwen→BERT +0.000788, **p = 0.1324**）⇒ 管道在 BERT→Qwen 方向把「分不清」变成了「分得清」。详见 §4.4。

⇒ **A1 激活级路线的现状**：**容器关与传递关，管道都过了**；剩下的是 **P2′（深度对应）** 与 **P5d（非目标槽普涨）** 两个失败项 —— 两者都与容器/共享空间的**线性性质无关**（§4.5）⇒ 指向**源侧语义本身**（源模型层间语义不对齐；Qwen 源侧的 Q/O 槽本身混在一起）。

### 4.4 读出端补测（post_hoc_only，**不参与任何裁决**；留档 `results/diag_readout.json`，脚本 `readout_diag.py`）

六项判据只测了注意力侧的连通/寻址（P5a/P5b）与正文侧的整体增量（P5c/P5d），「正文侧的内容特异性与槽特异性各是多少」没有单独测过。本节补测，统计量与 **v81（`v81_s3_semantic`）的 P1a/P1b 同款口径**（正文 token 级 r2_q 的臂间差）⇒ `arm1−arm2` 可与 v81 的 P1b 直接比较。

| 读数 | 块级中位 | 为正观测 | 置换 p | Qwen→BERT | BERT→Qwen |
|---|---:|---:|---:|---:|---:|
| 贯通 `arm1−arm0`（有内容 vs 无内容） | +0.004419 | 236/320 | 0.0 | +0.002451 (p = 0.0) | +0.007731 (p = 0.0) |
| **内容特异 `arm1−arm3`**（Q 槽 vs 随机方向） | **+0.011373** | **281/320** | **0.0** | +0.011683 (p = 0.0) | +0.011195 (p = 0.0) |
| **槽特异 `arm1−arm2`**（Q 槽 vs O 槽） | **+0.002700** | 194/320 | **0.0** | +0.000788 (**p = 0.1324**) | **+0.004155 (p = 0.0)** |
| 随机噪声 `arm3−arm0`（随机方向 vs 无内容） | **−0.004986** | 61/320 | 1.0 | −0.008816 (p = 1.0) | −0.002624 (p = 1.0) |

- **内容是按内容过去的**：内容特异 **+0.011373**（p = 0.0，两方向均 p = 0.0）远大于「有无内容」的 +0.004419；随机方向臂**没有**带来可读性（`arm3−arm0` = −0.004986, p = 1.0）⇒ P5a 的失败**不是**「信息没到正文」，而是「模型没把注意力权重分配给管道位」。
- **槽特异只在 BERT→Qwen 方向成立**：与 v81 同口径对照 **P1b = −0.002455, p = 0.9521** ⇒ 管道在 BERT→Qwen 方向把「分不清」变成了「分得清」；Qwen→BERT 方向仍是「分不清」（+0.000788, p = 0.1324）。
- ⇒ **更正**：此前「卡点在读出端」的判断**不成立** —— 读出端**没有卡住**；剩下的是**深度对应（P2′）** 与**非目标槽普涨（P5d）**。

⚠️ 本节是**事后诊断**（post_hoc_only）：不参与裁决、不推翻任何阈值；它改的是**解释**，不是 `S4PIPE_FAIL` 这个裁决本身。



### 4.5 载体性质：共享空间是**线性**子空间（post_hoc_only；留档 `results/diag_carrier.json`，脚本 `carrier_probe.py`）

| 项 | BERT→Qwen | Qwen→BERT | 说明 |
|---|---:|---:|---|
| 投影正交性 `‖P Pᵀ − I‖_F` | ≤ 9.09e-06 | ≤ 5.35e-06 | v62 `measure.projections()` 是**随机正交**投影（行正交，DS = 256） |
| 范数比 `‖Δ‖ / ‖a_s‖`（块中位的中位） | **1.000000**（1.0 ~ 1.0000001） | **0.531143**（0.485455 ~ 0.573749） | 1.0 = 范数**严格**保持（等距）；< 1 = 幅度被压 |
| 方差保留（范数比²） | 1.000000 | 0.282257 | 投影掉的方差比例；与 v81 `ceiling_diag.json` 的 `r2_project` 中位 0.288 同口径（本次实测 0.282114） |
| 成对夹角差 `\|cos_源 − cos_目标\|` | **7.586e-08**（max 3.576e-07） | 1.0643e-03（max 5.380e-02） | 0 = 夹角**严格**保持 |
| 夹角相关性 Pearson r | 1.0000000 | 0.99677 | 源侧夹角在目标侧仍高度可还原 |

- **载体形式**：`Δ = (a_s @ P_Aᵀ) @ P_B`，P_A / P_B 是**常量**矩阵 ⇒ 载体是**线性**映射；注入端唯一的非线性是**逐样本范数归一化**（`‖Δ_i‖ = λ · 正文第 0 层平均范数`，`s4_pipe.py` 的 `make_pipe_delta`）⇒ **只改幅度、不改方向**。
- **BERT→Qwen 方向是等距映射**：源维 = 共享维 = 256 ⇒ 全程正交 ⇒ 范数与夹角**严格**保持（残差 ~1e-07，就是 float32 精度）。
- **Qwen→BERT 方向是随机秩-256 投影**：源维 896 → 共享维 256 ⇒ 幅度被压到 **0.531143**（方差保留 0.282257），夹角轻微收缩（|Δcos| ~1e-03，但 r = 0.99677 ⇒ 源侧夹角仍高度可还原）。

⇒ **失败不能归因于「空间是线性的」**：载体在 BERT→Qwen 方向**等距**（范数与夹角都保持）⇒「换非线性」不解决可分性、「扩维度」只补幅度（Qwen→BERT 方向缺的正是幅度）。**要打破「分不清」，必须引入选择/标签（管道、路由、门控），而不是改映射的性质** —— 与 §4.3 / §4.4 一致：剩下的是**源侧语义**问题。

## 5. 局限（引用本代必须带上）

1. **管道内容写在第 0 层** ⇒ 管道位置在 embedding 层就带上了源信息；这与 v81 的「层边界注入」口径**不同**，与 v81 **不可直接比大小**。
2. **正文被截断到 SEQ−K**（实测 1/128 条超长）⇒ 与 v81 的 128 token 正文口径**不同**。
3. **arm0 口径不同**（管道开、内容为 0 vs v81 的管道不可见）⇒ 与 v81 的 Δ **不可直接比大小**。
4. **注意力在第 0 层（写入层）测**（深层注意力对内容不稳定，pipe_probe3 实测）⇒ P5a/P5b 回答的是「模型在内容进入的那一层读不读、按不按通道读」，**不是**「深层还在不在看管道」。
5. **P5a/P5b 的块集合是 12 个 (方向, 源层) 组**（不是 64 块）⇒ 观测数 60（P5a/P5b），P5c/P5d/P2′ 是 64 块 / 320 观测。
6. **模型没被训练过去读这些管道位置** ⇒ 管道能被读是**实测结论**，不是构造保证；不同底座/不同位置需各自验证。
7. **共享空间仍是 256 维** ⇒ 源侧信息上限不变（BERT 无损、Qwen 29%、ViT 33%），本代不修这一条；⚠️ 但载体是**线性**映射且在 BERT→Qwen 方向**等距**（§4.5）⇒ 「扩维度」只补幅度、「换非线性」不解决可分性 ⇒ 这两条路线的期望收益已被**下调**，不再作为「下一步」候选。
8. **ViT 臂已整臂撤出**（§0.1 修订 9）⇒ 本代**只覆盖文本两个方向**（BERT↔Qwen），ViT 上的结论外推不了；撤出前的实测证据留档在 `results/calib_records.jsonl`（`direction` 为 `ViT->ViT` 的 40 行）；撤出理由的两条实测（扰动越界 + 通道寻址失效）见 §0.1 修订 9。
9. 本代**不训练**任何底座权重、**不产生**任何能力指标、**不产生** A1 的总判定。
10. **§4.4 / §4.5 两段补测是 post_hoc_only**（读出端解读 + 载体性质）⇒ 不参与裁决、不推翻阈值；引用本代的**裁决**以 §4 的六项判据为准，引用**解释**时必须把这两段一起带上（否则会误引「卡在读出端」这个已被推翻的旧判断）。

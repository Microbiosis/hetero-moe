## 1. 问题与候选

S3 的注入算子（[`docs/A1_DESIGN.md`](../../docs/A1_DESIGN.md) §1.1）需要

```text
z  = P_A · a_s^{l}          （源模型第 l 层槽 s 激活的共享空间表示）
z~ = align[s|A→B] · z       （← **本代要找的就是这个映射**）
Δ_B = P_Bᵀ · z~
```

| 候选 | 拟合数据 | 说明 |
|---|---|---|
| **none** | — | 不做映射（基线） |
| **procrustes** | 真模型激活 | 正交 Procrustes（保结构、不保幅度） |
| **ridge** | 真模型激活 | 闭式岭回归（沿用 v75 的 `fit_transport` 同式，λ=1.0） |
| **lowrank16** | 真模型激活 | U 的 top-16 PCA 子空间里拟合岭回归 |
| **v75_synth** | **合成切片 + 随机输入** | 复刻 v75 的成对对齐流程（闭式 ridge + cyclic leave-one-layer-out）；正交帧换成 v62 的 `projections(0)`（帧是规范选择，方法不变；换了帧才能同帧比较） |

> **为什么对齐映射只能在样本级拟合**：两个模型的 token 网格不同，**无法逐 token 配对** ⇒ 配对只能在 mean-pool 之后做。⇒ 本代测的正是「对齐映射唯一可能的口径」。

---

## 2. 三条纪律

1. **块级 leave-out**：评估块 (l, j) 的映射只用 `l'≠l` 且 `j'≠j` 的块拟合 ⇒ 源层与目标层都与拟合集不相交（防循环论证）。
2. **样本留出**：按标签分层切分，**63 条训练（拟合）/ 64 条留出（评估）**。
3. **阈值跑前写死**（`sign_p_max=0.05`、`min_blocks=32`、`ridge_lam=1.0`、`lowrank_k=16`…）；事后未放宽。

---

## 3. 判据与结果（负结果）

判据：**A1** 槽特异性（matched > 错槽）、**A2** 优于不对齐（matched > no-align），均用留出集双侧符号检验 p < 0.05；**A3** λ 稳健；**A4** 唯一选出来源。

**Q 槽（32 块/候选）**：

| 候选 | matched | 错槽 | 不对齐 | A1 中位差（正号/p） | **A2 中位差** |
|---|---:|---:|---:|---|---:|
| none（基线） | 0.6958 | 0.4112 | 0.6958 | +0.3117（29/32，p<1e-4） | **+0.0000** |
| procrustes | 0.6958 | 0.4112 | 0.6958 | +0.3117（29/32） | **+0.0000**（17/32，p=0.8601） |
| v75_synth | 0.6384 | 0.3559 | 0.6958 | +0.3007（29/32，p<1e-4） | **−0.0129**（10/32） |
| ridge | 0.6026 | 0.3393 | 0.6958 | +0.2846（30/32，p<1e-4） | **−0.0831**（1/32） |
| lowrank16 | 0.4103 | 0.2172 | 0.6958 | +0.2330（21/32，p=0.1102） | **−0.2772**（3/32） |

**O 槽**：基线 matched 0.5263 / 错槽 0.4112；A1 中位差 +0.0978（24/32，p=0.0070）；A2 中位差 0.0000；ridge 的 A2 为 −0.1619（0/32）。

**λ 稳健性（A3）**：λ=0.1 ⇒ A1 +0.1701（51/64，p=1.9e-6）但 A2 −0.1173（8/64）；λ=10 ⇒ A1 +0.0858（46/64，p=0.0006）但 A2 −0.1（3/64）⇒ **A3 不过**。

⇒ **裁决：ALIGN_SOURCE_NOT_FOUND**（功效闸门过；A1 过；**A2 对全部候选不过**；A3 不过；A4 无来源可选）。

**读法**：不是「差一点」——**没有任何候选的 A2 中位差为正**，最好的两个也只是打平（none/procrustes 的 0.0000 是恒等式），其余为负。

## 4. 机理（post_hoc，不参与裁决）

| 观察 | 数字 | 含义 |
|---|---|---|
| 池化表示有效秩（共享空间） | Qwen **Q** 槽 L0–L3 = 4.84 / 13.84 / 38.74 / 34.33；Qwen **O** 槽 = 58.15–68.36；BERT Q 槽 = 35.50–51.66；BERT O 槽 = 64.78–69.13 | **Q 槽的跨样本变化几乎是低秩的**（L0 只 4.84 维），O 槽近乎满秩 ⇒ 低秩表示天然容易被线性相关 |
| 块级映射（每个块用自己的 63 条训练样本拟合） | matched 0.6857 / 错槽 0.4172 / 不对齐 0.6110；**A2 +0.0677（p<1e-4）** | 块级映射**确实**超过基线 |
| 同上，但**去掉 top1 PC** | matched 0.5248 / 错槽 0.3705 / 不对齐 0.5372；**A2 −0.0261（28/64，p=1.0）** | 优势**全部来自共同成分**；去掉后连块级映射也不再超过基线 |
| 池化映射的训练集内 vs 留出集 | train 0.5082 / test 0.4516 / 基线 0.5990 | 连**训练集内**都不如基线 ⇒ 不是过拟合，是**没东西可学** |

⇒ **机理**：跨模型槽激活之间存在一个**低秩共同成分**（v78 的 D2 已测到 PC1 占 88.76%），它同时制造了「同槽比异槽像」（A1 成立）与「不做映射也不差」（A2 不成立）。二者是同一件事的两面。

---

## 5. 三个证伪（对主线的影响）

1. **「存在可用的跨模型槽对齐映射」** → **证伪**：四个候选的 A2 中位差全 ≤ 0，且训练集内也不如基线。
2. **「v77 的 B5 与 v78 的 Q 槽 8/8 反映的是槽特异的跨模型对应」** → 本代**不能直接否证**（post_hoc），但给出强反证压力：Q 槽有效秩 4.84–38.74 ⇒ 高 CKA 主要来自低秩共同成分；去掉 top1 PC 后连块级映射的优势也消失。
3. **「对齐映射可以改到 token 级拟合，以配合 S3 拍板的 token 级探针」** → **不可能**：token 网格不可配对 ⇒ 对齐映射只能在样本级拟合 ⇒ **「对齐映射」这个对象与 token 级口径不相容**。

## 6. 对 S3 的后果（协议必须先修订）

- [`docs/S3_PROTOCOL.md`](../../docs/S3_PROTOCOL.md) §2.3 的注入算子形式「`z~ = align[s|A→B] · z`」**不能按原文开跑**：不存在可用的 align 对象。
- 开跑前检查清单第 3 条（`align[s|A→B]` 的来源已定死并记 sha256）**当前无法满足**。
- ⇒ **S3 的注入算子口径已于 2026-11-17 拍板**：**保留共享空间载体、不学任何学出来的映射**（最终公式与修订记录见 [`docs/S3_PROTOCOL.md`](../../docs/S3_PROTOCOL.md) §2.3）⇒ 本代留下的块级映射工程件**该协议不采用**（只备查）。
- 本代同时留下一件**工程件**：块级 ridge 映射 64 张（`results/align_maps.pt`，sha256 已记入快照），**明确标注是 post_hoc 依据、不是本代裁决产物**；S3 若采用，必须在自己的留出集上重新验证。

## 1. 从 v82 到本代：三处缺陷的数学归因与闭式修复

### 1.1 缺陷一：未对齐的随机正交投影导致 P5a（管道连通）失败

在 v82 中，注入算子为 `Δ_B = (a_s @ P_Aᵀ) @ P_B`，其中 `P_A, P_B` 是 `v62/measure.py` 生成的独立随机正交矩阵。虽然随机正交变换保持样本间内积（因此有监督 Ridge 探针能求逆消去旋转，使 P5c 通过），但它将源激活的坐标轴随机旋转到了目标模型第 0 层注意力 Query-Key 接收锥之外，导致目标模型第 0 层注意力对 `arm1` 与随机方向 `arm3` 完全无区分（v82 P5a：`arm1−arm3 = −0.000983, p = 0.9053`；逐样本符号检验 `p = 1.0`）。

**闭式修复（`target_qk_receptive_field` + `fit_orthogonal_procrustes`）**：
1. 用纯前向闭式线性代数（`torch.no_grad()`，无任何 `.backward`）计算目标模型第 0 层注意力对管道位的 Q-K 接收场方向 $g_0 \in \mathbb{R}^{N \times D_B}$：
   - **BERT（MHA + 绝对位置编码）**：正文有效位置的平均 Query $\bar{q}_i = \text{mean}_{t \in \text{body}_i}(h_{0,i,t} W_Q^\top + b_Q)$ 经 Key 矩阵拉回 $g_{0,i} = \bar{q}_i W_K$。
   - **Qwen（GQA 14Q/2KV + RoPE + RMSNorm）**：对 `input_layernorm(h0)` 算出的 Query 施加第 0 层真实 `rotary_emb` 正向旋转 $\text{RoPE}(t)$，在正文有效位置求均值后施加管道位 $p \in [0, 8)$ 的逆旋转 $\text{RoPE}(-p)$，按 GQA 组（每 7 个 Q 头归 1 个 KV 头）求均值后经 $W_K$ 与 `RMSNorm` 权重拉回第 0 层隐空间。
2. 将接收场投到共享空间 $Y_0 = g_0 P_B^\top \in \mathbb{R}^{N \times 256}$，仅在**训练集 `train_idx`（前 64 条样本）**上求解正交 Procrustes 对齐矩阵：
   $$\Omega_s = \arg\max_{\Omega^\top \Omega = I_{256}} \text{Tr}\!\left(\Omega^\top Z_{s,\text{tr}}^\top Y_{0,\text{tr}}\right) = U V^\top, \quad U \Sigma V^\top = \text{SVD}\!\left(Z_{s,\text{tr}}^\top Y_{0,\text{tr}}\right)$$
3. **严格等距与零泄漏**：由于 $\Omega_s^\top \Omega_s = I_{256}$，映射 $z \mapsto z \Omega_s$ 100% 保持范数与样本间成对夹角，且测试集样本（`64..127`）全程不参与 $\Omega_s$ 的求解。

### 1.2 缺陷二：O 槽取输入 + 同层句子主成分混淆导致 P5d（选择性）失败

v77–v82 中 `SLOT_SOURCE["O"] = "in"` 抓取的是 `o_proj` 的输入（多头 Value 拼接态）而非 $W_O$ 的输出；且样本级 `mean-pool` 后同层 $a_Q$ 与 $a_O$ 共享句子级词袋主成分（$R^2(a_Q \to a_O) \approx 0.45$），注入 $a_Q$ 必然连带抬高 $a_O$ 的可读性（v82 P5d：`+0.001921, p = 0.0`）。

**闭式修复（`capture_slots_true_out` + `orthogonalize_slot_pair`）**：
1. `Q` 与 `O` 均抓取模块真实输出（`SLOT_SOURCE_V83 = {"Q": "out", "O": "out"}`）。
2. 仅在**训练集 `train_idx`** 上对同层 $(a_Q, a_O)$ 做闭式 Ridge 正交残差化（$\lambda_{\text{orth}} = 10.0$）：
   $$a_{Q\perp O} = (a_Q - \mu_{Q,\text{tr}}) - (a_O - \mu_{O,\text{tr}}) W_{O\to Q, \text{tr}}, \qquad a_{O\perp Q} = (a_O - \mu_{O,\text{tr}}) - (a_Q - \mu_{Q,\text{tr}}) W_{Q\to O, \text{tr}}$$
   剥离同层共享句子成分后，留出集上 $R^2(a_{Q\perp O} \to a_{O\perp Q})$ 从 `0.22–0.45` 降至 `0.01–0.04`。

### 4.2 为什么单点第 0 层管道下 P2′（`sl == tl`）的 $p = 0.1256$：Qwen L0 的 GQA $M_{VO}^{(0)}$ 谱瓶颈

在单点第 0 层写入机制下，管道信息必须经目标模型第 $l$ 层的 Value-Output 复合算子 $M_{VO}^{(l)} = W_O^{(l)} G_{\text{GQA}} W_V^{(l)} \text{diag}(w_{\text{ln}}^{(l)})$ 才能写入正文残差流。实测各层谱结构：

| 模型与层 | 有效非零秩 (`sv > 1e-5`) | 最大奇异值 `top1_sv` | 前 128 维平均奇异值 | Frobenius 范数 `‖M_vo‖_F` |
|---|---:|---:|---:|---:|
| **Qwen L0** | **128** / 896 | **0.0897** | **0.0192** | **0.2862** |
| Qwen L1 | 128 / 896 | 0.5344 | 0.2650 | 3.1448 |
| Qwen L3 | 128 / 896 | 1.3984 | 0.4731 | 5.9945 |
| Qwen L12 | 128 / 896 | 3.0220 | 1.1456 | 14.2536 |
| Qwen L23 | 128 / 896 | 5.6362 | 1.2731 | 18.6372 |
| **BERT L0** | **256** / 256 | **2.9571** | **0.4964** | **12.2703** |
| BERT L3 | 256 / 256 | 8.1997 | 1.7889 | 39.5157 |

- **结论**：Qwen 第 0 层因 GQA（2 KV 头 × 64 = 128 维）存在 768 维零空间，且 `‖M_vo^(0)‖_F = 0.2862` **比 BERT L0（12.2703）小 42.9 倍、比 Qwen L1–L23（3.14–18.64）小 11～65 倍**。因此 `BERT->Qwen` 在第 0 层读出（`tl=0`）时受到 ~50 倍物理带宽节流，信息必须到 `tl >= 1` 才完全进入正文，从而稀释了 `sl == tl` 在 `(0, 0)` 块上的优势。

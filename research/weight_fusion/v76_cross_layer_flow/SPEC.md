## 1. 重建的层栈长什么样

```text
层 i (由切片权重重建):
  x  = RMSNorm(h)                      # 非仿射: 切片的 norm 参数不在里面
  q  = x @ Wq^T ; k = x @ Wk^T ; v = x @ Wv^T
  q/k/v 拆头 (Qwen: 14 头 / 2 KV 头, head_dim=64, GQA repeat 7×)
  ctx = softmax(q k^T / sqrt(64)) v
  h  = h + ctx @ Wo^T                  # 残差
  x  = RMSNorm(h)
  e  = x @ We^T ; f = e @ Wc^T
  h  = h + f                           # 残差 (FFN 只剩线性部分)
```

**头数由切片形状反推**（切片里没有 config）：Qwen D=896=14×64、K/V [128,896]=2×64 ⇒ 14 头 / 2 KV 头（GQA）；BERT 256=4×64；ViT 768=12×64。

**已声明的建模选择**（不是从切片读出来的，是我们做的决定，必须随数字一起引用）：

1. 统一 pre-norm + **非仿射** RMSNorm（真实模型有 norm 参数，切片里没有）；
2. attention 无 bias、FFN 无激活（Qwen 的 SwiGLU 缺 gate 路 ⇒ 只剩线性部分）；
3. **无 embedding** ⇒ 输入 `h0` 为随机向量；
4. 无 position embedding；
5. GQA 头数由形状反推。

## 3. 范围外缺陷：ViT 进不了首代

| 量 | ViT | 判据 |
|---|---:|---|
| layer0 残差膨胀 | **20.11×** | ≤ 10× ❌ |
| 有效秩 | 744 → **64** | > 1.1（形式上过，但塌了 10 倍）⚠️ |
| layer0 attention 分支 RMS | 2.10 | — |
| layer0 **FFN 分支 RMS** | **20.84** | — |

**根因**：切片里没有 norm 的 gain、也没有 embedding 的尺度，我们只能用非仿射 RMSNorm —— 它压得住 attention 分支（2.10），压不住 ViT 的 FFN 分支（20.84）⇒ 残差在第一层就膨胀 20 倍。

⇒ **ViT 进入首代范围前必须先修**（候选：按分支量级做残差缩放 / 补 embedding 尺度 / 改用真模型路线）。本代**不修**，如实登记。

## 4. 本代证伪的两条设计前提（比 PASS 本身更重要）

### 4.1 路线 α 测不了语义层判据

跨模型槽级 ridge（共享空间随机输入，A 的槽输出 → B 的槽输出）：

| 量 | 值 |
|---|---|
| 匹配槽 R² | 0.964 ~ 0.992 |
| 错槽 R² | 与匹配槽**几乎相同** |
| 差值中位数 | **−0.0000754** |
| 差值为正的行数 | **11/24 = 45.8%** |

**为什么必然退化**：在随机输入下，任一槽的输出都是**同一个随机输入的线性函数** ⇒ 任意两槽彼此线性可预测，R² 天然接近 1，且与槽身份无关。

⇒ **设计稿把 P1a/P1b/P2/P3 放在路线 α 的安排是错的**（已改：语义层归路线 β）。

> 附带一个正面结论：C4 的 alignment 是 **0.63~0.83 而不是 1.0** ⇒ 注入方向**没有**被残差流原样携带，而是被后续层实质改造过。这比我设计稿里担心的「平凡携带」要好一点 —— 但它仍然只证明机制，不证明语义。

### 4.2 ViT 不能与 Qwen/BERT 同等入局

见 §3。

## 5. 边界（引用本代的一切数字都必须带上）

1. 路线 α = **权重级随机输入前向**：无 embedding / norm 参数 / bias / 激活 / position embedding ⇒ 无真语义。
2. **C4 只证机制**：残差流会携带注入方向 ⇒ 「注入信息还在输出里」平凡；本代用 alignment < 1 说明它被改造过，但仍不说明信息被**用**了。
3. **C5 的内容度量退化**（§4.1）⇒ 本代**没有**任何跨模型内容/槽对应的结论。
4. 无端到端任务指标、无标签 ⇒ 不得说成能力或精度结论。
5. C3 判据只覆盖 Qwen/BERT；ViT 的数值是**缺陷记录**，不是结论。
6. seed=1 足够：S1 是结构与通路自检，不含需要多种子的统计推断。

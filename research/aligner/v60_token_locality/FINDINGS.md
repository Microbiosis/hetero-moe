# V60 观测量换成"位置对余弦相似度"：预登记判据全败，但暴露两个信号

> 运行：Space `redmingwei/hetero-moe`（cpu-upgrade），**75s**
> 产物：桶 `redmingwei/hetero-moe-jobs/v60-area1/`
> 单测：8/8（`v60t-5`）

## 判决：token 轴无局部性

| 判据 | raw | centered | detrend |
| --- | --- | --- | --- |
| **P0 正控**（纯噪声） | **通过**（corr=+0.048） | — | — |
| **P1 距离衰减** | 0/8 | 3/8 | 0/8 |
| **P2 置换可分** | **0/8** | **0/8** | **0/8** |
| P3 局部性差 | 4/8 | 8/8 | 0/8 |
| **P1+P2 同时过** | **0/8** | **0/8** | **0/8** |

按预登记，**结论是 token 轴上不存在局部结构**。

而且方向是**反的**：`raw` 与 `detrend` 臂的 `corr(d, M̄(d))` 都是**正**的
（+0.32…+0.68 / +0.43…+0.50），即**远端位置反而更相似**。

## P2 抓到了 P1 的假阳性（这正是它存在的理由）

`centered` 臂 layer2/3/4 的 `corr` 是 −0.524 / −0.544 / −0.491，
按 P1 的 `corr < −0.5` 字面会判"过"。但 P2 全部失败：

```
layer2 centered  corr=-0.524   置换零分布下界=-0.925
layer3 centered  corr=-0.544   置换零分布下界=-0.903
```

**打乱 token 顺序后，相关可以到 −0.9。** 说明这个负相关与"谁和谁相邻"无关，
是 `M` 矩阵自身的量级结构（某些行列整体偏高）造成的。
若没有 P2，会误判出一个不存在的局部性。

## 两个未经预登记检验的信号（不得当作结论）

### 信号 1：`detrend` 臂的 d=1 是强负，且**八层完全稳定**

```
layer0 d=1: −0.2947      layer4 d=1: −0.2803
layer1 d=1: −0.2888      layer5 d=1: −0.2876
layer2 d=1: −0.2826      layer6 d=1: −0.2840
layer3 d=1: −0.2842      layer7 d=1: (见 metrics)
```

而 d≥2 全在 −0.06…+0.06 之间。**相邻对与其余对的差距约 5 倍，跨 8 层几乎不变。**

这与"局部性"相反：相邻 token 表征**反相关**（互相区分），而非相似。

**为什么判据没抓到**：`corr(d, M̄(d))` 是线性相关，d=2..15 的缓慢上升
（−0.04 → +0.06）抵消了 d=1 的离群值，使总相关变成 +0.44。
**一个只在最邻近点上出现的结构，会被线性相关系数稀释掉。**

### 信号 2：`centered` 臂呈"d=1 正、其余负"

```
layer3 centered M̄(d) = [+0.205, −0.005, −0.024, −0.068, −0.028, −0.002, ...]
```

d=1 显著为正，d≥2 全负。形状与信号 1 相反。

两条信号方向相反，说明**三臂去掉的成分不同，得到的结构也不同**——
这本身提示"位置结构"不是一个单一的量，而取决于你控制了什么。

## 方法学教训（三条可复用）

1. **谱范数型耦合对位置结构失明**。逐列标准化到 `‖col‖=√n` 会抹掉幅度信息；
   植入 `X[t]=base+t·direction` 后剖面起伏仅 **1.26%**
   （`test_v1_spectral_coupling_is_blind` 固化）。

2. **共同因的效应不能凭直觉断言**。我先后猜错两次：
   ① 猜"不改斜率" → 实测 0.776→0.730；
   ② 猜"压缩斜率" → 实测 −0.933→−0.973（反而增强）。
   推导后才明白：共同因足够大时分母被常数化，余弦变成
   `cos ≈ 1 − c·(i−j)²/(2·scale²|base|²)`，即 `|i−j|²` 的**纯净抛物线**，
   衰减反而更规整。⇒ 幅度效应取决于位置项形式，**不是普遍性质**。

3. **线性相关会漏掉"只在最邻近出现"的结构**。下一代的判据应改为：
   - 秩相关（Spearman）对离群点稳健；
   - 或直接检验 `M̄(1)` 相对 `{M̄(2..S−1)}` 的偏离（而非整体斜率）。

## 下一步（若要继续）

**先不改代码，先补一次"只测 d=1"的分析**：用已有 `metrics.json` 里的
`M` 矩阵，算 `M̄(1)` 与其余距离均值的差，并对其做同样的置换零分布。
这不需要重跑主干，成本极低。

若该差异显著且八层一致，则"相邻 token 反相关"是一个真实的位置效应，
值得单独成题；若不显著，则 v60 的结论就是干净的"无局部性"。

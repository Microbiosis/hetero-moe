# V60 — 换观测量：token 轴的局部性

## 为什么换

| 代 | 空间轴 | 观测量 | 结果 |
| --- | --- | --- | --- |
| v58 | 隐维切块（**任意**） | 切口谱 → χ | 平凡（B3 两臂相同 17.60/264） |
| v59 | token 位置（非任意） | 切口谱 → χ | 平凡（N1 0/8） |

v59 查明了原因：

> χ 度量的是「两侧是否同源」，而同一个样本的所有 token 天然同源。
> 这个量对"空间怎么切"不敏感。

所以问题不在轴，在**观测量**。本代换一个对位置敏感的量。

## 观测量：局部性

```
M[i, j] = token i 与 token j 的耦合强度
d       = |i − j|
```

若 token 轴上存在空间结构 ⇒ `M` 随 `d` **衰减**。

这是"空间有几何"能被检验的**最小陈述**。面积律只是它的推论：
局部性不成立时，任何二分的通道数都相同，面积律必然平凡 ——
正是 v58/v59 的处境。

### 耦合强度的定义

对 token i、j 各自按列标准化得 `W_i, W_j ∈ R^{n×D}`，令 `G_i = W_i W_iᵀ`。
互协方差 `W_iᵀ W_j` 的非零奇异值 = `sqrt(eig(G_i^{1/2} G_j G_i^{1/2}))`。

取**前 `topk=3` 项之和**作为耦合强度。取 3 项而非 1 项，是为了抗单点噪声：
单个最强方向可能被某次采样主导，前三项之和更稳。

## 判据（P0–P3，运行前固定）

| 判据 | 内容 |
| --- | --- |
| **P0 正控** | 纯噪声上 `\|corr(d, M̄(d))\| < 0.3` |
| **P1 距离衰减** | `corr(d, M̄(d)) < −0.5` |
| **P2 置换可分** | 真实 corr < 40 次「打乱 token 顺序」零分布的 2.5% 分位 |
| **P3 局部性比** | `M̄(1) / M̄(S−1) > 1.5` |

判读顺序：**P0 → P1/P2 → P3**。

- P0 不过 ⇒ 管线有问题，整表作废。
- **P2 不过 ⇒ P1 可能只是单调趋势的副产品**（例如所有 `M` 都随 d 缓降，
  但这与"相邻"无关）。P1 与 P2 同时过才可说存在局部结构。

## 为什么 P2 是必要的

`M̄(d)` 是一个把 15 个距离点各平均若干对的量。**任何**平滑的 `M` 都可能
给出负的 `corr(d, M̄(d))`（比如 `M` 的整体量级随索引漂移）。

P2 把同样的 `M` 的行列同时重排（保持全部数值，只破坏"谁和谁相邻"），
重算剖面。若真实 corr 不显著低于这个零分布，说明"相邻"这个信息没起作用。

## 两臂

| 臂 | 处理 | 用意 |
| --- | --- | --- |
| `raw` | 原样 | 含逐样本共同成分 |
| `centered` | `X[t] ← X[t] − mean_t X` | 去掉共同成分后，token 特有部分还有局部性吗 |

v59 显示共同因会让所有切口的 χ 相同。本代要问：它是否也让所有
**token 对**的耦合相同。单测 `test_global_common_cause_is_flat` 直接构造
这个情形，要求给出近平剖面 —— 把"为什么 v58/v59 平凡"固化成可复现的机制。

## 预期

**我预期 P1/P2 在 `centered` 臂上失败。** 理由：MSA-4B 是因果语言模型，
token 表征是**因果累积**的（位置 t 的隐状态汇聚了 0..t 的全部信息）。
因果累积不产生"局部性"，而是产生**单调漂移**——后者恰好会被
`corr(d, M̄(d))` 误读成衰减。P2 就是为区分这两者而设的。

若 P1 过但 P2 不过，则正是上述情形；若两者都过，才说明真有局部结构。

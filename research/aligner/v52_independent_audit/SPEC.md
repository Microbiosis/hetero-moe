## 0. 被复算的结论

- **v50** (规模异构线 v33): "『融合优于单专家』的 margin 主要是**识别机制**的产物;
  换成有意义的空间后 margin 塌掉。"
- **v51** (架构异构线 v6/v7): "目标置换后 margin 不变 → margin 与底座间语义对应无关;
  attention 通路的领先也随空间消失。"

## 1. 独立性: 本包刻意不 import v49/v50/v51 的实现

| 维度 | v49/v50/v51 | v52 (本包) |
|---|---|---|
| 数据生成器 | 槽位组合, 8 类, 每类 16×16 | **新词表 8 类**, 组合用**奇偶划分** → 留出是**未见组合** (不是换扰动种子) |
| 留出协议 | 同分布新扰动 | **未见组合** (每个槽位值两边都出现, 但配对没见过) |
| 非线性抬升 | 两层 MLP (SiLU) | **MLP + LayerNorm + GELU** (独立实现), 隐藏维按参数量反解 (与线性臂差 <1%) |
| 探针 | SGD 逻辑回归 (有随机性) | **闭式岭回归** (无随机性, 估计量不同) |
| 种子 | 0–4 | **1000–1004** |
| 训练循环 | v49 风格 | 重写 (minibatch + 分组学习率 + 梯度裁剪) |
| D_shared | 256 | **128 / 256 / 512** (C3 的配置稳健性) |

**只保留被审计的对象本身**: 三个真实底座 (MSA-4B 浅层 / embedding-0.6b / reranker-0.6b)
与 v33 的融合层 —— 它们是主张的对象, 不是测量工具。

## 2. 预登记判决 (事后不得修改)

| 编号 | 判决 | 阈值 |
|---|---|---|
| **C1a** | 冻结随机空间里, 源身份可解码性 − 目标类别可解码性 ≥ 0.30 | ≥4/5 seeds |
| **C1b** | 目标置换后, margin 变化 ≤ 10 个百分点 | ≥4/5 seeds |
| **C1c** | 有意义空间 (非线性可训练) 的 margin ≤ 冻结随机臂的一半 | ≥4/5 seeds |
| **C2** | **随机目标臂**里, 目标类别可解码性 ≤ 0.50 | 全部 seeds |
| **C3** | D_shared ∈ {128,256,512} 上 C1a/C1c 的方向一致 | 全部配置 |

**V1 审计通过**: C1a / C1b / C1c 在每个 D_shared 上都满足, 且 C2 通过。
**V2 审计失败**: C2 不通过 (随机目标臂里类别可解码仍 ≥ 0.70) → 探针测的不是
"输出里有目标信息" → **v50/v51 的全部探针读数作废** → 论文必须回退相应表述。
**V3 部分推翻**: 任一 D_shared 上 C1a/C1b/C1c 不满足 → 相应主张在该配置下被推翻。

## 3. C2 为什么是关键 (v50/v51 只做了正向自检)

v50/v51 的探针自检是**正向**的: 在可分数据上准确率高 (0.98), 在纯噪声上接近随机
(0.44)。但那只说明"探针能读出真实结构"; 它**没有排除**"探针读的是别的东西"。

C2 是**反向**对照: 把目标换成**逐样本随机**的块 (模型不可能解出) → 若此时类别可解码
仍然很高, 说明探针测的是"输出与底座/批次结构相关"之类的东西, 而不是"输出里有目标
信息" → v50/v51 的读数全部失去意义。**这是本次审计唯一可能推翻 v50/v51 全部结论的检查。**

### 判决

| 配置 | C1a | C1b | C1c | C2 | C3 |
|---|---|---|---|---|---|
| D_shared=128 | 通过 (逐 seed 差 0.68–0.69) | 通过 (0.0 pp) | 通过 (+23.0% → −0.0%) | 通过 (0.31–0.32) | 方向一致 |
| D_shared=256 | 通过 (0.57–0.61) | 通过 (0.0 pp) | 通过 (+32.9% → +0.2%) | 通过 (0.39–0.43) | 方向一致 |

**V1 审计通过** —— 五条预登记判决在三档配置上全部满足。

### 两条比预登记更强的发现

1. **冻结随机臂的 A / B / D 三臂数字逐位相同** (fuse 7.1759 / margin +23.0% / 源 1.000 / 目标块 0.314,
   三档配置皆然)。D 臂的目标是**逐样本随机**的 → 模型绝无可能解出 → 但它的
   held-out 数字与"目标对齐"臂**完全一致**。
   → **在冻结随机空间里, 模型的输出与目标毫无关系**; 那个 +23%~+38% 的 margin
   是两个**同样坏**的模型之间的比较 (fuse 5.8–7.2, 而平凡基线是 0.125 →
   差 46–57 倍)。它比 v50/v51 的"识别机制假象"更彻底: 连任务都没在做。
2. **有意义空间里 margin 归零而绝对误差降约 100 倍** (5.78 → 0.071, 低于平凡
   基线 0.125), 且目标类别可解码性升到 0.55–0.57 (随机基线 0.125) → 模型
   **确实在解任务**; 而此时**融合相对最优单专家没有任何优势** (+0.0%~+0.3%)。
   → 在有意义的空间里, 这套架构的收益来自**空间**, 不来自**融合**。

### C2 的读数要如实记

随机目标臂的目标类别可解码为 0.31–0.46, **高于 0.125 的随机基线**。
这说明冻结随机投影本身**残留**了一些类别信息 (残差通路泄漏), 但模型无法用它
去拟合目标 (fuse 与目标无关)。C2 的阈值 (≤0.50) 通过, 但这个余量要写进正文,
不能只报"通过"。

## 5. 诚实声明

1. 本包仍然只覆盖**一个合成协议** (三类底座、槽位组合文本、CPU 规模); 真实语料未验证。
2. 探针是**线性**的 (岭回归); 非线性探针可能读出更多 —— 但 C1a 断言的是"源 ≫ 类别"
   这个**大差距**, 线性探针的局限不足以制造它。
3. "有意义空间"沿用 v50 的配方 (非线性 + 可训练), 未再区分"非线性"与"可训练"两个因子
   (那是 v49 的 2×2 已覆盖的); 本包只审计**"空间从随机变有��"这一个方向**。
4. `leakage_audit`: 本包是**对 v50/v51 的审计**, 自身仍需第三个独立复算才算结清
   (三审制); 在此之前, 论文里相关表述应保持 "pending independent audit"。

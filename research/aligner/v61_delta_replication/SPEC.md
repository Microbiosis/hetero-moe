# V61 — Δ（最邻近效应）的跨模型复制

## 这一代要判定什么

v60.1 的事后分析发现 `Δ ≡ M̄(1) − mean(M̄(2..S−1))` 在三种臂上都显著且八层一致，
但**三臂方向分裂**：

| 臂 | Δ 符号 | 读作 |
| --- | --- | --- |
| `raw` / `centered` | **正** | 位置通用成分 `p_t` 平滑 |
| `detrend` | **负** | 去掉 `p_t` 后，样本特异偏离在相邻位置反相关 |

那是**事后探索**（判据在看到主结果之后才定），不能作为结论。

**本代把它变成预登记检验**：判据写在运行之前，且要求**跨模型复制**。
单模型上的效应可能只是该模型的位置编码实现细节；跨三个不同规模/用途的
模型都成立，才值得当一个现象。

## 条件

3 个模型 × 2 个 token 长度 = **6 个条件**

| 模型 | HF 仓库 | 说明 |
| --- | --- | --- |
| big | `EverMind-AI/MSA-4B` | D=2560，v58/v59/v60 用过的同一个 |
| emb | `EverMind-AI/skillcorpus-embedding-0.6b` | 0.6B，检索嵌入 |
| rer | `EverMind-AI/skillcorpus-reranker-0.6b` | 0.6B，重排 |

token 长度：**16 和 32**。若 Δ 是位置效应，它不应只在某一个长度上存在。

层：每模型取前 8 层（不足 8 层则全取）。

## 观测量（与 v60.1 完全一致，不再改）

```
M[i, j] = (1/n) Σ_s cos( X[s,i,:], X[s,j,:] )     跨样本平均的位置对余弦
Δ       = M̄(1) − mean( M̄(2..S−1) )
```

零分布：打乱 token 顺序（M 的行列同时重排），40 次，取 [2.5%, 97.5%]。
"显著" = Δ 落在该区间之外。

## 预登记判据（R0–R4，运行前固定，运行后不得修改）

| 判据 | 内容 | 若不过意味着 |
| --- | --- | --- |
| **R0 正控** | 6 个条件里，纯噪声的 Δ **全部**不显著 | 管线有问题，整表作废 |
| **R1 跨模型复制** | `detrend` 臂：Δ<0 在 **≥5/6** 条件成立，且**每个成立的条件内 ≥6/8 层为负** | 该效应不是跨模型规律 |
| **R2 反向对照** | `raw` 臂：Δ>0 在 **≥5/6** 条件成立（同上层级要求） | "位置通用成分平滑"这一半不成立 |
| **R3 效应量** | 全部条件的中位 \|Δ\| > **0.05** | 统计显著但太小，无实际意义 |
| **R4 非交替** | 每个条件下 \|mean(偶 d) − mean(奇 d≥3)\| < **0.15** | 效应可由"逐位置交替"解释，不是最邻近特性 |

### R1 与 R2 是两条独立预测

它们方向相反，不能同时由"某种伪影"满足：

- R1 说：剥掉位置通用成分后，相邻 token 的**残差**互相区分。
- R2 说：位置通用成分本身随位置**缓慢变化**。

若两者都成立 ⇒ 位置结构至少有两层，且方向相反。
若只有 R1 成立 ⇒ "平滑的位置成分"是错的，需重新解释。
**两条都是可证伪的**，这是本代最重要的设计。

### R4 为什么必要

若隐表征里存在随位置**交替**的分量（偶/奇位置分属两簇），
则 `cos` 在任何奇距离上都偏低、偶距离上都偏高，`M̄(1)` 自然为负 ——
但那**不是**"最邻近"效应，而是周期为 2 的周期性。

判别方法：把 d=1 排除，比较偶距离与奇距离的均值。
若差异大，则效应是周期性的；若差异小，则效应确实局限在 d=1。

## 判读规则

- R0 不过 ⇒ 整表作废，不提任何结论。
- R1 与 R2 都过 ⇒ "位置结构有两层且方向相反"成立。
- R1 过 R2 不过 ⇒ 只有残差层成立，`raw` 的正 Δ 需另找解释。
- R1 不过 ⇒ v60.1 的观察**不能复制**，应明确记为"未复现"。

## 与 v60 的关系

v60 的预登记判据（P1/P2，线性相关）**仍然全败**，那个结论不变。
本代不推翻它 —— 本代检验的是另一个量（Δ），
因为 v60.1 已表明线性相关会把 d=1 的离群值和 d≥2 的缓变混成一个无意义的中庸值。

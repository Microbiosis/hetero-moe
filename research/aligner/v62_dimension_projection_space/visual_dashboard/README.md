# visual_dashboard —— 仪表盘版机制可视化

**形式沿用 `moe_mechanism_full.mp4`（旧版七幕），内容换成 v62.3 的真实数据。**

用户看过旧版后说：「视频修修改改那么多次，没有这个表现形式好看」——
所以这里刻意保留旧版的视觉语言，只换掉过期内容（旧版讲的是 v33 时代的
玩具模型 MiniHeteroMoE：STE 路由 + 量化 + 反向梯度）。

## 沿用的「形式」四层

| 层 | 旧版 | 这里 |
|---|---|---|
| 左上固定标题块 | 17pt bold + 9.5pt 副标题 | 同 |
| 每幕左上幕名 | `head()`，13pt bold | 同 |
| **底部章节进度条** | 彩色段，当前幕 alpha 0.85 / 其余 0.18 | 同 |
| 片头七幕目录 | ①…⑦ 逐个亮起 | 同 |

配色与旧版完全一致：
`BG #0a0c10` · `FG #e8eaed` · `DIM #5b6572` · `GOLD #F0873B` ·
`ICE #64E3F6` · `GREEN #35D0BA` · `RED #CF3655` · `VIOLET #b085f5`

## 换掉的「内容」

| 幕 | 旧版（v33 玩具模型） | 现在（v62.3 真实） |
|---|---|---|
| ① 前向 | 一个 token 穿过算子链 | 896/256/768 → P_m → 256 → 四槽 → canonical 1024 → 4 专家 |
| ② mask | 三个 6×4 矩阵 | **十个真实投影矩阵** proj[s\|m]（Q/K/V/O × 三模态） |
| ③ 量化 | 台阶 + 误差直方图 | **槽门控分布**：Q 槽 α=0.0035 几乎为空 |
| ④ 反向 | 梯度链 + 柱状图 | **专家负载**：2002 条 held-out，均衡 0.612 |
| ⑤ 注意力 | Q·Kᵀ 真实计算 | **对齐**：两两 0.988+ vs 三模型 0.6767，环路约束后 0.9925 |
| ⑥ 负载演化 | 训练中路由演化 | **逐 token 路由热力图**（真实 held-out） |
| ⑦ 总结 | 七幕要点 | v62.3 的五行要点 |

## 文件

| 文件 | 说明 |
|---|---|
| `style_dash.py` | 形式层：标题块 / 幕名 / 进度条 / 热力图 / 竖条 / 缓动 |
| `acts.py` | 七幕的内容 |
| `render_dashboard.py` | 编排：片头 + 七幕 + 进度条 + 落帧 |
| `v62_dash_sample.json` | 渲染数据（由 Kaggle kernel `hetero-moe-v62-emb` 抓） |

## 渲染

```
DASH_DATA=... DASH_OUT=... python render_dashboard.py
```

1370 帧 / 1600×1000 / 30fps = **45.7 秒**（与旧版等长）。
在 Kaggle 上跑（本地跑会占满手机 CPU/内存）。

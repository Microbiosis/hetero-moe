# V58.0 — 膜 / 面积律算子: 维度按边界面积分配

> **日期**: 2026-10-28
> **归属**: aligner（投影空间线的理论收口）
> **复现**: `bash run.sh v58` / `python tests/test_v58_entanglement_area.py`（11/11）
> **一句话**: v57 让维度会伸缩，但只有一个**全局标量 r**。膜结构要求维度在空间上**分布不均**，
> 而这件事必须由 Ryu–Takayanagi 的面积律来定，不能拍。

## 0. 理论链（每一环都可算，没有一环是比喻）

```
膜理论 / AdS-CFT
  → Ryu–Takayanagi:  S(A) = Area(γ_A) / (4 G_N)
     「区域 A 的纠缠熵由包围它的最小曲面面积决定」
  → 高斯基态下这条是**可算的恒等式**:
     S(A) = ½ Σ_i log( 1 / (1 − ρ̃_i²) )
     ρ̃_i 由跨越 A|B 的互协方差谱给出 —— 只有「跨界的通道」计入熵
  → 面积律: S 随 |A| **饱和**; 体积律: S ∝ |A| 线性增长
  → 张量网络: 切口上的 bond dimension χ ≈ e^{S}
  → **自适应维度的正确形式**: χ 由边界面积决定，与块内体积无关
```

这给出 v57 给不出的东西：

| | 表达形式 | 能表达什么 |
|---|---|---|
| v57 | 一个全局标量 `r` | 维度会伸缩，但处处同宽 |
| **v58** | 逐切口 `χ(l)` 剖面 | 维度**在空间上分布不均** |

**B4 是证伪点**：若 χ 处处相同，膜结构就退化回 v57，本文的主张不成立。

## 1. 算子：为什么用互协方差，不用 CCA

第一版用了 CCA（正则相关）。**实测连续踩三个坑**，全部记录在此：

| 做法 | 失败现象 | 根因 |
|---|---|---|
| 朴素 CCA | 纯独立随机块（n=512, 32×48）给出 **29–31** 个"显著"通道 | 白化在 n 与 d 同量级时把样本噪声白成信号 |
| + 置换零分布 (n_null=8, 95 分位) | k=12 读成 **13**、k=6 读成 **7** | 小样本分位数插值抖动，系统性 +1 |
| + z 检验 (n_null=16) | 噪声通道 z>2 → k=2 读成 **17** | 16 次置换估不准尾部，z 重尾 |

**正解：直接对互协方差矩阵做 Gavish–Donoho 阈值。**

```
Σxy = XᵀY / (n−1)          （两侧按列标准化到 ‖col‖=√n）
独立时 Σxy 的元素 ~ N(0, 1/n)  ⇒  σ = 1/√(n−1)  是**解析值**
τ = ω(β)·σ·√max(da,db),   β = min/max
χ = #{singvals(Σxy) > τ}
```

**没有置换、没有自由参数、没有阈值要调。**

关键细节：σ 必须用**解析值**而不是 GD 的 `median(s)` 估计。因为 GD 的
σ̂ 假设"信号稀疏、中位数仍属噪声"；当信号子空间接近 ambient 时中位数被污染，
σ̂ 虚高 → τ 虚高 → 漏掉通道（实测 k=20 读成 7、k=30 读成 4）。
用解析 σ 后 k∈{0..12} **全部精确**。

## 3. 预登记判决

| 编号 | 判决 | 失败意味着 |
|---|---|---|
| **B1** | 面积律：\|corr(\|A\|, χ)\| < 0.5 | 体积律 ⇒ 维度随体积膨胀，膜图像失效 |
| **B2** | RG 流：沿层方向的熵随深度下降 | 没有粗粒化 ⇒ 层不是 RG 方向 |
| **B3** | 顺序有结构：natural 的 χ < random 的 χ | 「相邻」无意义 ⇒ 只是任意二分 |
| **B4** | 非均匀：χ 剖面取值 > 1 种 | **膜退化成 v57 的标量 r** |

## 4. 诚实边界

- `ambient` 是计算上界；χ 是**可分辨通道数**，不是物理维数
- 扩张不造信息：出生 = 此前低于噪声地板的方向浮出水面
- **大 k 失效**：信号占满 ambient 时噪声地板消失，k≥20 低估（17/15 vs 20/30）。
  真实表征里 χ 远小于 ambient，故此边界影响有限，但必须写明
- 互协方差只测**线性**耦合；非线性依赖会漏（与 CKA/CVA 同一盲区）
- 「层 = RG 方向」是一个假设；B2 正是它的检验
- `n_blk` 切块是对隐维的任意二分；B3 用 random 置换做对照来检测这一点

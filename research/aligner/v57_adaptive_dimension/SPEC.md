## 1. 算子设计

### 1.1 状态

```
状态 = (V, s)        V ∈ R^{d×r} 正交基（d 是 environment 上界）
维度 = r = V 的列数   —— 随数据出生/死亡，双向
```

**空间就是状态。** 没有「先定 D，再建模型」这一步。

### 1.2 两个动作都由数据决定

| 动作 | 触发条件 | 数学依据 |
|---|---|---|
| **扩张**（出生） | 残差里出现超阈值的奇异方向 | Gavish–Donoho 最优硬阈值 |
| **坍缩**（死亡） | 某方向能量 < 噪声地板，且连续 `window` 步 | MP 噪声谱 |

阈值不是拍脑袋：

```
τ = ω(β)·σ̂·√max(n,d),   ω(β) = 0.56β³ − 0.95β² + 1.82β + 1.43
σ̂ = median(s) / (√max(n,d) · c_β),   c_β = median(Marchenko–Pastur)
```

这是**未知噪声下 Frobenius 最优**的硬阈值（Gavish & Donoho 2014）。
它保证 τ 刚好高于噪声谱上边缘 —— 纯噪声矩阵估出 **0** 秩，不会自欺。

### 1.3 自写算子：把可导与不可导分开

```python
class _SpectralProject(torch.autograd.Function):
    # 前向: Z ← Z V Vᵀ
    # 反向: 直通 —— 只回传子空间「内」的梯度，
    #       不假装能对「选了哪几个方向」求导
```

「选哪几个方向」是离散决策，没有梯度。**显式承认这一点**，而不是让 autograd
在一个伪梯度上蒙混。

### 1.4 空间模型化（模型次之）

```python
y = P_V · W · P_V · x        P_V = V Vᵀ,   W ∈ R^{d×d} 形状固定
```

W 的参数总量**不随 r 变**，变的是**有多少参数被用到**：

| r | 有效参数 / 总参数 |
|---|---|
| 5 | 1255 / 16384 |
| 0 | 0 / 16384 |

于是：
- **r 长大** → 有效容量自动变大，不需要重建模型、不重置参数
- **r 收缩** → 被砍掉的方向自动不参与，灾难性遗忘被空间本身挡住

这就是「空间优先，然后才是模型」的可执行形式。

## 2. 实验：真实表征上的 r(t)

三阶段数据流（每阶段 10 批 × 32 样本，复用 v56 的 `h_base[512,2560]` + `c_passive[512,512]`）：

| 阶段 | 输入 | 预期 |
|---|---|---|
| P1 | 只用文本侧 | r 低 |
| P2 | 文本 + 表格 | **扩张** |
| P3 | 只用文本侧 | **坍缩** |

### 预登记判决

| 编号 | 判决 | 失败的意味 |
|---|---|---|
| **V1** | P2 的 r > P1 的 r | 不会扩张 = 换名的固定维度 |
| **V2** | P3 的 r < P2 的 r（且 `died > 0`） | 只会涨不会缩 = 单调增长器，不是自适应 |
| **V3** | r 在整条轨迹上取值 > 1 种 | 维度是常数 |
| **V4** | 记录 max r 与固定 D 的比值 | 固定 D 的代价 |

**V2 是关键。** 一个「只会扩张」的空间等于固定维度换了个名字。

## 4. 诚实边界

- `ambient_dim` 是**计算上界**，不是维度。真实维度是 r，且 r ≤ ambient
- **扩张不是造信息**：出生意味着此前低于噪声地板的方向浮出水面；
  没有算子在 ambient 之外创造维度
- 噪声地板依赖"噪声近似各向同性"这一假设；真实表征的噪声可能结构化，
  此时 τ 会偏保守或偏激进（需在 v58 用已知秩的注入实验标定）
- 单数据集、单批次策略（32/批）；batch 大小会直接影响 n，从而影响 τ
- `AdaptiveOperator` 的 W 是 d×d，d 大时参数浪费（有效的是 P_V W P_V）；
  更省的实现是将 W 参数化在 V 的坐标里，但那会破坏「维度变化不重置参数」这一性质

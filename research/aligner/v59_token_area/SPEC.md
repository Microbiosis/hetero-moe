# V59 — 面积律，空间轴换成 token 位置

## 问题

v58 把 2560 维隐表示切成 16 个块当空间轴，但那个轴是**任意的**：
隐维没有天然次序。v58 的 B3 两臂给出完全相同的均值与总容量
（17.60 / 264）⇒ 按 `brane.make_lattice` 自己的判读规则，
此时"面积律是任何二分都有的平凡性质"，B1 的"过"不可解释。

**要谈空间上的面积律，必须用一个非任意的轴。** token 位置就是：
它是序列，相邻即相邻。

## 与 v58 的两处方法学改动

### 1. 阈值改为每切口就地零分布

v58 的 `noise_tau` 被推翻四版（低 5–9 倍 → 高得离谱 → 凸组合 0/40 → 经验式），
根因是"一个拟合公式覆盖所有 (n,d)"这个想法本身不稳。

v59 不再拟合：对同一个 `(n, d_a, d_b)`，用纯噪声重复 `N_NULL` 次算谱最大值，
取其 0.95 分位作 τ。假设被去掉，而不是被修得更准。

### 2. 谱计算用 Gram 技巧

token 轴上 `d_a = k·2560` 最大到 `15·2560 = 38400`。直接算 `AᵀB` 是 O(d_a·d_b)，
内存不可行。改用 `AAᵀ / BBᵀ`（n×n）求同一组奇异值：

```
AᵀB 的非零奇异值 = sqrt(eig(G_a G_b)),  G_a = AAᵀ, G_b = BBᵀ
G_a G_b 相似于 Lᵀ G_b L   (G_a = LLᵀ)
⇒ 只需 n×n 特征分解
```

单测 `test_gram_equals_direct` 强制两条路径对比，相对误差 <0.5%。

## 预登记判决（运行时不可改）

| 判据 | 内容 |
| --- | --- |
| **N1 顺序有结构** | ≥3/15 切口上，natural 的 χ 落在置换零分布 `[2.5%, 97.5%]` 之外 |
| **N2 面积律** | `corr(\|A\|, χ_natural) < 0.5` |
| **N3 非均匀** | χ 剖面 ≥ 3 种取值 |
| **N4 正控** | 纯噪声在全部切口上 χ = 0 |

**判读顺序：N4 → N1 → N2/N3。**

- N4 不过 ⇒ 阈值仍低于噪声，整表作废。
- **N1 不过 ⇒ N2 不可解释**（v58 的教训：平凡性质也会"过"）。

## 置换零分布的定义

对每个切口 k，零分布是「从 16 个 token 中**随机取 k 个**放进 A」，
重复 `N_PERM=40` 次。它回答的问题是：

> **在位置 k 处切开，是否比随便挑 k 个 token 更特殊？**

如果模型对 token 位置不敏感（或层已充分上下文混合），两者不可分。

## 灵敏度正控（单测）

光有零分布不够——还要证明这个检验**能**检测到顺序结构。
`test_positional_structure_detected` 构造 `X[t] = base + t·direction`，
要求 natural 显著高于置换上界。若这个测试都过不了，N1 无灵敏度，读数无意义。
